# CFServerLauncher v1.1 실행 프로필 계획

문서 버전: v1.1.0-plan  
작성 기준일: 2026-05-29

## 1. 목적

v1.1의 목적은 v1.0에서 하나만 존재하던 서버 실행 설정을 여러 개의 실행 프로필로 확장하는 것이다.

프로필은 서버 실행 설정을 이름 붙여 저장하는 프리셋이다.

예시:

```text
로컬 테스트 서버
차량 테스트 서버
밸런스 테스트 서버
```

각 프로필은 서로 다른 맵, 포트, 로그 경로, 추가 인자를 가질 수 있다.

## 2. 배경

v1.0은 단일 서버 실행을 안정적으로 처리한다.

v1.0 완료 기능:

- 서버 시작
- 서버 종료
- 로그 tail
- 설정 저장/불러오기
- 찾아보기 버튼
- runtime 로그 경로 분리
- 서버 실행 중 앱 닫기 확인
- publish 스크립트

다음 단계에서는 테스트 목적별 설정을 쉽게 바꿀 수 있어야 한다.

## 3. v1.1 목표

```text
서버 실행 설정을 여러 개의 프로필로 저장하고,
선택한 프로필 값으로 서버를 실행할 수 있게 만든다.
```

## 4. 포함 기능

- 프로필 목록 표시
- 프로필 선택
- 현재 UI 값을 새 프로필로 저장
- 선택한 프로필에 현재 UI 값 저장
- 선택한 프로필 삭제
- 마지막 선택 프로필 기억
- v1.0 설정 파일 자동 마이그레이션
- 선택한 프로필 기준 서버 시작/종료/재시작

## 5. 제외 기능

- 여러 서버 동시 실행
- 프로필별 자동 서버 시작
- 서버 자동 재시작
- 원격 서버 관리
- RCON
- 웹 대시보드
- Unreal 빌드/Cook/Stage 자동화
- CPU/메모리/TPS 모니터링
- 서버 빌드 자동 교체

## 6. 프로필 기본 동작

### 6.1 앱 시작 시

```text
1. server.local.json을 읽는다.
2. v1.1 구조이면 그대로 로드한다.
3. v1.0 구조이면 기본 프로필 1개로 마이그레이션한다.
4. 선택된 프로필 값을 UI에 적용한다.
```

### 6.2 프로필 선택 시

```text
1. 선택한 프로필을 찾는다.
2. 프로필 값을 UI 입력 필드에 적용한다.
3. 실행 인자 미리보기를 갱신한다.
4. selectedProfileName을 갱신한다.
```

### 6.3 프로필 저장 시

```text
1. 현재 UI 값을 읽는다.
2. 선택한 프로필에 값을 덮어쓴다.
3. server.local.json에 저장한다.
```

### 6.4 새 프로필 생성 시

```text
1. 현재 UI 값을 기반으로 새 프로필을 만든다.
2. 프로필 이름을 사용자에게 입력받는다.
3. 중복 이름이면 생성을 막는다.
4. 새 프로필을 선택 상태로 만든다.
5. server.local.json에 저장한다.
```

### 6.5 프로필 삭제 시

```text
1. 삭제 확인 대화상자를 표시한다.
2. 프로필이 1개뿐이면 삭제를 막는다.
3. 삭제 후 남은 첫 번째 프로필을 선택한다.
4. server.local.json에 저장한다.
```

## 7. 기본 프로필

v1.1 초기 기본 프로필은 하나만 만든다.

```text
로컬 테스트 서버
```

나머지 프로필은 사용자가 직접 만든다.

## 8. 완료 기준

```text
1. 프로필 콤보박스가 표시된다.
2. 기본 프로필이 존재한다.
3. 프로필 추가/선택/저장/삭제가 가능하다.
4. 마지막 선택 프로필이 앱 재실행 후 유지된다.
5. v1.0 설정이 자동으로 v1.1 구조로 변환된다.
6. 선택한 프로필로 서버 시작/종료/재시작이 가능하다.
7. v1.0의 핵심 기능이 깨지지 않는다.
```
