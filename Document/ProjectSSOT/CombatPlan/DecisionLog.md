각 상세 문서는 개별 주제의 설명을 담당하고, 이 문서는 결정의 요약과 추적을 담당한다.


| 상태 | 의미 |

### CP-D001. 전투 정체성 기준 채택

- 날짜: 2026-06-02
- 상태: Accepted
- 관련 문서: `01_Identity.md`

#### 결정

CarFight는 차량을 직접 몰고 조준하며 싸우되, 승패는 피팅·거리·각도·속도·락온·배터리/연료·탄약 중량 운용에서 갈리는 전략형 차량 전투 게임으로 정의한다.

#### 이유

전략 측면은 EVE Online처럼 깊이를 가지되, 전투 조작은 Elite Dangerous처럼 직접 조준과 하드포인트 운용 감각을 가져야 한다.

다만 CarFight는 자동차 전투 게임이므로, 모든 자원과 기동 규칙은 자동차 기반으로 재해석해야 한다.

#### 영향 범위

- 전투 시스템 전체
- 피팅 시스템
- 무기 시스템
- 탄약 시스템
- 차량 기동 시스템
- 전투 UI
- AI 전투 행동

#### 후속 작업

`02_WinFactors.md`에서 승패를 가르는 핵심 요소를 선정한다.

- 밸런싱 문서

#### 후속 작업

### CP-D003. 열은 무기별 자원으로 분리

- 날짜: 2026-06-02
- 상태: Accepted
- 관련 문서: `01_Identity.md`, `11_WeaponHeat.md`

#### 결정

열은 차량 전체 자원이 아니라 무기별 자원으로 둔다.

반면 차량 전체 과열은 자동차 전투의 정체성을 흐리고, 우주선식 자원 관리처럼 보일 위험이 있다.

- 피팅 시스템

#### 후속 작업

`11_WeaponHeat.md`에서 무기별 과열, 냉각, 과열 페널티를 정의한다.

### CP-D004. 탄종 / 탄수 / 중량 연계 채택

- 날짜: 2026-06-02
- 상태: Accepted
- 관련 문서: `01_Identity.md`, `07_AmmoDamageTypes.md`, `13_Fitting.md`

#### 결정

탄종과 탄수는 피팅의 핵심 요소로 둔다.

탄약을 많이 싣거나 무거운 탄종을 선택하면 차량 중량이 증가하고, 가속 / 제동 / 선회 / 연료 소비 등에 영향을 준다.

#### 이유

탄약 적재량이 전투 지속력만 결정하면 전략성이 약하다.

탄약을 중량과 연결하면 출격 전 선택이 전투 중 기동성과 생존성에 직접 영향을 준다.

#### 영향 범위

- 탄약 시스템
- 피팅 시스템
- 차량 중량 계산
- 차량 기동성
- 연료 소비
- 전투 UI

#### 후속 작업

`07_AmmoDamageTypes.md`에서 탄종과 탄수의 역할을 먼저 정의하고, `13_Fitting.md`에서 중량 계산과 연결한다.

### CP-D006. 무기 각속도 원칙 채택

- 날짜: 2026-06-02
- 상태: Accepted
- 관련 문서: `02_WinFactors.md`, `05_AimingSystem.md`, `06_WeaponTypes.md`, `12_Hardpoints.md`

#### 결정

고정 무기가 아닌 모든 무기에는 각속도 개념을 둔다.

강한 한 방 무기일수록 회전 속도와 조준 안정화가 느려야 하며, 빠르게 붙거나 측면을 파고드는 상대를 쉽게 따라잡지 못해야 한다.

#### 이유

무기 밸런스를 피해량, 연사력, 사거리만으로 잡으면 대구경 / 고화력 무기가 만능화될 위험이 있다.

무기 각속도는 빠른 차량의 근접 압박, 측면 진입, 고속 교차 기동에 의미를 부여한다.

#### 영향 범위

- 조준 방식
- 무기 밸런스
- 터렛 / 짐벌 / 제한 회전 무기
- 차량 기동 가치
- 피팅 선택
- 전투 UI
- AI 조준 행동

#### 후속 작업

`05_AimingSystem.md`에서 무기 각속도, 조준 가능 각도, 조준 안정화 시간을 구체화한다.

### CP-D008. 조준 방식 5종과 조준점 분리 원칙 채택

- 날짜: 2026-06-08
- 상태: Accepted
- 관련 문서: `05_AimingSystem.md`

#### 결정

CarFight의 조준 방식을 아래 5종으로 정의한다.

1. 고정 무기
2. 짐벌 무기
3. 터렛 무기
4. 락온 무기
5. 수동 유도 무기

무기 실제 조준점이 늦게 따라오도록 만들면 빠른 차량의 근접 압박, 측면 진입, 고속 교차 기동에 전술적 의미가 생긴다.

- 조준 시스템
- 무기 타입
- 무기 각속도 / 안정화
- 전투 UI
- 배터리 / 센서 / 락온 시스템
- P0 전투 프로토타입

#### 후속 작업

`06_WeaponTypes.md`에서 무기 타입을 피해 방식, 조준 방식, 각속도, 탄약 중량, 무기 열, 배터리 의존도, 전투 거리의 조합으로 정의한다.

#### 후속 작업

### CP-D015. 전투 AI 역할 기반 설계 원칙 채택

- P0 전투 테스트

P0에서는 4개 역할 AI만 구현하고, 복잡한 전자전/설치물/다수 AI 협동 전술은 P1 이후로 미룬다.

### CP-D018. 밸런싱 원칙 채택

- 상태: Accepted
- 관련 문서: `18_Balancing.md`

밸런싱은 수치보다 역할 차이를 우선하며, 모든 강점은 거리, 각도, 중량, 열, 배터리, 탄약, 조작 난이도 중 하나의 대가를 가져야 한다.

### CP-D019. CombatPlan 싱글플레이 기준 채택

- 날짜: 2026-06-19
- 상태: Accepted
- 관련 문서: `README.md`, `00_Index.md`, `04_Positioning.md`, `06_WeaponTypes.md`, `15_CombatAI.md`

#### 결정

현재 `CombatPlan`의 P0 / P1 전투 기준은 싱글플레이 AI 교전으로 둔다.

멀티플레이, PvP, 팀전, 매치메이킹, 서버 / 네트워크 전제는 `CombatPlan`의 현재 범위에서 제외한다.

#### 이유

현재 CombatPlan은 전투 정체성, 차량 기동, 조준, 피팅, 락온, AI 역할을 먼저 검증하는 문서 묶음이다.

멀티플레이 전제를 섞으면 밸런싱, UI, AI, 네트워크 범위가 한 문서군 안에서 섞여 P0 검증 목표가 흐려진다.

#### 영향 범위

- 전투 시스템 문구
- 무기 역할 설명
- 차량 역할 설명
- AI 전투 범위
- P0 / P1 검증 기준
- 멀티플레이 범위 제외 기준

#### 후속 작업

`팀전`, `팀플레이`, `팀 전술`로 읽히던 기존 표현은 싱글플레이 기준의 AI 목표 압박, 여러 AI 역할 대응, 다수 AI 협동 행동 제외로 정리한다.

현재 CombatPlan 안에서는 서버 / 네트워크 / 팀전 밸런스를 다루지 않는다.
