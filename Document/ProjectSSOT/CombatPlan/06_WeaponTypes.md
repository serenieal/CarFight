- 문서 상태: Current

---

## 1. 목적

이 문서는 CarFight의 무기 타입을 정의한다.

무기 타입은 단순한 총기 이름이 아니라, 아래 요소가 결합된 전투 역할 단위로 다룬다.

```text
무기 타입 = 피해 방식 + 조준 방식 + 유효 거리 + 무기 각속도 + 탄약 중량 + 무기 열 + 배터리 의존도 + 대응법
```

CarFight는 EVE Online식 전략 구조를 참고하지만, 우주함선 전투를 그대로 복제하지 않는다.

따라서 무기는 자동차 기반 전투에 맞게 거리, 각도, 속도, 접지, 장갑 방향, 차량 중량, 탄약 적재량과 연결되어야 한다.

---

## 2. 핵심 원칙

### 2.1 무기는 피해량만으로 구분하지 않는다

무기 밸런스는 피해량, 연사력, 사거리만으로 잡지 않는다.

CarFight의 무기 타입은 아래 요소를 함께 가진다.

| 기준 | 설명 |
|---|---|
| 역할 | 전장에서 맡는 임무 |
| 강한 거리 | 가장 효율이 좋은 교전 거리 |
| 조준 방식 | 고정, 짐벌, 터렛, 락온, 수동 유도 |
| 각속도 | 목표를 따라가는 속도 |
| 조준 안정화 | 목표 방향에 도달한 뒤 정확도가 회복되는 시간 |
| 무기 열 | 사격할수록 해당 무기에 쌓이는 열 |
| 탄약 중량 | 탄을 많이 실을 때 차량 중량에 미치는 영향 |
| 배터리 의존도 | 센서, 락온, 안정화 보조 필요 여부 |
| 강한 대상 | 어떤 차량/상황에 강한지 |
| 약한 대상 | 어떤 차량/상황에 약한지 |
| 대응법 | 상대가 어떻게 대처할 수 있는지 |

---

### 2.2 편한 무기일수록 대가가 있어야 한다

조준이 편하고 대응이 쉬운 무기는 화력, 중량, 탄약, 배터리, 각속도, 락온 취약성 중 하나로 대가를 치러야 한다.

```text
강하지만 어렵다.
편하지만 약하다.
자유롭지만 느리다.
압박은 강하지만 대응 가능하다.
```

이 원칙을 유지해야 직접 조준, 차량 기동, 피팅 선택이 모두 의미를 가진다.

---

### 2.3 강한 한 방 무기에는 각속도 약점이 필요하다

대구경 무기나 고화력 무기는 한 방이 강한 대신 아래 약점을 가져야 한다.

```text
느린 회전
느린 조준 안정화
느린 재장전
높은 무기 열
높은 탄약 중량
높은 장착 중량
```

빠른 차량은 이런 무기의 각속도 한계를 넘는 방식으로 생존해야 한다.

## 3. 무기 타입 전체 분류

CarFight의 1차 무기군은 아래 10개로 정의한다.

```text
01. 기관총
02. 오토캐논
03. 대구경포
04. 산탄 무기
05. 로켓
06. 미사일
07. 레일건 / 코일건
08. EMP / 전자전 무기
09. 방어 장비
10. 지뢰 / 설치물
```

P0에서는 전체 무기군을 모두 구현하지 않는다.

P0 우선 무기군은 아래 4개로 제한한다.

```text
01. 기관총
02. 오토캐논
03. 대구경포
04. 미사일 또는 락온 로켓
```

미사일을 P0에 넣는다면, 대응용 연막 또는 플레어 1종도 같이 넣어야 한다.

## 4. 기관총

### 4.1 정의

기관총은 가볍고 빠르게 반응하는 지속 화력 무기다.

CarFight에서 기관총은 가장 강한 무기가 아니라, 가장 안정적으로 쓸 수 있는 기본 전투 무기에 가깝다.

---

### 4.2 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 빠른 목표 대응, 근거리 압박, 마무리 |
| 보조 역할 | 바퀴, 센서, 외부 모듈 타격 |
| 강한 거리 | 초근거리 ~ 중거리 초입 |
| 약한 상황 | 중장갑 정면, 장거리 교전 |

---

### 4.3 조준 방식

| 조준 방식 | 적합도 | 설명 |
|---|---:|---|
| 고정 | 중간 | 경량 차량의 정면 압박용 |
| 짐벌 | 높음 | P0 기준 무기로 적합 |
| 터렛 | 높음 | 방어 터렛, 근접 대응용 |
| 락온 | 낮음 | 기관총과는 맞지 않음 |

기관총은 짐벌 또는 소형 터렛과 궁합이 좋다.

---

### 4.4 전투 특성

| 요소 | 방향 |
|---|---|
| 피해량 | 낮음 |
| 연사력 | 높음 |
| 각속도 | 빠름 |
| 안정화 시간 | 짧음 |
| 무기 열 | 천천히 누적 |
| 탄약 중량 | 낮음 ~ 중간 |
| 탄 소모 | 높음 |
| 배터리 의존도 | 낮음 |

---

### 4.5 강점

- 빠른 차량을 따라가기 좋다.
- 초보자가 이해하기 쉽다.
- 과열 부담이 비교적 낮다.
- 근거리에서 상대 무기의 조준을 흔들며 압박할 수 있다.
- 바퀴, 센서, 노출된 터렛 같은 외부 모듈을 갉아먹기 좋다.

---

### 4.6 약점

- 중장갑 차량 정면에는 효율이 낮다.
- 탄 소모가 빠르다.
- 장거리 피해 효율이 낮다.
- 한 방 결정력이 부족하다.

---

### 4.7 설계 원칙

```text
기관총은 약하지만 빠르고 안정적인 무기다.
빠른 목표를 상대하거나 근거리 압박을 유지하는 데 강해야 한다.
```

P0에서는 소형 짐벌 기관총을 기준 무기로 둔다.

---

## 5. 오토캐논

### 5.1 정의

오토캐논은 기관총보다 느리지만, 더 강한 피해와 관통력을 가진 중거리 주력 화기다.

CarFight의 기본 전투 감각을 만들기 가장 좋은 무기군이다.

---

### 5.2 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 중거리 주력 교전 |
| 보조 역할 | 장갑 압박, 모듈 피해, 지속 화력 |
| 강한 거리 | 근거리 후반 ~ 중거리 |
| 약한 상황 | 극근거리 고속 선회전, 초장거리 저격전 |

---

### 5.3 조준 방식

| 조준 방식 | 적합도 | 설명 |
|---|---:|---|
| 고정 | 높음 | 운전 실력 기반 주력 무기 |
| 짐벌 | 높음 | 범용 전투 무기 |
| 터렛 | 중간 | 중형 차량 이상에 적합 |
| 락온 | 낮음 | 오토캐논 자체는 직접 사격이 맞음 |

---

### 5.4 전투 특성

| 요소 | 방향 |
|---|---|
| 피해량 | 중간 |
| 연사력 | 중간 |
| 각속도 | 중간 |
| 안정화 시간 | 중간 |
| 무기 열 | 중간 속도로 누적 |
| 탄약 중량 | 중간 |
| 탄 소모 | 중간 |
| 배터리 의존도 | 낮음 ~ 중간 |

---

### 5.5 강점

- 기관총보다 장갑 대응이 좋다.
- 대구경포보다 다루기 쉽다.
- 중거리 전투에서 가장 안정적이다.
- 탄종 선택의 의미를 주기 좋다.
- 고정, 짐벌, 터렛 방식을 모두 테스트할 수 있다.

---

### 5.6 약점

- 기관총보다 빠른 목표 대응이 느리다.
- 대구경포보다 순간 화력이 낮다.
- 계속 연사하면 무기 열 관리가 필요하다.
- 모든 상황에서 무난하지만, 특정 영역에서는 특화 무기에게 밀려야 한다.

---

### 5.7 설계 원칙

```text
오토캐논은 CarFight의 기준 무기다.
중거리에서 직접 조준, 탄종, 무기 열, 거리 관리가 모두 드러나야 한다.
```

P0에서는 전방 고정 오토캐논을 반드시 넣는다.

## 6. 대구경포

### 6.1 정의

대구경포는 느리지만 한 방이 강한 중장갑 대응 / 선제타격 / 공간 통제 무기다.

이 무기군의 핵심은 단순히 피해량이 높은 것이 아니다.

> 대구경포는 강한 대신 느려야 한다.

여기서 느리다는 것은 단순 연사력만 뜻하지 않는다.

```text
느린 회전
느린 안정화
느린 재장전
높은 무기 열
높은 탄약 중량
높은 장착 중량
```

---

### 6.2 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 중장갑 대응, 강한 한 방, 길목 장악 |
| 보조 역할 | 선제타격, 엄폐 사격 |
| 강한 거리 | 중거리 후반 ~ 장거리 |
| 약한 상황 | 초근거리, 빠른 측면 접근, 고속 선회전 |

---

### 6.3 조준 방식

| 조준 방식 | 적합도 | 설명 |
|---|---:|---|
| 고정 | 높음 | 차체 조준 기반 강한 한 방 |
| 짐벌 | 낮음 | 대구경 짐벌은 밸런스 위험 |
| 터렛 | 높음 | 단, 각속도를 느리게 해야 함 |
| 락온 | 낮음 | 대구경포 자체는 직접 사격이 어울림 |

---

### 6.4 전투 특성

| 요소 | 방향 |
|---|---|
| 피해량 | 높음 |
| 연사력 | 낮음 |
| 각속도 | 느림 |
| 안정화 시간 | 김 |
| 무기 열 | 한 발당 크게 증가 |
| 탄약 중량 | 높음 |
| 탄 소모 | 낮음 |
| 배터리 의존도 | 낮음 ~ 중간 |

---

### 6.5 강점

- 중장갑 차량에게 위협적이다.
- 정면 압박을 깨기 좋다.
- 길목을 장악하는 힘이 크다.
- 맞히면 전투 흐름을 바꿀 수 있다.
- 엄폐 후 노출 사격과 궁합이 좋다.

---

### 6.6 약점

- 빠른 차량이 근접하면 맞히기 어렵다.
- 포탑/무장부 각속도가 느리다.
- 조준 안정화 전 사격하면 정확도가 낮다.
- 탄약이 무겁고 적게 싣게 된다.
- 재장전/냉각 타이밍에 취약하다.

---

### 6.7 설계 원칙

```text
대구경포는 적을 쫓아다니며 맞히는 무기가 아니라,
미리 조준하고 공간을 통제하는 무기다.
```

P0에서는 대구경 저속 터렛포를 넣어 무기 각속도 시스템을 검증한다.

## 7. 산탄 무기

### 7.1 정의

산탄 무기는 초근거리에서 강한 근접 압박 / 측면 기습 / 마무리 무기다.

자동차 전투에서는 빠른 차량이 옆이나 뒤에 붙었을 때 큰 보상을 주는 무기군으로 쓸 수 있다.

---

### 7.2 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 초근거리 폭딜, 측후면 기습 |
| 보조 역할 | 바퀴/외부 모듈 파괴 |
| 강한 거리 | 초근거리 |
| 약한 상황 | 중거리 이상, 정면 중장갑 |

---

### 7.3 조준 방식

| 조준 방식 | 적합도 | 설명 |
|---|---:|---|
| 고정 | 높음 | 근접 돌진/교차 사격 |
| 짐벌 | 중간 | 너무 강해질 수 있어 제한 필요 |
| 터렛 | 중간 | 방어용 근접 터렛 가능 |
| 락온 | 없음 | 산탄과 맞지 않음 |

---

### 7.4 전투 특성

| 요소 | 방향 |
|---|---|
| 피해량 | 초근거리 높음 |
| 연사력 | 낮음 ~ 중간 |
| 각속도 | 방식에 따라 다름 |
| 안정화 시간 | 짧음 |
| 무기 열 | 낮음 ~ 중간 |
| 탄약 중량 | 중간 |
| 탄 소모 | 중간 |
| 배터리 의존도 | 낮음 |

---

### 7.5 강점

- 측면/후면을 잡았을 때 강하다.
- 빠른 차량의 근접 보상으로 좋다.
- 바퀴나 노출 모듈을 때리기 좋다.
- 초근거리에서 대구경 무기보다 실전성이 높다.

---

### 7.6 약점

- 거리가 조금만 벌어져도 효율이 크게 떨어진다.
- 정면 장갑에는 피해 효율이 낮아야 한다.
- 근접해야 하므로 충돌/피격 위험이 크다.
- 탄약을 많이 싣기 어렵게 만들 수 있다.

---

### 7.7 설계 원칙

```text
산탄 무기는 빠른 차량이 위험을 감수하고 붙었을 때 받는 보상이다.
멀리서도 강하면 안 된다.
```

P0에서는 제외하고, P1에서 근접 전투를 강화할 때 추가한다.

## 8. 로켓

### 8.1 정의

로켓은 직접 조준 또는 제한 보정으로 발사하는 비유도 폭발 무기다.

미사일과 다르게 로켓은 락온해서 따라가는 무기가 아니라, 플레이어가 직접 맞히거나 예측해서 쏘는 무기에 가깝다.

---

### 8.2 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 순간 폭발 피해, 지역 압박 |
| 보조 역할 | 엄폐 뒤 적 견제, 모듈/바퀴 피해 |
| 강한 거리 | 근거리 ~ 중거리 |
| 약한 상황 | 빠른 횡이동 목표, 장거리 정밀전 |

---

### 8.3 조준 방식

| 조준 방식 | 적합도 | 설명 |
|---|---:|---|
| 고정 | 높음 | 전방 로켓 포드 |
| 짐벌 | 중간 | 제한된 보정 가능 |
| 터렛 | 중간 | 중형 이상 플랫폼 |
| 락온 | 낮음 | 락온이 붙으면 미사일에 가까움 |

---

### 8.4 전투 특성

| 요소 | 방향 |
|---|---|
| 피해량 | 중간 ~ 높음 |
| 연사력 | 낮음 ~ 중간 |
| 각속도 | 발사대 방식에 따라 다름 |
| 안정화 시간 | 짧음 ~ 중간 |
| 무기 열 | 낮음 |
| 탄약 중량 | 중간 ~ 높음 |
| 탄 소모 | 낮음 ~ 중간 |
| 배터리 의존도 | 낮음 |

---

### 8.5 강점

- 직접 조준 보상이 크다.
- 폭발 피해로 근처 모듈을 압박할 수 있다.
- 직격이 아니어도 일부 효과를 줄 수 있다.
- 엄폐물 근처의 적을 압박하기 좋다.

---

### 8.6 약점

- 탄속이 느리면 예측 사격이 필요하다.
- 빠른 횡이동 목표에게 약하다.
- 탄약 중량 부담이 있다.
- 근접에서 자폭/충돌 위험을 둘 수 있다.

---

### 8.7 설계 원칙

```text
로켓은 락온 없는 폭발 화력이다.
맞히기는 어렵지만, 맞히거나 근처에 터뜨리면 전투 흐름을 흔들 수 있어야 한다.
```

---

## 9. 미사일

### 9.1 정의

미사일은 센서와 락온을 기반으로 하는 추격 / 이탈 방해 / 장거리 압박 무기다.

미사일은 누르면 알아서 맞는 확정 명중 무기가 되면 안 된다.

---

### 9.2 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 락온 압박, 추격, 도주 차단 |
| 보조 역할 | 장거리 견제, 전자전 탄두 운용 |
| 강한 거리 | 중거리 ~ 장거리 |
| 약한 상황 | 엄폐, 연막, 플레어, 전자전, 초근거리 난전 |

---

### 9.3 조준 방식

| 조준 방식 | 적합도 | 설명 |
|---|---:|---|
| 고정 | 낮음 | 발사 방향 제한 정도만 |
| 짐벌 | 낮음 | 직접 보정보다 락온 중심 |
| 터렛 | 중간 | 런처 회전각 정도는 가능 |
| 락온 | 매우 높음 | 미사일의 핵심 |

---

### 9.4 전투 특성

| 요소 | 방향 |
|---|---|
| 피해량 | 중간 ~ 높음 |
| 연사력 | 낮음 |
| 각속도 | 런처보다 미사일 자체 선회력 중요 |
| 안정화 시간 | 락온 시간으로 대체 |
| 무기 열 | 낮음 |
| 탄약 중량 | 높음 |
| 탄 소모 | 낮음 |
| 배터리 의존도 | 높음 |

---

### 9.5 강점

- 도망가는 적을 압박하기 좋다.
- 빠른 차량에게 회피 행동을 강요한다.
- 장거리에서 먼저 전투를 걸 수 있다.
- EMP/소이/고폭 등 탄두 변형이 가능하다.
- 싱글플레이에서 도주하거나 거리 유지하는 AI 목표를 압박하기 좋다.

---

### 9.6 약점

- 락온 시간이 필요하다.
- 배터리와 센서에 의존한다.
- 연막, 플레어, 재밍, 엄폐에 대응당한다.
- 탄약이 무거워 많이 싣기 어렵다.
- 초근거리에서는 사용하기 애매해야 한다.

---

### 9.7 설계 원칙

```text
미사일은 확정 명중 무기가 아니라,
상대에게 회피 / 방어 / 엄폐 / 전자전 선택을 강요하는 압박 무기다.
```

P0에서는 소형 락온 로켓 또는 경량 미사일 하나만 둔다.

---

## 10. 레일건 / 코일건

### 10.1 정의

레일건/코일건은 배터리 기반 보조 전력을 사용하는 고속 관통 정밀 무기다.

이 무기군은 우주선식 에너지빔이 아니라, 자동차에 장착한 전자기 가속 화기로 해석한다.

---

### 10.2 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 장거리 정밀 관통, 선제타격 |
| 보조 역할 | 모듈 관통, 장갑 약점 타격 |
| 강한 거리 | 장거리 |
| 약한 상황 | 근접 난전, 빠른 측면 접근, 배터리 부족 |

---

### 10.3 조준 방식

| 조준 방식 | 적합도 | 설명 |
|---|---:|---|
| 고정 | 높음 | 차체 장착 고화력 무기 |
| 짐벌 | 낮음 | 밸런스 위험 |
| 터렛 | 중간 | 매우 느린 각속도 필요 |
| 락온 | 낮음 | 직접 정밀 조준이 어울림 |

---

### 10.4 전투 특성

| 요소 | 방향 |
|---|---|
| 피해량 | 높음 |
| 연사력 | 낮음 |
| 각속도 | 느림 |
| 안정화 시간 | 김 |
| 무기 열 | 한 발당 높음 |
| 탄약 중량 | 중간 ~ 높음 |
| 배터리 의존도 | 높음 |
| 탄속 | 매우 빠름 |

---

### 10.5 강점

- 장거리에서 맞히기 좋다.
- 관통 피해 컨셉과 잘 맞는다.
- 장갑 약점 사격 보상이 크다.
- 숙련자용 정밀 무기로 좋다.

---

### 10.6 약점

- 배터리 부담이 크다.
- 발사 후 무기 열이 크게 증가한다.
- 근접 고속 차량에 취약하다.
- 조준 안정화가 필요하다.
- 탄약/장치 중량이 크다.

---

### 10.7 설계 원칙

```text
레일건/코일건은 배터리와 무기 열을 크게 쓰는 장거리 정밀 무기다.
자동차 아이덴티티를 지키기 위해 마법 같은 에너지빔이 아니라 전자기 화기로 다룬다.
```

P0에서는 제외하고, P1 또는 P2에서 추가한다.

---

## 11. EMP / 전자전 무기

### 11.1 정의

EMP/전자전 무기는 직접 피해보다 센서, 락온, 배터리, 터렛 안정화, 능동 방어를 방해하는 무기군이다.

이 무기군은 EVE Online식 전자전의 전략성을 참고하되, 자동차 기반 전장장비로 해석한다.

---

### 11.2 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 락온 방해, 배터리 압박, 센서 교란 |
| 보조 역할 | 터렛 안정화 방해, 방어장비 차단 |
| 강한 거리 | 중거리 |
| 약한 상황 | 순수 물리 화력전, 배터리 의존 낮은 적 |

---

### 11.3 형태

EMP/전자전은 반드시 총알일 필요는 없다.

| 형태 | 설명 |
|---|---|
| EMP 탄 | 명중 시 배터리/센서 교란 |
| EMP 미사일 | 락온 후 전자장비 방해 |
| 재밍 장치 | 주변 적 락온 방해 |
| 센서 교란기 | 적 UI/정보 품질 저하 |
| 터렛 안정화 방해 | 일정 시간 터렛 추적 성능 저하 |

---

### 11.4 전투 특성

| 요소 | 방향 |
|---|---|
| 직접 피해 | 낮음 |
| 전술 피해 | 높음 |
| 각속도 | 장착 방식에 따라 다름 |
| 무기 열 | 낮음 ~ 중간 |
| 탄약 중량 | 중간 |
| 배터리 의존도 | 높음 |
| 대응 장비 | 차폐, 예비 배터리, 재밍 저항 |

---

### 11.5 강점

- 락온/미사일 빌드 카운터로 쓸 수 있다.
- 배터리 의존 높은 차량을 압박한다.
- 터렛 안정화, 센서, 능동 방어를 약화할 수 있다.
- 직접 피해가 낮아도 전투 흐름을 크게 바꾼다.

---

### 11.6 약점

- 물리 화력 자체는 낮다.
- 고정 무기/순수 탄도 무기 중심 차량에는 효율이 낮다.
- UI/피드백 설계가 부족하면 불쾌해진다.
- P0에 넣으면 복잡도가 크게 증가한다.

---

### 11.7 설계 원칙

```text
EMP/전자전은 적을 바로 죽이는 무기가 아니라,
적이 의존하는 전자장비를 망가뜨려 전투 조건을 바꾸는 무기다.
```

P0에서는 제외하고, P1 이후에 락온/배터리 시스템이 자리 잡은 뒤 넣는다.

---

## 12. 방어 장비

### 12.1 정의

방어 장비는 직접 공격 무기는 아니지만, CarFight에서는 전투 장비로 분류한다.

미사일, 락온, 과열, 충돌, 전자전 같은 시스템을 만들면 반드시 대응 수단도 필요하다.

---

### 12.2 주요 방어 장비

| 장비 | 역할 |
|---|---|
| 연막 | 시야/락온 차단 |
| 플레어 | 열추적/미사일 방어 |
| 요격장치 | 일부 로켓/미사일 격추 |
| 냉각 장치 | 특정 무기 열 빠르게 감소 |
| 긴급 수리 장치 | 바퀴/엔진/터렛 임시 복구 |
| 차폐 장치 | EMP/전자전 저항 |
| 보조 배터리 | 전자장비 사용 시간 증가 |
| 장갑 키트 | 특정 방향 방어 강화 |

---

### 12.3 전투 특성

| 요소 | 방향 |
|---|---|
| 직접 피해 | 없음 |
| 배터리 의존도 | 중간 ~ 높음 |
| 중량 | 장비별로 다름 |
| 재사용 대기 | 필요 |
| 탄약/소모품 | 연막/플레어는 소모품 가능 |
| 피팅 슬롯 | 유틸리티/방어 슬롯 사용 |

---

### 12.4 설계 원칙

```text
방어 장비는 생존 버튼이 아니라,
상대 무기 타입에 대한 준비와 타이밍 판단이어야 한다.
```

미사일이 강하다면 반드시 연막/플레어/엄폐/전자전 같은 대응이 있어야 한다.

## 13. 지뢰 / 설치물

### 13.1 정의

지뢰와 설치물은 지역 통제 / 추격 차단 / 도주 경로 제어 무기군이다.

차량 전투와 궁합이 좋지만, 너무 빨리 넣으면 AI와 맵 설계 부담이 커진다.

---

### 13.2 주요 형태

| 장비 | 역할 |
|---|---|
| 대차량 지뢰 | 경로 차단, 바퀴/하부 피해 |
| 근접 폭발물 | 좁은 길목 통제 |
| 스파이크 스트립 | 타이어/접지 손상 |
| 센서 비콘 | 적 탐지/락온 보조 |
| 재밍 비콘 | 특정 지역 락온 방해 |
| 자동 방어 터렛 | 제한된 지역 화력 지원 |

---

### 13.3 전투 특성

| 요소 | 방향 |
|---|---|
| 직접 피해 | 장비별로 다름 |
| 강한 상황 | 추격전, 골목, 방어전 |
| 약한 상황 | 넓은 평지, 고속 우회 |
| 탄약 중량 | 중간 ~ 높음 |
| 배터리 의존도 | 비콘/터렛류는 있음 |
| 대응법 | 탐지, 회피, 제거, 속도 조절 |

---

### 13.4 설계 원칙

```text
설치물은 상대를 즉시 죽이는 함정이 아니라,
상대의 이동 선택지를 제한하는 지역 통제 수단이어야 한다.
```

P0에서는 제외하고, 맵 구조가 생긴 뒤 P1~P2에서 넣는다.

## 15. 무기군 간 상성

### 15.1 빠른 차량 대응

| 대응 무기 | 이유 |
|---|---|
| 기관총 | 빠른 각속도와 지속 사격 |
| 소형 짐벌 | 전방 제한각 안에서 빠른 보정 |
| 소형 터렛 | 근접 방어 |
| 락온 미사일 | 회피 행동 강요 |
| 지뢰/스파이크 | 이동 경로 제한 |

빠른 차량을 대구경포로 쉽게 맞히면 안 된다.

빠른 차량은 느린 무기의 각속도를 깨는 존재여야 한다.

### 15.2 중장갑 차량 대응

| 대응 무기 | 이유 |
|---|---|
| 대구경포 | 높은 관통/한 방 피해 |

| 철갑 오토캐논 | 지속 관통 압박 |
| 미사일 | 상부/후면 압박 가능 |
| EMP | 방어장비/터렛 안정화 방해 |

중장갑 차량은 기관총에 쉽게 녹으면 안 된다.

대신 측면/후면, 모듈, 전자장비, 이동 능력을 노리는 선택지가 있어야 한다.

---

### 15.3 락온/센서 빌드 대응

| 대응 수단 | 이유 |
|---|---|
| 연막 | 시야/락온 차단 |
| 플레어 | 미사일 방어 |
| 재밍 | 락온 품질 저하 |
| 엄폐 | 센서선 차단 |
| 고속 횡이동 | 락온 안정도 흔듦 |

락온 무기는 강하지만, 대응 수단이 명확해야 한다.

## 16. P0 무기 구성 제안

처음 전투 프로토타입에서는 아래 4개 무기와 대응 장비 1종을 우선 검증한다.

| 무기 | 조준 방식 | 역할 | 검증 목적 |
|---|---|---|---|
| 소형 짐벌 기관총 | 짐벌 | 빠른 목표 대응 | 각속도 빠른 무기의 감각 |
| 전방 고정 오토캐논 | 고정 | 중거리 주력 | 운전 실력 기반 조준 |
| 대구경 저속 터렛포 | 터렛 | 한 방/공간 통제 | 느린 각속도의 약점 |
| 경량 락온 미사일 | 락온 | 추격/압박 | 배터리/락온/대응 구조 |
| 연막 또는 플레어 | 방어 장비 | 미사일 대응 | 락온 무기 대응 가능성 |

이 구성은 CarFight의 핵심 조준 구조를 최소 범위로 검증한다.

```text
기관총 → 빠른 각속도
오토캐논 → 기준 직접 전투
대구경포 → 강하지만 느린 무기
미사일 → 락온 / 배터리 / 대응
```

---

## 17. P0에서 제외할 항목

| 제외 | 이유 |
|---|---|
| 산탄 무기 | 근접 밸런스와 차량 충돌 감각이 먼저 필요 |
| 레일건/코일건 | 배터리/열/관통 시스템이 자리 잡은 뒤 적합 |
| EMP/전자전 | UI와 피드백 없으면 불쾌해질 수 있음 |
| 방어장비 다종 | 미사일 대응용 최소 1종만 먼저 |
| 지뢰/설치물 | 맵 구조와 AI가 먼저 필요 |
| 수동 유도 무기 | 조작 부담과 UX 설계가 큼 |

## 18. 결정안

```text
CarFight Weapon Types v0.1

핵심 원칙:
무기는 피해량만으로 구분하지 않는다.
각 무기군은 거리, 조준 방식, 각속도, 무기 열, 탄약 중량,
배터리 의존도, 대응법을 함께 가진다.

무기군:
01. 기관총
- 빠른 각속도와 지속 화력으로 빠른 목표를 상대한다.
- 장갑 관통력은 낮다.

02. 오토캐논
- 중거리 기준 주력 화기다.
- 직접 조준, 탄종, 무기 열, 거리 관리가 모두 드러난다.

03. 대구경포
- 강한 한 방과 공간 통제 무기다.
- 느린 각속도, 긴 안정화, 높은 탄약 중량을 약점으로 가진다.

04. 산탄 무기
- 초근거리 측면/후면 기습 보상 무기다.
- 거리가 벌어지면 급격히 약해진다.

05. 로켓
- 락온 없는 폭발 화력이다.
- 맞히기 어렵지만 지역 압박과 모듈 피해에 강하다.

06. 미사일
- 락온 기반 추격/압박 무기다.
- 배터리, 센서, 탄약 중량을 요구하며 연막/플레어/엄폐로 대응 가능해야 한다.

07. 레일건 / 코일건
- 배터리와 무기 열을 쓰는 장거리 전자기 관통 무기다.
- 우주선식 에너지빔이 아니라 자동차 장착 전자기 화기로 다룬다.

08. EMP / 전자전 무기
- 직접 피해보다 센서, 락온, 배터리, 터렛 안정화를 방해한다.
- 락온/전자장비 의존 빌드에 강하다.

09. 방어 장비
- 연막, 플레어, 요격, 냉각, 긴급 수리, 차폐 등으로 대응 선택지를 만든다.

10. 지뢰 / 설치물
- 추격로와 교전 공간을 제한하는 지역 통제 수단이다.

P0 우선 구현:
01. 소형 짐벌 기관총
02. 전방 고정 오토캐논
03. 대구경 저속 터렛포
04. 경량 락온 미사일
05. 미사일 대응용 연막 또는 플레어 1종
```
