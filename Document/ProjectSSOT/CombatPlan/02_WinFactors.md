# 02. 전투 승패 요소

- 문서 버전: v0.3
- 작성일: 2026-06-08
- 최근 갱신일: 2026-06-08
- 문서 상태: Current
- 담당 범위: CarFight의 핵심 승패 요소 정의

---

## 1. 핵심 질문

CarFight에서 플레이어는 무엇을 잘해야 이기는가?

CarFight의 승패는 단순히 에임, 차량 속도, 무기 DPS 하나로 갈리면 안 된다. 전투 전 준비와 전투 중 조작/판단이 함께 작동해야 한다.

핵심 구조:

> 전투 전에 준비를 잘한 플레이어가 유리하게 시작하고, 전투 중 조작과 판단을 잘한 플레이어가 그 유리함을 승리로 확정한다.

---

## 2. 핵심 승패 요소 5개

```text
01. 피팅 / 출격 준비
02. 차량 기동
03. 거리 / 각도 / 속도 관리
04. 조준 / 사격 / 무기 추적 운용
05. 락온 / 센서 / 배터리 운용
```

보조 승패 요소:

```text
06. 탄종 / 탄수 / 중량 관리
07. 무기별 과열 관리
08. 장갑 방향 / 모듈 손상
09. 연료 / 작전 지속력
10. 지형 / 엄폐 / 충돌
11. 무기 각속도 / 조준 안정화
```

---

## 3. 피팅 / 출격 준비

전투 전에 차량을 어떻게 세팅했는가를 의미한다.

| 피팅 요소 | 전투 영향 |
|---|---|
| 차급 | 기본 중량, 속도, 슬롯, 장갑, 선회력 |
| 무기 | 사거리, 화력, 조준 방식, 무기 열 |
| 탄종 | 관통, 폭발, EMP, 소이, 산탄 등 |
| 탄수 | 지속 전투력, 중량 |
| 장갑 | 생존력, 중량, 기동성 저하 |
| 배터리 | 센서, 락온, 전자전, 능동 방어 |
| 연료 | 작전 지속력, 추격/이탈 여유 |
| 유틸리티 | 연막, 플레어, 냉각, 수리, 재밍 |
| 타이어/서스펜션 | 접지, 선회, 충돌 안정성 |

핵심 원칙:

> 무엇을 싣고 나가느냐가, 어떻게 싸울 수 있는지를 결정한다.

---

## 4. 차량 기동

차량을 얼마나 잘 몰아서 유리한 상황을 만드는가를 의미한다.

| 기동 요소 | 전투 의미 |
|---|---|
| 가속 | 교전 개시, 추격, 이탈 |
| 제동 | 거리 조절, 오버슈트 방지 |
| 선회 | 측면 잡기, 락온 회피 |
| 드리프트 | 빠른 방향 전환, 위험한 각도 확보 |
| 후진/저속 조작 | 근거리 교전 유지 |
| 충돌 | 적 자세 붕괴, 진로 차단 |
| 지형 주행 | 엄폐, 고저차, 접지 유지 |

핵심 원칙:

> 좋은 운전은 좋은 조준만큼 중요해야 한다.

---

## 5. 거리 / 각도 / 속도 관리

내 무기는 잘 맞고, 상대 무기는 잘 안 맞는 상태를 유지하는 능력이다.

| 요소 | 의미 |
|---|---|
| 거리 | 무기별 최적 사거리 |
| 각도 | 정면/측면/후면 장갑, 하드포인트 사각 |
| 속도 | 명중률, 추격, 이탈, 회피 |
| 상대 속도 | 리드샷 난이도, 락온 안정도 |
| 차체 방향 | 내 장갑 방향과 무기 발사각 |
| 상대 무기 각속도 | 상대 무장이 나를 따라올 수 있는지 |

수정된 핵심 원칙:

> 승자는 더 강한 총을 가진 사람이 아니라, 자기 무기가 강한 상황을 만들고 상대 무기의 사거리와 각속도 한계를 강요한 사람이어야 한다.

---

## 6. 조준 / 사격 / 무기 추적 운용

직접 조준, 무기 그룹, 사격 타이밍, 재장전, 무기별 과열, 무기 각속도, 조준 안정화 시간을 운용하는 능력이다.

| 조준 방식 | 승패 요소 |
|---|---|
| 고정 무기 | 차체 조준, 운전 실력 |
| 짐벌 무기 | 조준 보정 범위 유지 |
| 터렛 무기 | 발사각, 회전속도, 추적 안정성 |
| 락온 무기 | 락온 유지, 방해 대응 |
| 수동 유도 무기 | 발사 후 조작 집중 |

사격은 계속 누르고 있는 것이 정답이면 안 된다.

| 사격 판단 | 의미 |
|---|---|
| 점사 | 명중률 유지, 열 억제 |
| 연사 | 순간 압박, 과열 위험 |
| 차징 | 강한 한 방, 타이밍 노출 |
| 재장전 타이밍 | 엄폐/이탈 판단 |
| 탄종 전환 | 상대 방어에 맞춘 대응 |
| 무기 그룹 전환 | 거리/상황별 화력 운용 |

핵심 원칙:

> 사격은 조준 실력뿐 아니라, 언제 쏘고 언제 쉬는지의 판단이어야 한다.

---

## 7. 무기 각속도 / 조준 안정화

고정 무기가 아닌 모든 무기에는 각속도 개념이 존재한다.

각속도란 무기가 현재 바라보는 방향에서 목표 방향까지 얼마나 빨리 회전할 수 있는가를 의미한다.

| 무기 장착 방식 | 각속도 적용 여부 |
|---|---|
| 완전 고정 무기 | 없음 또는 차체 회전만 사용 |
| 제한 회전 무기 | 있음 |
| 짐벌 무기 | 있음 |
| 터렛 무기 | 있음 |
| 미사일 런처 | 발사 방향/락온 추적부에 적용 가능 |

필수 스탯 후보:

| 스탯 | 설명 |
|---|---|
| HorizontalTurnSpeed | 좌우 회전 속도 |
| VerticalTurnSpeed | 상하 회전 속도 |
| YawLimit | 좌우 조준 가능 각도 |
| PitchLimit | 상하 조준 가능 각도 |
| AimSettleTime | 목표 방향 도달 후 정확도가 안정되는 시간 |
| TrackingStability | 차량 흔들림/고속 주행 중 조준 유지력 |

핵심 원칙:

> 강한 한 방 무기일수록 각속도와 안정화가 느려야 한다.

---

## 8. 락온 / 센서 / 배터리 운용

적을 탐지하고, 락온을 유지하거나 방해하며, 배터리를 필요한 순간에 쓰는 능력이다.

### 8.1 센서

| 센서 정보 | 전투 영향 |
|---|---|
| 적 거리 | 사거리 판단 |
| 적 속도 | 리드샷/추격 판단 |
| 적 방향 | 장갑 방향 판단 |
| 락온 안정도 | 미사일/터렛/전자전 효율 |
| 모듈 상태 | 약점 공격 판단 |

### 8.2 배터리

| 배터리 사용처 | 예시 |
|---|---|
| 센서 강화 | 장거리 탐지, 약점 스캔 |
| 락온 유지 | 빠른 락온, 락온 저항 |
| 전자전 | 재밍, 교란, EMP 대응 |
| 능동 방어 | 플레어, 요격장치, 연막 시스템 |
| 터렛 안정화 | 회전 보조, 흔들림 감소 |
| 특수 무장 | 레일건, 코일건, EMP 계열 |

핵심 원칙:

> 배터리는 자동차 전투에서 센서, 락온, 방어장비, 전자전의 사용권을 결정하는 자원이다.

---

## 9. 보조 승패 요소

### 9.1 탄종 / 탄수 / 중량 관리

탄약은 인벤토리 숫자가 아니라 차량 성능을 바꾸는 피팅 요소다.

| 선택 | 장점 | 단점 |
|---|---|---|
| 탄을 많이 싣기 | 장기전 유리 | 중량 증가 |
| 탄을 적게 싣기 | 기동성 유지 | 장기전 불리 |
| 철갑탄 중심 | 장갑 대응 우수 | 무겁고 범용성 낮음 |
| 고폭탄 중심 | 모듈/범위 피해 | 장갑 관통 약함 |
| EMP탄 포함 | 전자장비 방해 | 직접 피해 약함 |

### 9.2 연료 / 작전 지속력

연료는 순간 스킬 자원이 아니라, 출격 범위와 지속 전투력을 결정하는 자원이다.

### 9.3 장갑 방향 / 모듈 손상

적을 반드시 폭파해야만 이기는 것이 아니라, 움직이지 못하게 만들거나 싸울 수 없게 만들어도 전투적 우위를 얻어야 한다.

### 9.4 지형 / 엄폐 / 충돌

전장은 배경이 아니라, 차량 전투의 일부여야 한다.

---

## 10. P0 검증 목표

```text
1. 같은 무기라도 거리와 각도에 따라 결과가 달라진다.
2. 차량을 잘 몰면 더 유리한 사격 위치를 만들 수 있다.
3. 탄약/장갑/연료를 많이 실으면 무거워져서 주행 성능이 변한다.
4. 무기를 계속 쏘면 해당 무기만 과열되어 잠시 쉬어야 한다.
5. 락온 또는 센서 보조는 강하지만 배터리 자원을 사용한다.
6. 상대 무기의 각속도 한계를 깨는 기동이 가능하다.
7. 플레이어는 전투 중 쏠지, 돌지, 빠질지, 식힐지를 계속 판단해야 한다.
```
