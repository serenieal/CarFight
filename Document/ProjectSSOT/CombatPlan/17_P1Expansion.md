---

## 1. 목적

이 문서는 P0 전투 프로토타입 검증 이후 확장할 P1 시스템 후보를 정의한다.

P1의 목표는 시스템을 무작정 늘리는 것이 아니다. P0에서 확인된 핵심 전투 감각을 유지하면서, 자동차 기반 전략성을 넓히는 것이다.

---

## 2. P1 확장 기준

P1 시스템은 아래 조건을 만족해야 한다.

```text
01. P0에서 검증된 전투 루프를 강화한다.
02. 자동차 정체성을 흐리지 않는다.
03. UI와 피드백을 제공할 수 있다.
04. AI가 최소한 사용할 수 있다.
05. 피팅 선택과 중량 비용이 명확하다.
```

---

## 3. 우선 확장 후보

| 후보 | 확장 이유 |
|---|---|
| 소이탄 | 연료 계통, 화재, 지속 압박 추가 |
| EMP탄 | 센서/락온/배터리 카운터 추가 |
| 재밍 장비 | 락온/센서 대응 확장 |
| 센서 타입 | 피팅 전략성 강화 |
| 냉각 장비 | 무기별 열 시스템 확장 |
| 긴급 수리 장비 | 모듈 손상 대응 추가 |
| 연료 계통 손상 | 자동차 정체성 강화 |
| 배터리 계통 손상 | 전자장비 의존 빌드 카운터 |
| 지뢰/설치물 | 추격/이탈/지역 통제 확장 |
| 수동 유도 무기 | 숙련자용 고위험 고보상 무기 |

---

## 4. 탄종 확장

## 4.1 소이탄

소이탄은 화재와 연료 계통 압박을 만드는 탄종이다.

| 역할 | 설명 |
|---|---|
| 화재 | 일정 시간 피해 또는 기능 저하 |
| 연료 계통 압박 | 연료 누출, 고출력 주행 제한 가능 |
| 외부 모듈 압박 | 노출 장비에 지속 피해 가능 |

소이탄은 차량 전체 과열이 아니다. 차량 전체 열 자원으로 다루지 않고, 화재/연료/모듈 상태이상으로 표현한다.

## 4.2 EMP탄

EMP탄은 직접 피해보다 전자장비를 방해한다.

| 대상 | 효과 |
|---|---|
| 센서 | 탐지/락온 정보 저하 |
| 배터리 | 출력 또는 회복 저하 |
| 터렛 안정화 | 안정화 시간 증가 |
| 능동 방어 | 연막/플레어/요격 사용 지연 |

---

## 5. 센서 / 전자전 확장

| 시스템 | 설명 |
|---|---|
| 장거리 센서 | 먼 거리 탐지/락온 유리 |
| 고속 추적 센서 | 빠른 목표 락온 안정도 증가 |
| 약점 스캐너 | 장갑 방향/모듈 정보 표시 |
| 재밍 장치 | 적 락온 속도와 안정도 저하 |
| 전자 차폐 | EMP/재밍 저항 |

전자전은 직접 피해가 낮아야 하며, 상대가 의존하는 시스템을 약하게 만드는 역할을 가져야 한다.

---

## 6. 모듈 손상 확장

P0 모듈은 바퀴, 엔진, 터렛이다. P1에서는 아래를 추가할 수 있다.

| 모듈 | 손상 효과 |
|---|---|
| 센서 | 탐지 거리 감소, 락온 시간 증가 |
| 배터리 계통 | 방어장비/락온/전자전 사용 제한 |
| 연료 계통 | 연료 누출, 화재 위험, 부스트 제한 |
| 냉각 계통 | 무기 냉각 속도 저하 |

---

## 7. 방어 / 유틸리티 확장

| 장비 | 역할 |
|---|---|
| 냉각 장치 | 특정 무기 열 빠르게 감소 |
| 긴급 수리 | 바퀴/엔진/터렛 임시 복구 |
| 요격장치 | 일부 로켓/미사일 격추 |
| 전자 차폐 | EMP/재밍 저항 |
| 보조 배터리 | 전자장비 운용 시간 증가 |
| 장갑 키트 | 특정 방향 또는 모듈 보호 강화 |

---

## 8. 무기 확장

| 무기 | 도입 이유 |
|---|---|
| 산탄 무기 | 초근거리 측후면 기습 보상 |
| 로켓 | 비유도 폭발 화력과 모듈 압박 |
| 레일건/코일건 | 장거리 정밀 관통과 배터리 운용 |
| 수동 유도 무기 | 숙련자용 특수 조작 무기 |
| 지뢰/스파이크 | 지역 통제와 추격 차단 |

각 무기는 반드시 대응법과 중량 비용을 같이 가져야 한다.

---

## 9. P1에서 피해야 할 확장

| 피해야 할 것 | 이유 |
|---|---|
| 무기 수만 과도하게 늘리기 | 역할 중복 발생 |
| 대응 없는 전자전 | 불쾌감 증가 |
| 자동 명중 미사일 강화 | 직접 조준과 차량 기동 약화 |
| 지나치게 복잡한 센서 UI | 정보 과부하 |
| 중량 비용 없는 강력 장비 | 피팅 전략 붕괴 |

---

## 10. P1 우선순위 제안

```text
01. 냉각 장비
02. 긴급 수리 장비
03. 센서 손상 / 센서 타입
04. EMP탄 / 재밍 장비
05. 연료 계통 손상 / 소이탄
06. 산탄 무기 / 로켓
07. 지뢰 / 설치물
08. 수동 유도 무기
09. 레일건 / 코일건
```

이 순서는 P0 결과에 따라 바뀔 수 있다. P0에서 가장 재미있었던 축을 먼저 확장한다.

---

## 11. 핵심 원칙

```text
01. P1은 P0를 대체하지 않고 확장한다.
02. 새 시스템은 반드시 피팅 비용과 대응 수단을 가진다.
03. 자동차 정체성은 계속 유지한다.
04. 전자전과 상태이상은 UI 피드백이 준비된 뒤 넣는다.
05. 역할이 겹치는 무기보다 새로운 전투 판단을 만드는 시스템을 우선한다.
```
