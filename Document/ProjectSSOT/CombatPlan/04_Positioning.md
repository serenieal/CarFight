## 1. 목적

이 문서는 CarFight에서 차량 기동, 거리, 각도, 속도, 장갑 방향, 무기 각속도가 어떻게 맞물려 전투의 유불리를 만드는지 정의한다.

핵심 정의:

> CarFight에서 좋은 운전은 단순히 빠르게 달리는 것이 아니라, 내 무기는 맞히기 쉽고 상대 무기는 맞히기 어렵게 만드는 위치를 계속 만드는 것이다.

즉, 차량 기동은 단순 이동 조작이 아니라 전투 판정의 중심축이다.

## 3. 좋은 위치의 정의

CarFight에서 좋은 위치는 단순히 적 뒤에 있는 상태가 아니다.

좋은 위치 v0.1:

> 내 무기는 최적 조건으로 쏠 수 있고, 상대 무기는 사거리·각도·각속도·장갑 방향·지형 때문에 불리해지는 위치.

좋은 위치는 아래 조건을 많이 만족할수록 강하다.

| 조건 | 의미 |
|---|---|
| 내 무기 최적 거리 | 내 무기의 피해/명중/추적 성능이 좋은 거리 |
| 상대 무기 비효율 거리 | 상대 무기가 너무 멀거나 너무 가까워 제 성능을 못 냄 |
| 상대 약점 장갑 방향 | 측면, 후면, 상부, 하부 등을 노출시킴 |
| 내 강한 장갑 방향 | 내 정면 장갑이나 보강된 방향을 상대에게 보여줌 |
| 상대 무기 각속도 초과 | 상대 무장이 나를 따라오지 못함 |
| 내 이탈 경로 확보 | 불리할 때 빠질 수 있음 |
| 엄폐/지형 활용 | 재장전, 냉각, 락온 차단 가능 |
| 충돌/진로 통제 | 상대 이동 방향을 제한함 |

핵심 문장:

```text
좋은 위치 = 내 무기 효율은 높이고, 상대 무기 효율은 낮추는 위치
```

## 4. 거리 구간 설계

거리 구간은 현실 단위에 먼저 묶기보다 게임플레이 역할로 나눈다.

P0 기준 임시 거리 구간은 아래처럼 잡는다.

| 구간 | 임시 거리 | 전투 의미 | 유리한 무기 |
|---|---:|---|---|
| 초근거리 | 0 ~ 15m | 충돌, 난전, 후방/측면 붙기 | 산탄, 화염, 기관총 |
| 근거리 | 15 ~ 50m | 빠른 선회전, 각속도 싸움 | 기관총, 산탄, 소형 짐벌 |
| 중거리 | 50 ~ 150m | 주력 교전 거리 | 오토캐논, 짐벌포, 로켓 |
| 장거리 | 150 ~ 350m | 선제타격, 락온, 저격 | 대구경포, 레일건, 미사일 |
| 초장거리 | 350m 이상 | 특수 상황, 정찰/저격 | 고성능 센서, 장거리 미사일 |

이 수치는 P0 테스트용 임시 기준이다. 실제 맵 크기, 차량 최고속도, 카메라 FOV, 무기 탄속이 정해지면 조정한다.

## 5. 거리별 전투 감각

### 5.1 초근거리

초근거리는 빠른 차량이 무거운 차량의 대구경 무기 각속도를 깨는 거리다.

특징:

- 충돌 위험이 높다.
- 터렛/짐벌이 목표를 따라가기 어렵다.
- 산탄/기관총이 유리하다.
- 대구경포, 레일건은 불리하다.
- 운전 실수 시 벽이나 차량에 박기 쉽다.

### 5.2 근거리

근거리는 차량 선회와 무기 각속도의 싸움이 가장 강하게 드러나는 거리다.

특징:

- 빠른 차량이 강하다.
- 측면/후면 장갑 공격이 쉬워진다.
- 고정 무기는 차체 조준 실력이 중요하다.
- 짐벌/소형 터렛의 가치가 높다.
- 무거운 포탑은 불리하다.

### 5.3 중거리

중거리는 CarFight의 기본 교전 거리다.

특징:

- 대부분의 무기가 작동 가능하다.
- 거리 유지와 탄종 선택이 중요하다.
- 조준 실력과 차량 기동이 모두 반영된다.
- 무기별 역할 차이가 가장 잘 보인다.
- P0 테스트의 중심 거리로 적합하다.

### 5.4 장거리

장거리는 준비, 센서, 락온, 선제타격의 거리다.

특징:

- 센서/락온이 중요하다.
- 탄속과 리드샷이 중요하다.
- 대구경포/레일건/미사일이 유리하다.
- 빠른 차량은 엄폐와 접근 루트가 중요하다.
- 장거리 무기가 너무 강하면 근거리 전투가 죽으므로 제약이 필요하다.

## 6. 각도 설계

자동차 전투의 장점은 장갑 방향이 직관적이라는 점이다.

장갑 방향 v0.1:

| 방향 | 기본 의미 | 전투 역할 |
|---|---|---|
| 정면 | 가장 튼튼함 | 버티기, 압박, 돌파 |
| 측면 | 중간 약점 | 선회전에서 자주 노출 |
| 후면 | 큰 약점 | 엔진/연료 계통 위험 |
| 상부 | 특수 약점 | 고각탄, 폭발, 드론, 낙하 공격 |
| 하부 | 특수 약점 | 지뢰, 충돌, 지형 피해 |

## 7. P0 임시 피해 계수

초기 테스트용으로는 너무 복잡하게 가지 않는다.

| 피격 방향 | 피해 계수 초안 |
|---|---:|
| 정면 | 1.0x |
| 측면 | 1.2x |
| 후면 | 1.5x |
| 상부 | 1.3x |
| 하부 | 1.6x |

이 수치는 최종 밸런스가 아니라 플레이 감각 검증용이다.

목표 감각:

> 정면으로 맞으면 버틸 만한데, 후면을 잡히면 확실히 위험하다.

## 8. 속도 설계

CarFight에서 속도는 단순 회피율이 아니다.

속도는 아래 4가지를 동시에 바꾼다.

```text
01. 내 조준 안정성
02. 상대가 나를 맞히기 어려운 정도
03. 락온 안정도
04. 거리/각도 주도권
```

속도 상태별 전투 의미:

| 속도 상태 | 장점 | 단점 |
|---|---|---|
| 정지 | 조준 안정성 최고 | 맞기 쉬움, 락온당하기 쉬움 |
| 저속 | 정밀 조준, 선회 안정 | 회피 약함 |
| 중속 | 가장 균형적 | 특화 장점은 약함 |
| 고속 | 회피, 추격, 이탈 | 조준 흔들림, 선회 어려움 |
| 과속/부스트 | 순간 돌파, 도주 | 연료 소모, 제어 불안정 |

---

## 9. 상대 횡방향 속도

CarFight에서 중요한 것은 단순 절대 속도보다 상대가 내 조준 기준으로 얼마나 빠르게 좌우로 지나가는가다.

이를 전투적으로는 상대 횡방향 속도로 본다.

| 상대 움직임 | 맞히기 난이도 |
|---|---|
| 나에게 정면으로 달려옴 | 상대적으로 쉬움 |
| 나에게서 멀어짐 | 상대적으로 쉬움 |
| 내 앞을 좌우로 빠르게 지나감 | 어려움 |
| 내 주변을 원형으로 돎 | 매우 어려움 |

이 개념은 무기 각속도와 직접 연결된다.

핵심 원칙:

> 빠르다는 것은 단순히 속도가 높다는 뜻이 아니라, 상대 무기가 따라야 하는 각도를 빠르게 바꾼다는 뜻이다.

## 10. 무기 각속도와 차량 기동

고정 무기가 아닌 모든 무기에는 각속도가 있다.

무기 각속도 원칙:

```text
고정 무기가 아닌 모든 무기에는 각속도가 있다.
강한 한 방 무기일수록 각속도와 조준 안정화가 느리다.
빠른 차량은 상대 무기의 각속도 한계를 넘는 방식으로 생존할 수 있다.
```

조준 방식별 기동 관계:

| 무기 방식 | 조준 기준 | 차량 기동과의 관계 |
|---|---|---|
| 고정 무기 | 차체 방향 | 차량 선회력이 곧 조준력 |
| 짐벌 무기 | 전방 제한각 | 차체를 대략 맞추면 무기가 보정 |
| 터렛 무기 | 포탑 회전 | 차체 방향과 별개지만 각속도 제한 |
| 락온 무기 | 센서/락온 유지 | 목표가 추적각을 벗어나면 불안정 |
| 수동 유도 | 발사 후 조작 | 운전과 조준 집중이 충돌 |

무기 각속도와 상대 기동의 관계:

```text
상대가 요구하는 추적 속도 > 내 무기의 각속도
= 무기가 상대를 따라가지 못함
```

예시:

| 상황 | 결과 |
|---|---|
| 빠른 경량 차량이 대구경 터렛 옆에 붙음 | 터렛이 못 따라감 |
| 느린 중장갑 차량이 정면에서 다가옴 | 대구경포가 맞히기 쉬움 |
| 빠른 차량이 멀리서 직선으로 달려옴 | 각속도 부담은 낮음 |
| 빠른 차량이 근거리에서 측면 선회 | 각속도 부담이 매우 높음 |

## 11. 차량 선회력과 무기 운용

차량 선회력은 무기 선택과 직접 연결된다.

### 11.1 고정 무기 차량

고정 무기는 차체가 곧 조준선이다.

| 차량 특성 | 결과 |
|---|---|
| 선회력 좋음 | 고정 무기 운용 쉬움 |
| 선회력 낮음 | 고정 무기 운용 어려움 |
| 고속 안정성 좋음 | 교차 사격에 유리 |
| 제동력 좋음 | 오버슈트 방지 |

고정 무기에 적합한 플레이:

- 정면 돌파
- 고속 교차 사격
- 차체를 돌려 한 방 넣기
- 운전 실력 기반 조준

### 11.2 짐벌 무기 차량

짐벌 무기는 차체 방향이 완벽하지 않아도 보정된다.

| 차량 특성 | 결과 |
|---|---|
| 중간 선회력 | 안정적으로 운용 가능 |
| 빠른 목표 대응 | 고정 무기보다 쉬움 |
| 화력 | 고정 무기보다 낮게 잡는 것이 좋음 |
| 조준 보정각 | 넓을수록 편하지만 밸런스 위험 |

짐벌 무기는 P0에서 가장 테스트하기 좋은 무기 방식이다.

### 11.3 터렛 무기 차량

터렛은 차체 방향과 무기 방향이 독립적이다.
대신 무기 각속도와 안정화가 핵심 약점이다.

| 차량 특성 | 결과 |
|---|---|
| 무거운 차량 | 터렛 플랫폼으로 적합 |
| 느린 차량 | 정면 장갑과 포탑으로 버팀 |
| 빠른 차량 | 소형 터렛/방어 터렛에 적합 |
| 대구경 터렛 | 위치 선점이 중요 |

핵심 원칙:

> 터렛은 자유롭게 쏘는 무기가 아니라, 차체 방향 의존도를 줄이는 대신 각속도와 안정화 제한을 받는 무기다.

## 12. 차급별 전투 방식

### 12.1 경량 차량

예시 차급:

- Microcar
- City Car
- Subcompact

| 강점 | 약점 |
|---|---|
| 가속 좋음 | 장갑 약함 |
| 선회 좋음 | 충돌에 약함 |
| 각속도 싸움에 강함 | 대구경 한 방에 취약 |
| 이탈 쉬움 | 장기전 탄약/연료 제한 |

전투 방식:

```text
붙고
측면/후면을 잡고
상대 무기 각속도를 깨고
짧게 때리고
다시 빠진다
```

경량 차량은 피해를 버티는 것이 아니라 상대가 못 맞히게 만들어야 한다.

### 12.2 중형 차량

예시 차급:

- Compact
- Sedan
- Wagon

| 강점 | 약점 |
|---|---|
| 밸런스 좋음 | 특화 차량에게 한 분야에서 밀림 |
| 무기 선택 폭 넓음 | 세팅 방향이 애매하면 약함 |
| 중거리 교전 강함 | 극근거리/극장거리 대응은 피팅 의존 |
| 여러 AI 역할 대응력 좋음 | 실수 보정은 낮음 |

전투 방식:

```text
중거리 유지
상황 따라 접근/이탈
탄종과 무기 그룹 전환
상대 약점 방향을 계속 압박
```

중형 차량은 CarFight의 기준점이다.

### 12.3 중량 차량

예시 차급:

- SUV
- Van
- Pickup
- Armored Sedan

| 강점 | 약점 |
|---|---|
| 장갑 좋음 | 둔함 |
| 대구경 무기 운용 가능 | 빠른 적에게 약함 |
| 충돌/진로 통제 강함 | 이탈 어려움 |
| 지속전 강함 | 연료/중량 부담 큼 |

전투 방식:

```text
좋은 위치를 먼저 잡고
정면 장갑을 세우고
길목을 통제하고
강한 한 방으로 압박한다
```

중량 차량은 빠른 적을 쫓아다니면 안 된다. 대신 상대가 들어와야 하는 공간을 장악해야 한다.

## 13. 대표 전투 패턴

### 13.1 빠른 차량의 측면 파고들기

```text
중거리 접근
→ 상대 대구경 무기 방향 확인
→ 급가속으로 측면 진입
→ 상대 터렛 각속도 초과
→ 측면/후면 사격
→ 과열 전 이탈
```

승리 조건:

- 내 속도와 선회력이 상대 각속도보다 우위
- 상대 후면/측면 장갑 노출
- 내 무기가 근거리 대응에 적합

### 13.2 중장갑 차량의 정면 압박

```text
장거리 또는 중거리에서 위치 선점
→ 정면 장갑을 상대에게 향함
→ 대구경 무기를 미리 조준
→ 상대 접근 경로 통제
→ 맞히면 큰 피해
→ 근접당하면 보조무기/충돌/후퇴
```

승리 조건:

- 상대 접근 방향 예측
- 대구경 무기 사전 조준
- 측면 노출 최소화
- 근접 대응 보조 수단 확보

### 13.3 중거리 거리 유지 전투

중거리 거리 유지 전투는 내 유리한 거리만 유지하면서 상대를 소모시키는 전투 방식이다.

```text
중거리 유지
→ 상대가 붙으면 후퇴
→ 상대가 빠지면 압박
→ 오토캐논/미사일/짐벌로 지속 피해
→ 상대 배터리/연료/탄약 소모 유도
```

승리 조건:

- 속도 차이를 이용한 거리 유지
- 중거리 무기 효율
- 락온/센서 우위
- 무기 열과 탄약 관리

### 13.4 엄폐 재조준 전투

```text
엄폐 뒤 대기
→ 조준/락온 준비
→ 짧게 노출
→ 강한 한 방 사격
→ 다시 엄폐
→ 무기 냉각/재장전
```

승리 조건:

- 지형 활용
- 대구경/레일건/미사일과 궁합 좋음
- 상대 락온 차단
- 사격 타이밍 중요

## 14. 속도와 락온 안정도

락온은 속도 자체보다 상대 움직임의 변화량에 영향을 받아야 한다.

락온 안정도를 흔드는 요소:

| 요소 | 락온 영향 |
|---|---|
| 빠른 횡방향 이동 | 락온 안정도 감소 |
| 급가속/급제동 | 락온 흔들림 |
| 엄폐물 통과 | 락온 끊김 |
| 연막/전자전 | 락온 저하 |
| 거리 증가 | 락온 시간 증가 |
| 배터리 부족 | 락온 유지력 감소 |
| 센서 강화 사용 | 락온 안정도 증가 |

핵심 원칙:

> 빠른 차량은 단순히 자동 회피율을 얻는 것이 아니라, 상대의 락온과 무기 추적을 불안정하게 만들어야 한다.

## 15. P0 기준 단순화 모델

처음부터 복잡하게 구현하지 않는다. P0에서는 아래 정도만 검증한다.

### 15.1 P0 최소 변수

| 변수 | 용도 |
|---|---|
| 거리 | 무기 피해/명중률 보정 |
| 피격 방향 | 정면/측면/후면 피해 계수 |
| 차량 속도 | 조준 안정성/락온 안정도 보정 |
| 상대 횡방향 속도 | 무기 추적 난이도 |
| 무기 각속도 | 목표를 따라갈 수 있는지 판단 |
| 무기 안정화 시간 | 조준 후 바로 정확한지 결정 |
| 차량 중량 | 가속/제동/선회에 영향 |

### 15.2 P0 판정 흐름 예시

```text
01. 목표와의 거리 확인
02. 목표의 피격 방향 확인
03. 목표의 횡방향 속도 확인
04. 내 무기의 각속도로 따라갈 수 있는지 확인
05. 내 차량 속도에 따른 조준 안정성 확인
06. 사격 시 탄종/장갑 방향/거리 보정 적용
07. 무기 열 증가
08. 탄약 감소
```

## 16. P0 임시 수치 방향

정확한 밸런스가 아니라 테스트 출발점이다.

### 16.1 차량 속도와 조준 안정성

| 내 속도 상태 | 조준 안정성 |
|---|---:|
| 정지 | 100% |
| 저속 | 95% |
| 중속 | 85% |
| 고속 | 70% |
| 부스트 | 55% |

고정 무기는 차체 방향 조준이므로 차량 흔들림 영향을 더 크게 받는다. 짐벌/터렛은 안정화 장비나 배터리 보조로 일부 보정할 수 있다.

### 16.2 목표 횡방향 속도와 추적 난이도

| 목표 횡방향 움직임 | 추적 난이도 |
|---|---|
| 낮음 | 쉬움 |
| 중간 | 보통 |
| 높음 | 어려움 |
| 매우 높음 | 무기 각속도 낮으면 추적 실패 |

여기서 중요한 것은 속도 수치보다 내 조준 기준으로 얼마나 빠르게 각도가 바뀌는가다.

### 16.3 무기 크기별 각속도 방향

| 무기 크기 | 각속도 | 안정화 | 피해 |
|---|---:|---:|---:|
| 소구경 | 빠름 | 빠름 | 낮음 |
| 중구경 | 보통 | 보통 | 보통 |
| 대구경 | 느림 | 느림 | 높음 |

이 구조는 반드시 유지한다.

## 17. 결정안

```text
CarFight Vehicle Positioning v0.1

핵심 정의:
좋은 위치란 내 무기는 최적 조건으로 쏠 수 있고,
상대 무기는 사거리·각도·각속도·장갑 방향·지형 때문에
제 성능을 내기 어려운 위치다.

거리 구간:
- 초근거리: 충돌, 산탄, 기관총, 각속도 붕괴
- 근거리: 선회전, 측면/후면 압박
- 중거리: 주력 교전 거리
- 장거리: 센서, 락온, 선제타격
- 초장거리: 특수 저격/정찰 영역

각도 원칙:
- 정면은 가장 튼튼하다.
- 측면은 전술적 약점이다.
- 후면은 엔진/연료 계통이 있는 큰 약점이다.
- 상부/하부는 특수 무기와 지형 피해에 취약하다.

속도 원칙:
- 고속은 생존과 위치 선점에 유리하지만 조준 안정성을 낮춘다.
- 저속/정지는 조준에 유리하지만 피격과 락온에 취약하다.
- 중요한 것은 절대 속도보다 상대 기준 횡방향 속도다.

무기 각속도 원칙:
- 고정 무기는 차량 선회력이 곧 조준력이다.
- 짐벌/터렛/락온 무기는 각속도와 추적각을 가진다.
- 대구경 고화력 무기는 각속도와 안정화가 느려야 한다.
- 빠른 차량은 상대 무기의 각속도 한계를 넘는 방식으로 생존한다.

차량 역할 원칙:
- 경량 차량은 맞지 않는 위치를 만든다.
- 중형 차량은 거리와 상황을 조절한다.
- 중량 차량은 공간을 장악하고 정면으로 압박한다.
```
