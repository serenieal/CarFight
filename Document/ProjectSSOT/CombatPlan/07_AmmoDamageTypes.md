# 07. 탄종과 피해 타입

- 문서 버전: v0.2
- 작성일: 2026-06-08
- 최근 갱신일: 2026-06-08
- 문서 상태: Current
- 담당 범위: 탄종 / 피해 타입 / 탄수 / 적재 중량 규칙 정의

---

## 1. 핵심 정의

탄종은 단순히 피해량을 바꾸는 옵션이 아니라, 차량 중량·장갑 대응·모듈 손상·전투 지속력·출격 전략을 바꾸는 피팅 요소다.

CarFight에서 탄약은 단순한 총알 개수가 아니라, 차량에 싣고 나가는 전투 자원이다. 따라서 탄종과 탄수는 반드시 다음 요소와 연결되어야 한다.

- 중량
- 차량 성능
- 교전 거리
- 대상 장갑
- 모듈 손상
- 출격 준비

핵심 원칙:

```text
탄을 많이 싣는 것은 전투 지속력을 얻는 대신,
차량 기동성을 지불하는 선택이다.
```

---

## 2. 피해 타입과 탄종의 구분

피해 타입과 탄종은 서로 다른 개념이다.

| 구분 | 의미 | 예시 |
|---|---|---|
| 피해 타입 | 피해가 어떤 방식으로 들어가는가 | 물리, 관통, 폭발, 전자 |
| 탄종 | 플레이어가 싣고 나가는 탄약 종류 | 일반탄, 철갑탄, 고폭탄, 소이탄, EMP탄 |

예를 들어 철갑탄은 탄종이고, 그 결과로 관통 피해 비중이 높은 탄이다. 고폭탄은 탄종이고, 그 결과로 폭발 피해와 모듈 피해 비중이 높은 탄이다.

---

## 3. 피해 타입 v0.1

초기에는 피해 타입을 너무 많이 나누지 않는다. P0~P1 기준으로는 아래 4개를 기본 후보로 둔다.

| 피해 타입 | 역할 | 강한 대상 | 약한 대상 |
|---|---|---|---|
| 물리 피해 | 기본 차체 피해 | 일반 장갑, 노출 부위 | 중장갑 정면 |
| 관통 피해 | 장갑을 뚫는 피해 | 중장갑, 정면 장갑 | 경량 목표, 외부 모듈 |
| 폭발 피해 | 범위와 모듈 피해 | 바퀴, 센서, 터렛, 하부/상부 | 두꺼운 정면 장갑 |
| 전자 피해 | 센서/배터리/락온 방해 | 전자장비 의존 차량 | 순수 물리 화력 차량 |

P0에서는 물리, 관통, 폭발 3개만 먼저 사용한다. 전자 피해는 EMP/전자전이 들어가는 P1 이후로 미룬다.

---

## 4. 탄종 v0.1

CarFight의 탄종은 아래 5개를 기본 후보로 둔다.

```text
01. 일반탄
02. 철갑탄
03. 고폭탄
04. 소이탄
05. EMP탄
```

P0에서는 일반탄, 철갑탄, 고폭탄 3개만 사용한다.

---

## 5. 일반탄

### 정의

일반탄은 가장 기본적인 탄이다.

```text
가볍고, 범용적이지만 특화 성능은 낮은 탄종
```

### 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 기본 교전 |
| 피해 타입 | 물리 피해 중심 |
| 장갑 대응 | 보통 |
| 모듈 피해 | 보통 |
| 탄약 중량 | 낮음 |
| 탄수 확보 | 쉬움 |
| 추천 무기 | 기관총, 오토캐논 |

### 강점

- 가장 가벼운 편이다.
- 많이 싣기 쉽다.
- 장기전에 유리하다.
- 어떤 상황에서도 완전히 무력하지 않다.
- P0 기준 기본 비교군으로 적합하다.

### 약점

- 중장갑 정면 대응이 약하다.
- 모듈 파괴에 특화되어 있지 않다.
- 폭발 범위가 없다.
- 전술적 개성이 약하다.

### 설계 원칙

```text
일반탄은 기준 탄종이다.
가볍고 안정적이지만,
특정 방어를 뚫거나 모듈을 부수는 데 특화되지는 않는다.
```

---

## 6. 철갑탄

### 정의

철갑탄은 장갑 관통에 특화된 탄이다.

```text
무겁고 비싸지만,
정면 장갑이나 중장갑 차량을 상대할 때 강한 탄종
```

### 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 장갑 관통 |
| 피해 타입 | 관통 피해 중심 |
| 장갑 대응 | 강함 |
| 모듈 피해 | 낮음~중간 |
| 탄약 중량 | 높음 |
| 탄수 확보 | 어려움 |
| 추천 무기 | 오토캐논, 대구경포, 레일건/코일건 |

### 강점

- 중장갑 차량 대응에 강하다.
- 정면 장갑을 상대할 수 있다.
- 대구경포와 궁합이 좋다.
- 장갑 방향 시스템을 의미 있게 만든다.

### 약점

- 탄이 무거워 많이 싣기 부담스럽다.
- 경량 차량 상대로 과투자일 수 있다.
- 범위 피해가 없다.
- 바퀴/센서 같은 외부 모듈에는 고폭탄보다 덜 적합하다.

### 설계 원칙

```text
철갑탄은 중장갑 대응 선택지다.
강하지만 무겁고,
모든 상황에서 정답이면 안 된다.
```

철갑탄을 많이 싣는다는 것은 다음 의미를 가진다.

```text
나는 중장갑 차량을 상대할 준비를 했다.
대신 차량이 무거워지고,
장기전과 기동전에서 부담을 진다.
```

## 7. 고폭탄

### 정의

고폭탄은 폭발 피해와 모듈 손상에 특화된 탄이다.

```text
직격 피해보다 범위 피해,
바퀴/센서/터렛/하부 손상,
엄폐물 주변 압박에 강한 탄종
```

### 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 모듈 피해, 범위 압박 |
| 피해 타입 | 폭발 피해 중심 |
| 장갑 대응 | 약함~보통 |
| 모듈 피해 | 강함 |
| 탄약 중량 | 중간~높음 |
| 탄수 확보 | 보통~어려움 |
| 추천 무기 | 대구경포, 로켓, 미사일, 일부 오토캐논 |

### 강점

- 바퀴, 센서, 터렛 등 외부 모듈 압박에 강하다.
- 근처 폭발로 엄폐 뒤 적을 압박할 수 있다.
- 빠른 차량의 이동 능력을 깎는 데 좋다.
- 상부/하부 취약점과 연결하기 좋다.
- 미사일/로켓과 궁합이 좋다.

### 약점

- 두꺼운 정면 장갑 관통은 약하다.
- 탄약이 무겁거나 부피가 클 수 있다.
- 근접에서 자폭 위험을 둘 수 있다.
- 순수 차체 피해량은 철갑탄보다 낮아야 한다.

### 설계 원칙

```text
고폭탄은 차체를 뚫는 탄이 아니라,
차량의 기능을 무너뜨리는 탄이다.
```

고폭탄은 체력바를 빨리 깎는 탄이라기보다 아래 역할에 강해야 한다.

- 바퀴 손상
- 센서 손상
- 터렛 안정화 저하
- 엔진/하부 피해
- 엄폐 뒤 압박

## 8. 소이탄

### 정의

소이탄은 화재와 지속 피해에 특화된 탄이다.

```text
차량을 바로 터뜨리기보다는
연료 계통, 외부 장비, 지속 압박에 영향을 주는 탄종
```

### 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 화재, 지속 피해, 연료 계통 압박 |
| 피해 타입 | 열/화재 피해 |
| 장갑 대응 | 낮음 |
| 모듈 피해 | 중간 |
| 탄약 중량 | 중간 |
| 탄수 확보 | 보통 |
| 추천 무기 | 기관총, 산탄, 로켓, 특수 미사일 |

### 강점

- 연료 계통 손상과 연결 가능하다.
- 엄폐 중인 적에게 지속 압박을 줄 수 있다.
- 경량 차량/노출 모듈에 효과적이다.
- 장기전에서 불안정성을 만든다.

### 약점

- 중장갑 정면에는 약하다.
- UI/상태이상 피드백이 필요하다.
- 너무 강하면 불쾌한 지속 피해가 된다.
- P0에 넣기에는 상태 시스템 부담이 크다.

### 설계 원칙

```text
소이탄은 P1 이후 상태이상 탄종으로 둔다.
차량 전체 과열이 아니라,
화재/연료/외부 모듈 손상으로 표현한다.
```

중요 원칙:

```text
차량 전체가 열 자원으로 과열되는 것이 아니다.
무기는 무기별로 과열되고,
소이탄은 화재 상태를 일으키는 탄종이다.
```

## 9. EMP탄

### 정의

EMP탄은 전자장비를 방해하는 탄종이다.

```text
직접 피해는 낮지만,
센서·락온·배터리·터렛 안정화·능동 방어를 흔드는 탄종
```

### 역할

| 항목 | 방향 |
|---|---|
| 주 역할 | 전자장비 방해 |
| 피해 타입 | 전자 피해 |
| 장갑 대응 | 낮음 |
| 모듈 피해 | 전자 모듈에 강함 |
| 탄약 중량 | 중간~높음 |
| 탄수 확보 | 제한적 |
| 추천 무기 | 미사일, 특수 로켓, 일부 오토캐논 |

### 강점

- 락온/센서 빌드 카운터가 된다.
- 배터리 의존 차량을 압박한다.
- 터렛 안정화 방해가 가능하다.
- 능동 방어 장비 사용을 어렵게 만든다.

### 약점

- 직접 차체 피해는 낮다.
- 순수 고정 화기 차량에게 효율이 낮다.
- 상태 피드백이 없으면 플레이어가 이해하기 어렵다.
- P0에 넣으면 시스템이 복잡해진다.

### 설계 원칙

```text
EMP탄은 적을 죽이는 탄이 아니라,
적의 전자장비 기반 전투 능력을 떨어뜨리는 탄이다.
```

EMP탄은 P1 이후, 락온/센서/배터리/전자전 UI가 정리된 뒤 추가한다.

## 10. 탄종별 중량 원칙

탄종은 반드시 중량 차이를 가져야 한다.

| 탄종 | 중량 방향 | 이유 |
|---|---:|---|
| 일반탄 | 낮음 | 기본 탄, 많이 싣기 쉬워야 함 |
| 철갑탄 | 높음 | 관통탄은 무겁고 부담 있어야 함 |
| 고폭탄 | 중간~높음 | 폭약/탄두 부피 때문에 부담 |
| 소이탄 | 중간 | 특수 탄두지만 과도하게 무겁지는 않음 |
| EMP탄 | 중간~높음 | 특수 탄두/전자장비 성격 |

탄약 중량은 아래 차량 성능에 영향을 준다.

| 차량 성능 | 영향 |
|---|---|
| 가속 | 탄약이 많을수록 느려짐 |
| 제동 | 무거울수록 제동거리 증가 |
| 선회 | 무거울수록 둔해짐 |
| 최고속도 | 일정 중량 이상에서 감소 |
| 연료 소비 | 무거울수록 증가 가능 |
| 충돌 안정성 | 무거운 차량은 일부 유리할 수 있음 |

## 11. 탄수 선택의 전략성

출격 전에 탄종과 탄수를 고르는 것은 전투 방식 선택이어야 한다.

| 선택 | 장점 | 단점 |
|---|---|---|
| 일반탄 많이 | 장기전 가능, 기동 부담 낮음 | 특수 대응 약함 |
| 철갑탄 많이 | 중장갑 대응 강함 | 무거움, 경량 목표 상대로 비효율 |
| 고폭탄 많이 | 모듈/바퀴 압박 강함 | 정면 장갑 대응 약함 |
| 탄종 다양하게 | 상황 대응 좋음 | 각 탄종별 탄수 부족 |
| 탄 적게 | 가벼움, 기동성 좋음 | 장기전/추격전 불리 |

핵심 원칙:

```text
무슨 탄을 얼마나 싣느냐가,
어떤 전투를 선택할 수 있는지를 결정해야 한다.
```

## 12. 무기 타입과 탄종 호환

모든 무기가 모든 탄종을 쓰면 밸런스가 흐려질 수 있다. 무기군별로 어울리는 탄종을 제한한다.

| 무기군 | 일반탄 | 철갑탄 | 고폭탄 | 소이탄 | EMP탄 |
|---|---:|---:|---:|---:|---:|
| 기관총 | 높음 | 중간 | 낮음 | 중간 | 낮음 |
| 오토캐논 | 높음 | 높음 | 중간 | 낮음 | 중간 |
| 대구경포 | 중간 | 높음 | 높음 | 낮음 | 낮음 |
| 산탄 | 높음 | 낮음 | 낮음 | 중간 | 낮음 |
| 로켓 | 낮음 | 낮음 | 높음 | 중간 | 중간 |
| 미사일 | 낮음 | 중간 | 높음 | 중간 | 높음 |
| 레일건/코일건 | 낮음 | 높음 | 낮음 | 없음 | 중간 |
| EMP/전자전 | 낮음 | 낮음 | 낮음 | 낮음 | 높음 |

P0에서는 아래처럼 단순화한다.

```text
기관총: 일반탄
오토캐논: 일반탄 / 철갑탄
대구경포: 철갑탄 / 고폭탄
미사일: 고폭탄
```

## 13. 장갑 방향과 탄종의 관계

| 피격 방향 | 일반탄 | 철갑탄 | 고폭탄 |
|---|---:|---:|---:|
| 정면 | 보통 | 강함 | 낮음~보통 |
| 측면 | 보통 | 강함 | 보통 |
| 후면 | 강함 | 강함 | 강함 |
| 상부 | 보통 | 보통 | 강함 |
| 하부 | 낮음 | 보통 | 매우 강함 |

이 구조는 아래 판단을 만든다.

- 정면 중장갑을 상대하려면 철갑탄이 유리하다.
- 바퀴/하부/상부를 노리려면 고폭탄이 유리하다.
- 후면을 잡았다면 일반탄도 충분히 강하다.
- 탄종이 맞지 않으면 좋은 조준을 해도 효율이 떨어진다.

## 14. 모듈 손상과 탄종의 관계

| 모듈 | 일반탄 | 철갑탄 | 고폭탄 | EMP탄 |
|---|---:|---:|---:|---:|
| 차체 장갑 | 보통 | 강함 | 낮음~보통 | 낮음 |
| 바퀴 | 보통 | 낮음 | 강함 | 낮음 |
| 엔진 | 보통 | 강함 | 중간 | 낮음 |
| 터렛 | 보통 | 중간 | 강함 | 중간 |
| 센서 | 낮음 | 낮음 | 중간 | 강함 |
| 배터리 | 낮음 | 중간 | 중간 | 강함 |
| 연료 계통 | 중간 | 중간 | 강함 | 낮음 |

P0에서는 모듈 손상을 전부 넣지 않는다. 아래 3개만 우선 후보로 둔다.

```text
P0 모듈 피해 후보

01. 바퀴
02. 엔진
03. 터렛
```

센서/배터리/연료 계통은 P1 이후가 적합하다.

---

## 15. 탄종과 무기 열

탄종도 무기 열에 약간 영향을 줄 수 있다. 다만 P0에서는 과하게 복잡하게 하지 않는다.

| 탄종 | 무기 열 영향 |
|---|---|
| 일반탄 | 기본 |
| 철갑탄 | 약간 증가 가능 |
| 고폭탄 | 무기군에 따라 기본 또는 약간 증가 |
| 소이탄 | 열보다는 화재 상태 중심 |
| EMP탄 | 전자장비/배터리 부담 중심 |

P0에서는 탄종별 열 보정은 일단 제외한다. 먼저 무기별 열만 검증하고, 탄종별 열 차이는 P1에서 추가한다.

---

## 16. P0 탄종 범위

P0에서는 3개만 사용한다.

| 탄종 | 역할 | 중량 | 주요 대상 |
|---|---|---:|---|
| 일반탄 | 기준 탄 | 낮음 | 경량/일반 차량 |
| 철갑탄 | 장갑 관통 | 높음 | 중장갑 정면 |
| 고폭탄 | 모듈/폭발 | 중간~높음 | 바퀴, 터렛, 하부/상부 |

P0 제외 탄종:

| 제외 탄종 | 제외 이유 |
|---|---|
| 소이탄 | 화재/지속 피해/연료 계통 상태 시스템 필요 |
| EMP탄 | 센서/배터리/락온/전자전 UI가 먼저 필요 |

## 17. P0 탄종별 밸런스 방향

정확한 수치는 나중에 조정하고, 처음에는 아래 감각을 기준으로 한다.

| 항목 | 일반탄 | 철갑탄 | 고폭탄 |
|---|---:|---:|---:|
| 차체 기본 피해 | 보통 | 중간 | 낮음~중간 |
| 장갑 관통 | 보통 | 높음 | 낮음 |
| 모듈 피해 | 보통 | 낮음 | 높음 |
| 범위 피해 | 없음 | 없음 | 있음 |
| 탄약 중량 | 낮음 | 높음 | 중간~높음 |
| 탄수 확보 | 쉬움 | 어려움 | 보통~어려움 |
| 탄속 | 보통 | 빠름~보통 | 느림~보통 |
| 반동/안정성 | 보통 | 높을 수 있음 | 무기별 |

## 18. 탄종 선택 예시

### 예시 A. 경량 차량 사냥용

```text
무기:
소형 짐벌 기관총 + 오토캐논

탄종:
일반탄 많이
고폭탄 소량

전투 방식:
빠른 목표를 지속적으로 긁고,
바퀴나 터렛을 고폭탄으로 압박한다.
```

### 예시 B. 중장갑 대응용

```text
무기:
전방 고정 오토캐논 + 대구경포

탄종:
철갑탄 중심
일반탄 소량

전투 방식:
정면 장갑도 뚫을 수 있지만,
탄약이 무거워 차량 기동성이 떨어진다.
```

### 예시 C. 모듈 무력화용

```text
무기:
로켓 또는 대구경포

탄종:
고폭탄 중심

전투 방식:
상대 차체를 바로 터뜨리기보다,
바퀴/터렛/엔진을 망가뜨려 움직이지 못하게 만든다.
```

## 22. Migration Notes

- 기존 전투 기획에서 `열/에너지`로 통합 표현하던 자원은 사용하지 않는다.
- 차량 자원은 배터리/연료/탄약/중량 중심으로 유지한다.
- 열은 차량 전체 자원이 아니라 무기별 과열로만 다룬다.
- 탄약은 단순 잔탄 수가 아니라 중량과 연결되는 피팅 요소로 다룬다.
- EMP탄과 소이탄은 P0에서 제외하고 P1 이후 상태/전자전 시스템이 준비된 뒤 추가한다.
