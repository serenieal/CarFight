## 1. 문서 목적

이 문서는 CarFight에서 사용할 **차량 차급 목록과 차급별 원화 기준**을 정의한다.

CarFight의 차량 분류는 전투 역할이나 군사용 병과가 아니다.  
이 문서의 차급은 AI 원화 생성, 3D 메쉬 제작, 실루엣 검수에서 사용할 **민간 차량 기반 형태 분류**이다.

이 문서의 목적은 다음과 같다.

- CarFight에서 사용할 기본 차량 차급을 정한다.
- 각 차급의 큰 실루엣을 정한다.
- 차급별 모델링 난이도 기대치를 정한다.
- R1 Gameplay Mid에서 반드시 읽혀야 할 정보를 정한다.
- AI 이미지 생성 결과가 탱크, 장갑차, 군용 차량으로 흐르지 않도록 제한한다.
- 이후 `05_SilhouetteRules.md`, `06_ProportionRules.md`에서 사용할 기준선을 만든다.

## 2. 현재 확정 기준

이 문서는 아래 기준을 따른다.

| 항목 | 기준 |
|---|---|
| 전체 방향 | 단순화된 근미래 민간 차량 개조 전투차 |
| 기본 제작 목표 | C1 Simple Game Asset 최종 후보 |
| 기본 카메라 기준 | R1 Gameplay Mid |
| 차급 판단 | 민간 차량 실루엣이 먼저 읽혀야 함 |
| 전투 요소 | 차체 위에 추가된 장갑/마운트/센서로 제한 |
| 디테일 처리 | 큰 형태는 메쉬, 작은 정보는 텍스처/머티리얼 우선 |
| 제작 우선순위 | 1인 개발자가 제작·수정 가능한 단순 구조 우선 |

중요 기준:

```text
차급은 전투 역할 이름이 아니라, 제작 가능한 민간 차량 실루엣 기준이다.
```

따라서 이 문서에서는 전차, 장갑차, 수송차, 구축차 같은 군사용 역할 이름을 사용하지 않는다.

## 3. 차급 선정 원칙

CarFight의 차급은 다음 기준으로 선정한다.

1. 실제 민간 차량에서 바로 떠올릴 수 있어야 한다.
2. R1 Gameplay Mid에서 큰 실루엣 차이가 읽혀야 한다.
3. C1 기준으로 단순한 메쉬 제작이 가능해야 한다.
4. 차급별 차이가 작은 장식이 아니라 길이, 높이, 지붕 형태, 후방 공간에서 나와야 한다.
5. 전투 개조를 붙여도 원래 차급이 사라지지 않아야 한다.

피해야 할 기준:

- 전투 임무로 차급을 나누지 않는다.
- 무기 크기로 차급을 구분하지 않는다.
- 장갑 두께만으로 차급을 구분하지 않는다.
- 실제 브랜드나 특정 모델을 기준으로 삼지 않는다.
- 군용 차량, 장갑차, 탱크, 메카 형태로 확장하지 않는다.

## 4. 권장 차급 목록

CarFight의 기본 차량 차급은 아래 10종으로 시작한다.

| 순서 | Class Name | 한국어 표시명 | 기본 인상 |
|---|---|---|---|
| 01 | Microcar | 초소형차 | 매우 짧고 좁은 차량 |
| 02 | City Car | 도심형 경차 | 짧고 둥근 경량 차량 |
| 03 | Subcompact | 소형차 | 작은 해치백 중심 차량 |
| 04 | Compact | 준중형차 | 기본형 소형/준중형 차량 |
| 05 | Sedan | 세단 | 낮고 긴 승용차 |
| 06 | Coupe | 쿠페 | 낮고 짧은 스포티 차량 |
| 07 | Wagon | 왜건 | 긴 루프와 후방 적재 공간 |
| 08 | SUV | SUV | 높고 굵은 차체 |
| 09 | Van | 밴 | 넓고 높은 박스형 차체 |
| 10 | Pickup | 픽업 | 캐빈과 뒤쪽 짐칸이 분리된 차량 |

기본 사용 기준:

```text
초기 차량 리소스는 위 10종 중 하나로 분류한다.
```

이 목록은 차량 제작을 복잡하게 만들기 위한 목록이 아니다.  
AI 원화와 3D 제작에서 같은 방향을 보게 하기 위한 최소 분류표다.

## 5. 차급별 기준

### 5.1 Microcar

| 항목 | 기준 |
|---|---|
| Class Name | Microcar |
| 한국어 표시명 | 초소형차 |
| 기본 실루엣 | 매우 짧은 차체, 짧은 보닛, 작은 캐빈, 짧은 앞/뒤 오버행 |
| 모델링 난이도 기대치 | 낮음. 큰 덩어리가 적고 파츠 수를 줄이기 쉬움 |
| CarFight 권장 사용 | 가장 작은 민간 개조 차량, 빠르고 가벼운 인상, 튜토리얼/초기 차량 후보 |
| R1에서 읽혀야 할 것 | 매우 짧은 길이, 작은 차체, 휠 4개의 위치, 작은 루프 마운트 |
| 피해야 할 디테일 | 과한 장갑으로 SUV처럼 커지는 형태, 큰 터렛, 복잡한 하부 구조, 장난감처럼 과장된 비례 |

Microcar는 작은 크기 자체가 특징이다.  
전투 개조를 추가해도 차체가 너무 커지면 차급이 사라진다.

---

### 5.2 City Car

| 항목 | 기준 |
|---|---|
| Class Name | City Car |
| 한국어 표시명 | 도심형 경차 |
| 기본 실루엣 | 짧은 차체, 높은 캐빈, 둥글거나 단순한 앞뒤 형태 |
| 모델링 난이도 기대치 | 낮음. 단순한 곡면과 큰 창문 형태 중심 |
| CarFight 권장 사용 | 가벼운 기본 차량, 민간 차량 느낌을 가장 쉽게 보여주는 차급 |
| R1에서 읽혀야 할 것 | 짧고 높은 차체, 큰 유리 영역, 작은 휠베이스, 전면/후면 방향 |
| 피해야 할 디테일 | 실제 경차 브랜드 고유 형태, 너무 많은 곡면 패널, 과한 네온 장식, 군용 장갑차식 전면 |

City Car는 민간 차량 느낌을 유지하기 좋다.  
장갑은 큰 판형 2~4개 정도로 제한하는 것이 적합하다.

---

### 5.3 Subcompact

| 항목 | 기준 |
|---|---|
| Class Name | Subcompact |
| 한국어 표시명 | 소형차 |
| 기본 실루엣 | 짧은 해치백, 적당한 루프 높이, 짧은 후방 |
| 모델링 난이도 기대치 | 낮음에서 중간. 기본 C1 차량의 표준 후보 |
| CarFight 권장 사용 | 가장 범용적인 소형 전투 개조 차량, 반복 제작용 기본 차급 |
| R1에서 읽혀야 할 것 | 해치백 형태, 짧은 후방, 휠 위치, 루프 마운트, 큰 측면 장갑판 |
| 피해야 할 디테일 | 실제 차량처럼 복잡한 문/창문 라인, 작은 장갑 조각 남발, 과도한 사이드 스커트 |

Subcompact는 CarFight의 기본 제작 기준에 가장 잘 맞는 차급이다.  
처음 차량 원화를 만든다면 이 차급부터 시작하는 것이 안전하다.

---

### 5.4 Compact

| 항목 | 기준 |
|---|---|
| Class Name | Compact |
| 한국어 표시명 | 준중형차 |
| 기본 실루엣 | Subcompact보다 조금 길고 안정적인 차체, 보닛과 캐빈이 분명함 |
| 모델링 난이도 기대치 | 중간. 차체 길이가 늘어나 장갑/문 경계 정리가 필요함 |
| CarFight 권장 사용 | 기본형 중형 전투 차량, 장갑판과 루프 마운트 테스트용 |
| R1에서 읽혀야 할 것 | 균형 잡힌 길이, 명확한 보닛, 캐빈, 후방 해치 또는 트렁크 느낌 |
| 피해야 할 디테일 | 세단/왜건과 구분이 안 되는 긴 루프, 너무 낮은 스포츠카 비례, 실제 브랜드 복제 |

Compact는 작은 차량과 큰 차량 사이의 기준점이다.  
차급이 애매해지지 않도록 보닛, 캐빈, 후방 덩어리를 단순하게 나눈다.

---

### 5.5 Sedan

| 항목 | 기준 |
|---|---|
| Class Name | Sedan |
| 한국어 표시명 | 세단 |
| 기본 실루엣 | 낮고 긴 차체, 보닛-캐빈-트렁크가 분리되어 보이는 3박스 형태 |
| 모델링 난이도 기대치 | 중간. 긴 차체와 트렁크 비례를 단순하게 잡아야 함 |
| CarFight 권장 사용 | 안정적인 중형 민간 개조 차량, 전후 방향성이 중요한 차량 |
| R1에서 읽혀야 할 것 | 긴 보닛, 낮은 루프, 트렁크 덩어리, 전면/후면 구분 |
| 피해야 할 디테일 | 고급 승용차식 복잡한 곡면, 얇은 크롬 라인, 복잡한 라이트 내부, 너무 큰 루프 무기 |

Sedan은 차급 실루엣이 강하지만 실제 차량 디테일을 따라가면 난이도가 빨리 오른다.  
큰 3박스 형태만 유지하고 표면 디테일은 줄인다.

---

### 5.6 Coupe

| 항목 | 기준 |
|---|---|
| Class Name | Coupe |
| 한국어 표시명 | 쿠페 |
| 기본 실루엣 | 낮은 차체, 짧은 캐빈, 완만하게 내려가는 루프, 짧은 후방 |
| 모델링 난이도 기대치 | 중간. 낮은 비례는 쉽지만 곡면을 과하게 만들면 어려워짐 |
| CarFight 권장 사용 | 빠르고 날렵한 인상의 민간 개조 차량, 대표 차량 후보 |
| R1에서 읽혀야 할 것 | 낮은 높이, 날렵한 루프라인, 짧은 캐빈, 앞/뒤 방향 |
| 피해야 할 디테일 | 슈퍼카식 복잡한 곡면, 과도한 공기역학 파츠, 깊은 흡기구 반복, 네온 스포츠카 방향 |

Coupe는 멋있게 보이기 쉽지만 C1 기준을 넘기기도 쉽다.  
날렵함은 큰 비례로만 표현하고 세부 곡면은 단순화한다.

---

### 5.7 Wagon

| 항목 | 기준 |
|---|---|
| Class Name | Wagon |
| 한국어 표시명 | 왜건 |
| 기본 실루엣 | 긴 루프, 긴 후방 적재 공간, 세단보다 큰 후면 덩어리 |
| 모델링 난이도 기대치 | 중간. 긴 측면과 후방 공간을 단순하게 처리해야 함 |
| CarFight 권장 사용 | 적재 공간이 있는 민간 개조 차량, 센서/장비 박스 부착 후보 |
| R1에서 읽혀야 할 것 | 긴 루프, 긴 후방 캐빈, 후면 적재 공간, 측면 장갑판 |
| 피해야 할 디테일 | 밴처럼 완전한 박스형이 되는 형태, 너무 많은 창문 분할, 캠핑카/군용 수송차 방향 |

Wagon은 장비를 실은 민간 차량 느낌을 만들기 좋다.  
하지만 Van과 구분되도록 높이를 과하게 올리지 않는다.

### 5.8 SUV

| 항목 | 기준 |
|---|---|
| Class Name | SUV |
| 한국어 표시명 | SUV |
| 기본 실루엣 | 높은 차체, 큰 휠, 짧거나 중간 길이의 보닛, 굵은 캐빈 |
| 모델링 난이도 기대치 | 중간. 큰 면이 많아 만들기 쉽지만 장갑을 과하게 붙이기 쉬움 |
| CarFight 권장 사용 | 튼튼한 민간 개조 차량, 큰 장갑판과 범퍼 보강대 테스트용 |
| R1에서 읽혀야 할 것 | 높은 지상고, 큰 휠, 높은 루프, 굵은 차체, 루프 마운트 |
| 피해야 할 디테일 | 군용 장갑차처럼 보이는 수직 장갑, 탱크식 차체, 지나치게 두꺼운 장갑, 복잡한 오프로드 서스펜션 |

SUV는 CarFight 방향과 잘 맞지만 군용 차량으로 흐르기 쉽다.  
민간 SUV의 큰 실루엣을 먼저 유지하고 전투 개조는 덧붙이는 방식으로 제한한다.

### 5.9 Van

| 항목 | 기준 |
|---|---|
| Class Name | Van |
| 한국어 표시명 | 밴 |
| 기본 실루엣 | 높고 긴 박스형 차체, 짧은 보닛, 넓은 측면, 큰 후방 공간 |
| 모델링 난이도 기대치 | 낮음에서 중간. 박스형이라 만들기 쉽지만 면이 밋밋해질 수 있음 |
| CarFight 권장 사용 | 장비 운반 느낌의 민간 개조 차량, 큰 색면/마킹 테스트용 |
| R1에서 읽혀야 할 것 | 높은 박스형 캐빈, 긴 측면, 짧은 전면, 넓은 후면 |
| 피해야 할 디테일 | 군용 수송차, APC, 장갑 버스 방향, 측면의 작은 문/패널 과다 분할, 내부 구조 노출 |

Van은 단순 제작에 유리하다.  
개성을 줄 때는 작은 패널을 많이 만들기보다 큰 색면, 큰 장갑판, 단순 센서 박스를 사용한다.

### 5.10 Pickup

| 항목 | 기준 |
|---|---|
| Class Name | Pickup |
| 한국어 표시명 | 픽업 |
| 기본 실루엣 | 앞쪽 캐빈과 뒤쪽 열린 짐칸이 분리되어 보이는 형태 |
| 모델링 난이도 기대치 | 중간. 짐칸 형태와 후방 장비 배치를 단순하게 잡아야 함 |
| CarFight 권장 사용 | 다목적 민간 개조 차량, 후방 장비 박스나 단순 마운트 부착 후보 |
| R1에서 읽혀야 할 것 | 캐빈과 짐칸 분리, 높은 후방 적재 공간, 휠 위치, 전후 방향 |
| 피해야 할 디테일 | 군용 테크니컬 차량처럼 무기가 먼저 보이는 형태, 복잡한 적재물, 얇은 롤케이지, 실제 오프로드 튜닝 과다 복제 |

Pickup은 전투 개조와 잘 어울리지만 무기가 차량보다 먼저 읽히면 안 된다.  
짐칸은 복잡한 적재물보다 큰 장비 박스나 단순한 하드포인트 중심으로 처리한다.

## 6. 모델링 난이도 요약

C1 기준에서 차급별 모델링 난이도 기대치는 다음과 같다.

| 차급 | 난이도 기대치 | 이유 |
|---|---|---|
| Microcar | 낮음 | 큰 덩어리가 적고 파츠 수를 줄이기 쉬움 |
| City Car | 낮음 | 짧은 차체와 단순한 유리 영역 중심 |
| Subcompact | 낮음~중간 | 기본형 제작에 적합하지만 해치백 비례 정리가 필요 |
| Compact | 중간 | 보닛/캐빈/후방 구분이 필요 |
| Sedan | 중간 | 3박스 비례와 긴 차체 정리가 필요 |
| Coupe | 중간 | 낮은 곡면을 단순화해야 함 |
| Wagon | 중간 | 긴 루프와 후방 공간 정리가 필요 |
| SUV | 중간 | 큰 차체는 쉽지만 장갑 과다 위험이 있음 |
| Van | 낮음~중간 | 박스형은 쉽지만 밋밋함 보완이 필요 |
| Pickup | 중간 | 캐빈/짐칸 분리와 후방 장비 배치가 필요 |

초기 제작 추천 순서:

```text
Subcompact → Compact → SUV → Van → Pickup → Sedan → City Car → Wagon → Coupe → Microcar
```

이 순서는 품질 단계가 아니라 제작 연습과 기준 확립을 위한 추천 순서다.  
실제 리소스는 처음부터 C1 최종 후보를 목표로 만든다.

## 7. R1 Gameplay Mid 가독성 기준

모든 차급은 R1에서 아래 정보가 읽혀야 한다.

| 정보 | 기준 |
|---|---|
| 차급 | 2~3초 안에 대략적인 차급이 읽힘 |
| 전후 방향 | 라이트, 보닛, 트렁크/후방 형태로 구분됨 |
| 휠 위치 | 차량 움직임과 접지감이 읽힘 |
| 루프/상면 | 마운트 위치를 판단할 수 있음 |
| 큰 장갑판 | 전투 개조 차량이라는 인상이 보임 |
| 큰 색면 | 차체와 장갑판, 유리 영역이 구분됨 |

차급별로 특히 유지할 R1 가독성은 다음과 같다.

| 차급 | R1에서 가장 먼저 읽혀야 할 실루엣 |
|---|---|
| Microcar | 매우 짧은 길이 |
| City Car | 짧고 높은 도심형 차체 |
| Subcompact | 작은 해치백 |
| Compact | 균형 잡힌 기본 차체 |
| Sedan | 보닛-캐빈-트렁크 3박스 |
| Coupe | 낮고 날렵한 루프 |
| Wagon | 긴 루프와 후방 적재 공간 |
| SUV | 높은 차체와 큰 휠 |
| Van | 높은 박스형 캐빈 |
| Pickup | 캐빈과 짐칸 분리 |

## 8. 공통 금지 기준

모든 차급에서 아래 방향은 피한다.

| 금지 방향 | 이유 |
|---|---|
| 군용 장갑차 형태 | 민간 차량 개조 전투차 방향이 사라짐 |
| 탱크형 차체 | 차급 실루엣과 휠 기반 차량성이 사라짐 |
| 실제 브랜드 복제 | 저작권/상표권 위험과 독자성 저하 |
| 과도한 현실 차량 디테일 | C1 제작 난이도를 초과함 |
| 수십 개의 작은 장갑판 | 파츠 수, UV, 수정 비용이 증가함 |
| 너무 큰 무기 | 차급보다 무기가 먼저 읽힘 |
| 과도한 네온 장식 | 기능적 근미래 개조 느낌이 약해짐 |
| 복잡한 하부/서스펜션 노출 | 모델링과 애니메이션 부담이 큼 |
| 내부 구조 전제 | 문/보닛/트렁크 기능 범위를 불필요하게 키움 |

공통 판단 문장:

```text
전투 개조를 제거해도 어떤 민간 차급인지 읽혀야 한다.
```

## 9. 제작/모델링 영향

이 문서의 차급 기준은 모델링에서 다음처럼 사용한다.

1. 먼저 차급을 하나 고른다.
2. 차급의 큰 실루엣을 만든다.
3. R1에서 차급이 읽히는지 확인한다.
4. 큰 장갑판, 범퍼, 루프 마운트만 추가한다.
5. 작은 볼트, 얇은 패널 라인, 스크래치는 텍스처/노멀로 넘긴다.
6. 차급 실루엣이 무너지면 장갑과 무기를 줄인다.

C1 기준 권장 처리:

| 요소 | 처리 |
|---|---|
| 차체 큰 덩어리 | 메쉬 |
| 휠 | 분리 메쉬 |
| 유리 영역 | 단순 면 또는 단순 파츠 |
| 큰 장갑판 | 메쉬 |
| 루프 마운트 | 메쉬 |
| 작은 고정구/볼트 | 텍스처/노멀 |
| 작은 마킹/오염 | 텍스처 |

## 10. AI 프롬프트 영향

AI 원화 생성 시 차급 이름은 프롬프트 초반에 넣는다.

기본 형식:

```text
[Class Name],
simplified near-future civilian combat car,
clean readable silhouette,
low modeling complexity,
large simple armor panels,
R1 gameplay readable,
no real car brand,
no military armored vehicle,
no tank,
orthographic concept sheet,
plain background
```

예시:

```text
Subcompact,
simplified near-future civilian combat car,
small hatchback silhouette,
clean readable silhouette,
low modeling complexity,
large simple armor panels,
small roof weapon mount,
no real car brand,
no military armored vehicle,
no tank,
orthographic concept sheet,
plain background
```

차급별 프롬프트에는 전투 역할 이름보다 실루엣 단어를 우선 넣는다.

권장 실루엣 단어:

| 차급 | 프롬프트 핵심 단어 |
|---|---|
| Microcar | very short body, tiny civilian car |
| City Car | short tall city car |
| Subcompact | small hatchback silhouette |
| Compact | compact hatchback body |
| Sedan | long low sedan, three-box body |
| Coupe | low coupe roofline |
| Wagon | long roof wagon |
| SUV | tall civilian SUV body |
| Van | boxy civilian van |
| Pickup | cabin and open rear bed |

## 14. Migration

### v0.1 적용 시 기존 작업 영향

- 앞으로 차량 원화와 AI 프롬프트는 이 문서의 10개 차급 중 하나를 먼저 선택한 뒤 작성한다.
- 기존에 생성된 차량 이미지가 있다면 다음 기준으로 재검토한다.
  - 전투 개조를 제거해도 민간 차량 차급이 읽히는가?
  - 탱크, APC, 군용 장갑차, 메카처럼 보이지 않는가?
  - R1 Gameplay Mid에서 차급 실루엣이 먼저 읽히는가?
  - C1 Simple Game Asset 기준으로 10~16개 주요 파츠 안에 정리될 수 있는가?
  - 작은 디테일이 메쉬 제작 부담을 과하게 늘리지 않는가?
- 차급 이름은 전투 역할명으로 바꾸지 않는다.
- 이후 `05_SilhouetteRules.md`와 `06_ProportionRules.md`는 이 문서의 차급 목록을 기준으로 작성한다.
