## 1. 문서 목적

이 문서는 CarFight 차량 원화에서 **장갑 패널을 어떻게 단순하고 제작 가능하게 붙일지**를 정의한다.

CarFight의 장갑은 군용 장갑차나 탱크의 복잡한 장갑 구조가 아니다.  
기본 민간 차량 차체 위에 전투 개조용 판형 부품을 덧댄 형태로 보이는 것이 목표다.

이 문서의 목적은 다음과 같다.

- C1 Simple Game Asset 기준의 장갑 패널 형태를 정한다.
- 차급 실루엣과 비례를 해치지 않는 장갑 배치 기준을 정한다.
- 차량 1대당 장갑 패널 개수와 크기 기대치를 정한다.
- 메쉬로 만들 장갑과 텍스처/노멀로 처리할 장갑 디테일을 구분한다.
- AI 원화 생성 결과가 군용 장갑차, 탱크, APC 방향으로 흐르지 않도록 제한한다.
- 이후 `08_HardpointRules.md`에서 무기/터렛 장착부를 정할 때 장갑과 충돌하지 않는 기준을 만든다.

## 2. 현재 확정 기준

이 문서는 아래 기준을 따른다.

| 항목 | 기준 |
|---|---|
| 기본 제작 목표 | C1 Simple Game Asset 최종 후보 |
| 기본 카메라 기준 | R1 Gameplay Mid |
| 권장 파츠 수 | 차량 1대당 10~16개, 상한 20개 이하 |
| 장갑 기본 방향 | 큰 판형 패널 중심 |
| 작은 장갑 디테일 | 텍스처/노멀/머티리얼 처리 우선 |
| 실루엣 제한 | 장갑이 차급 실루엣을 대체하지 않음 |
| 비례 제한 | 장갑 추가 후 원래 차량 비례가 남아야 함 |

최상위 기준:

```text
장갑은 민간 차량 차체 위에 덧댄 단순한 큰 판형 부품이어야 한다.
```

## 3. 장갑 패널 판단 원칙

CarFight의 장갑 패널 판단 순서는 다음과 같다.

1. 먼저 원래 차급 실루엣이 읽히는지 본다.
2. 그다음 장갑이 큰 판형으로 단순하게 붙었는지 본다.
3. 그다음 장갑이 휠, 창문, 보닛, 트렁크/후방 공간을 가리지 않는지 본다.
4. 그다음 C1 파츠 예산 안에 들어오는지 본다.
5. 마지막으로 작은 볼트, 스크래치, 라벨 같은 표면 정보를 본다.

중요 기준:

```text
장갑판을 제거하지 않아도 원래 민간 차량 차급이 읽혀야 한다.
```

피해야 할 판단:

- 방어력이 강해 보인다는 이유로 차체 전체를 장갑으로 덮지 않는다.
- 작은 장갑 조각을 많이 붙여 디테일을 만든다고 보지 않는다.
- 장갑판을 복잡한 곡면으로 만들지 않는다.
- 전투 역할이나 밸런스 수치를 이 문서에서 정하지 않는다.

## 4. 장갑 패널 기본 형태

C1 기준의 장갑 패널은 아래 형태를 우선한다.

| 형태 | 허용 여부 | 기준 |
|---|---|---|
| 직사각형 판 | 권장 | 가장 제작하기 쉽고 재사용하기 좋음 |
| 사다리꼴 판 | 권장 | 차량 흐름에 맞추기 쉬움 |
| 단순 오각형 판 | 허용 | 전면/측면 포인트용으로 제한 사용 |
| 단순 곡면 판 | 제한 허용 | 큰 차체 곡면에 맞출 때만 사용 |
| 작은 조각 장갑 다발 | 금지 | 파츠 수와 UV 부담 증가 |
| 겹겹이 쌓인 복합 장갑 | 금지 | 군용 장갑차 느낌과 제작 난이도 증가 |
| 날카로운 가시형 장갑 | 금지 | 충돌체/LOD/가독성에 불리함 |

권장 형태:

```text
큰 직사각형 또는 사다리꼴 장갑판을 차체 면에 맞춰 덧댄다.
```

## 5. 장갑 패널 크기 등급

장갑 패널 크기는 3단계로 나눈다.

| 등급 | 이름 | 처리 기준 | 예시 |
|---|---|---|---|
| A0 | Small Surface Detail | 텍스처/노멀 우선 | 작은 볼트, 얇은 고정선, 작은 용접 자국 |
| A1 | Medium Panel | 상황에 따라 메쉬 | 작은 문 하단 보강판, 라이트 주변 보강판 |
| A2 | Large Armor Panel | 메쉬 권장 | 전면 장갑판, 측면 큰 장갑판, 후면 큰 장갑판 |

C1 기본 장갑은 A2 중심으로 구성한다.

```text
큰 장갑판은 메쉬로 만들고, 작은 장갑 정보는 텍스처로 넘긴다.
```

## 6. 차량 1대당 장갑 개수 기준

C1 차량 1대의 장갑 패널 권장 개수는 다음과 같다.

| 기준 | 장갑 패널 수 |
|---|---:|
| 최소 개조 인상 | 2~3개 |
| 기본 권장 | 4~6개 |
| 상한 권장 | 8개 이하 |
| 초과 주의 | 9~12개 |
| 기본 금지 | 13개 이상 |

기본 권장:

```text
차량 1대당 큰 장갑판 4~6개를 우선한다.
```

작은 볼트, 얇은 패널 라인, 고정 브래킷은 위 개수에 포함하지 않고 텍스처/노멀로 처리한다.

## 7. 위치별 장갑 배치 기준

### 7.1 전면 장갑

전면 장갑은 차량의 앞 방향을 강화하지만, 보닛과 라이트 위치를 완전히 가리면 안 된다.

권장 기준:

- 전면 중앙에 큰 판형 1개를 우선한다.
- 보닛 전체를 덮지 않는다.
- 헤드라이트 또는 전면 센서 위치는 읽히게 남긴다.
- 범퍼 보강대와 겹치면 둘 중 하나를 단순화한다.

피해야 할 것:

- 수직 장갑벽처럼 세워 APC처럼 보이게 만들기
- 보닛과 라이트를 모두 가려 전후 방향을 흐리게 만들기
- 작은 장갑 조각을 전면에 많이 붙이기

---

### 7.2 측면 장갑

측면 장갑은 차급 실루엣과 가장 많이 충돌할 수 있다.

권장 기준:

- 좌우 대칭 측면 장갑을 우선한다.
- 문, 창문, 휠 위치가 계속 읽히게 남긴다.
- 측면당 큰 판형 1~2개를 우선한다.
- 하단 장갑은 차체 폭을 과하게 넓히지 않는다.

피해야 할 것:

- 측면 전체를 덮어 차급이 안 보이게 만들기
- 휠 위치를 가려 차량 움직임이 읽히지 않게 만들기
- 얇은 장갑 조각을 계단처럼 많이 붙이기

---

### 7.3 후면 장갑

후면 장갑은 추격 상황에서 후방 방향성을 보강해야 한다.

권장 기준:

- 후면 중앙 또는 하단에 큰 판형 1개를 우선한다.
- 테일라이트 또는 후면 발광 포인트를 남긴다.
- Sedan의 트렁크, Wagon/Van의 해치, Pickup의 짐칸 후면을 가리지 않는다.

피해야 할 것:

- 후방 형태 차이를 모두 가리는 큰 박스 장갑
- 후면 전체를 군용 수송차처럼 만드는 수직 장갑
- 작은 냉각구와 배기구를 과하게 메쉬로 만들기

---

### 7.4 루프 장갑

루프 장갑은 기본값이 아니다.

권장 기준:

- 루프 마운트 주변 보강판 정도로 제한한다.
- 차급 루프라인을 가리지 않는다.
- 터렛 회전 공간을 막지 않는다.
- Coupe/Sedan처럼 낮은 차급에서는 특히 작게 처리한다.

피해야 할 것:

- 루프 전체를 장갑으로 덮어 군용 차량처럼 만들기
- 루프를 장비 플랫폼처럼 가득 채우기
- 루프 마운트와 장갑판이 겹쳐 형태가 복잡해지기

---

### 7.5 휠가드 장갑

휠가드는 실루엣에 큰 영향을 주므로 단순해야 한다.

권장 기준:

- 휠 위치가 계속 읽히게 둔다.
- 앞/뒤 휠가드는 같은 형태를 재사용한다.
- SUV/Pickup은 조금 크게 허용한다.
- Microcar/City Car는 작게 처리한다.

피해야 할 것:

- 휠을 거의 덮어 차량성이 사라지게 만들기
- 복잡한 다층 휠아치 장갑
- 작은 볼트와 고정구를 모두 메쉬로 만들기

---

## 8. 차급별 장갑 허용량

| 차급 | 권장 장갑량 | 기준 |
|---|---|---|
| Microcar | 낮음 | 작은 차체 인상을 해치지 않음 |
| City Car | 낮음~중간 | 짧고 높은 캐빈을 유지 |
| Subcompact | 중간 | 작은 해치백 실루엣 유지 |
| Compact | 중간 | 기본형 차량 비례 유지 |
| Sedan | 낮음~중간 | 낮고 긴 3박스 실루엣 유지 |
| Coupe | 낮음 | 낮은 루프라인과 날렵함 유지 |
| Wagon | 중간 | 긴 루프와 후방 공간 유지 |
| SUV | 중간~높음 | 큰 차체를 활용하되 APC화 금지 |
| Van | 중간 | 박스형 면을 활용하되 군용 수송차화 금지 |
| Pickup | 중간 | 캐빈/짐칸 분리를 유지 |

공통 기준:

```text
차급별 장갑량은 차량 크기와 실루엣을 따라가야 하며, 모든 차량을 같은 장갑량으로 덮지 않는다.
```

## 9. 메쉬/텍스처 처리 기준

장갑 관련 디테일은 아래 기준으로 나눈다.

| 요소 | 권장 처리 |
|---|---|
| 전면 큰 장갑판 | 메쉬 |
| 측면 큰 장갑판 | 메쉬 |
| 후면 큰 장갑판 | 메쉬 |
| 큰 휠가드 | 메쉬 |
| 루프 마운트 보강판 | 메쉬 또는 단순 텍스처 |
| 작은 볼트 | 텍스처/노멀 |
| 얇은 패널 라인 | 텍스처/노멀 |
| 작은 용접 자국 | 텍스처/노멀 |
| 스크래치/페인트 벗겨짐 | 텍스처 |
| 작은 경고 라벨 | 텍스처 |

판단 기준:

```text
R1에서 실루엣이나 큰 면으로 읽히면 메쉬, R0에서만 보이면 텍스처로 처리한다.
```

## 10. 재사용 가능한 장갑 규격

초기에는 완전한 모듈형 장갑 시스템을 목표로 하지 않는다.  
다만 아래 장갑은 여러 차급에 재사용하기 쉬운 형태로 만든다.

재사용 후보:

- 전면 중앙 장갑판
- 측면 직사각형 장갑판
- 측면 사다리꼴 장갑판
- 후면 하단 장갑판
- 단순 휠가드
- 루프 마운트 보강판

재사용 기준:

| 기준 | 설명 |
|---|---|
| 단순한 외곽선 | 스케일 조정으로 여러 차급에 사용 가능 |
| 적은 머티리얼 슬롯 | 관리 부담 감소 |
| 명확한 앞/뒤 방향 | 배치 실수 감소 |
| 예측 가능한 피벗 | 위치 조정과 회전이 쉬움 |
| 좌우 대칭 가능 | 제작 시간 절약 |

## 11. 공통 금지 기준

아래 장갑 방향은 C1 기본 기준에서 제외한다.

| 금지 방향 | 이유 |
|---|---|
| 탱크식 장갑 덩어리 | 민간 차량 차급이 사라짐 |
| APC식 수직 박스 장갑 | 군용 장갑차 느낌이 강해짐 |
| 수십 개의 작은 장갑 조각 | 파츠 수와 UV 부담 증가 |
| 복잡한 다층 장갑 | 모델링과 수정 난이도 증가 |
| 차량 전체를 덮는 장갑 | 실루엣/비례 기준 붕괴 |
| 얇고 날카로운 장갑 돌기 | 충돌체와 LOD에 불리함 |
| 실제 군용 장갑차 디테일 복제 | 아트 방향과 맞지 않음 |
| 작은 고정구 메쉬 남발 | C1 파츠 예산 초과 |

최종 금지 문장:

```text
장갑이 멋있어도 차급과 제작성을 망치면 CarFight 기본 기준에 맞지 않는다.
```

## 12. C1 장갑 원화 검수

AI 이미지나 수작업 원화를 검수할 때 아래 질문을 사용한다.

통과 질문:

- 장갑을 붙여도 원래 차급이 읽히는가?
- 장갑판이 큰 판형 중심인가?
- 차량 1대의 큰 장갑판이 4~6개 정도로 정리되는가?
- 장갑이 휠, 창문, 보닛, 후방 공간을 완전히 가리지 않는가?
- 작은 볼트와 고정구를 텍스처로 넘길 수 있는가?
- 좌우 대칭 장갑을 재사용할 수 있는가?
- R1에서 장갑의 큰 위치가 읽히는가?

탈락 질문:

- 장갑을 제거해야만 차급이 읽히는가?
- 탱크, APC, 군용 수송차처럼 보이는가?
- 장갑판이 수십 개 조각으로 나뉘어 있는가?
- 장갑이 차량보다 먼저 읽히는가?
- 장갑 때문에 모든 차급이 비슷한 SUV/Van 덩어리로 보이는가?
- 작은 고정구와 볼트가 메쉬 디테일의 대부분을 차지하는가?

## 13. AI 프롬프트 영향

AI 원화 생성 프롬프트에는 장갑을 단순화하는 문구를 반드시 넣는다.

기본 형식:

```text
[Class Name],
[class silhouette phrase],
[class proportion phrase],
simplified near-future civilian combat car,
large simple armor panels,
armor plates attached to civilian car body,
clean readable silhouette,
low modeling complexity,
R1 gameplay readable armor,
minimal small details,
no real car brand,
no military armored vehicle,
no tank,
no APC,
no many small armor plates,
no layered complex armor,
orthographic side/front/rear/top concept sheet,
plain background
```

권장 포함 문구:

```text
large simple armor panels,
few armor plates,
attached armor plates,
simple flat armor shapes,
easy to model armor,
readable at gameplay distance
```

권장 금지 문구:

```text
no tank armor,
no APC armor,
no full body armor shell,
no many tiny armor pieces,
no complex layered armor,
no spikes,
no exposed military suspension,
no armored personnel carrier silhouette
```

## 17. Migration

### v0.1 적용 시 기존 작업 영향

- 앞으로 차량 원화는 장갑이 붙은 상태에서도 원래 차급이 읽히는지 먼저 검수한다.
- 기존에 생성된 차량 이미지가 있다면 다음 기준으로 재검토한다.
  - 큰 장갑판이 4~6개 정도로 정리될 수 있는가?
  - 장갑이 휠, 창문, 보닛, 후방 공간을 완전히 가리지 않는가?
  - 장갑판이 수십 개의 작은 조각으로 나뉘어 있지 않은가?
  - 탱크, APC, 군용 수송차처럼 보이지 않는가?
  - 작은 볼트, 고정구, 용접 자국을 텍스처/노멀로 넘길 수 있는가?
- 장갑이 차급 실루엣이나 비례를 망친 차량은 색상/마킹을 조정하기 전에 장갑 크기와 개수를 먼저 줄인다.
- 이후 `08_HardpointRules.md`는 이 문서의 장갑 배치 기준을 바탕으로 마운트 위치와 간섭 제한을 정한다.
