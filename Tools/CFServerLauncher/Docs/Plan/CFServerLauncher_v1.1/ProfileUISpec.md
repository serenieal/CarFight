# CFServerLauncher v1.1 프로필 UI 구성안

문서 버전: v1.1.0-ui  
작성 기준일: 2026-05-29

## 1. UI 목표

v1.1 UI는 v1.0의 서버 설정 화면 위에 프로필 선택 영역을 추가한다.

핵심 목표:

```text
프로필을 선택하면 서버 실행 설정이 한 번에 바뀐다.
```

## 2. 전체 배치

v1.1 기본 배치:

```text
프로필 영역
서버 설정 영역
실행 제어 / 상태 영역
실행 인자 미리보기
최근 서버 로그
버전 표시
```

## 3. 프로필 영역

서버 설정 영역 위에 추가한다.

```text
[프로필] [로컬 테스트 서버 ▼] [새 프로필] [프로필 저장] [프로필 삭제]
```

선택 기능:

| UI 요소 | 역할 |
|---|---|
| 프로필 콤보박스 | 프로필 목록 표시 및 선택 |
| 새 프로필 | 현재 UI 값을 기반으로 새 프로필 생성 |
| 프로필 저장 | 현재 UI 값을 선택된 프로필에 저장 |
| 프로필 삭제 | 선택된 프로필 삭제 |

## 4. v1.1에서 보류할 UI

다음 버튼은 v1.1에서 보류 가능하다.

```text
프로필 이름 변경
프로필 복제
프로필 가져오기
프로필 내보내기
```

이름 변경이 필요하면 v1.2에서 추가한다. v1.1에서는 새 프로필 생성과 삭제로 충분하다.

## 5. 새 프로필 생성 흐름

단순성을 위해 새 프로필 버튼을 누르면 이름 입력 대화상자를 띄운다.

입력 문구:

```text
새 프로필 이름을 입력하세요.
```

기본 제안 이름:

```text
새 프로필
```

중복 시 메시지:

```text
같은 이름의 프로필이 이미 있습니다.
```

빈 이름일 때 메시지:

```text
프로필 이름을 입력해야 합니다.
```

## 6. 프로필 삭제 흐름

삭제 버튼을 누르면 확인 메시지를 띄운다.

문구:

```text
선택한 프로필을 삭제할까요?
```

프로필이 1개뿐이면 삭제를 막는다.

문구:

```text
프로필은 최소 1개 이상 필요합니다.
```

서버 실행 중에는 프로필 삭제를 막는다.

문구:

```text
서버 실행 중에는 프로필을 삭제할 수 없습니다.
```

## 7. 프로필 선택 흐름

프로필 콤보박스에서 항목을 선택하면 다음 작업을 한다.

```text
1. 선택 프로필 이름을 갱신한다.
2. 선택 프로필 값을 UI에 적용한다.
3. 실행 인자 미리보기를 갱신한다.
4. 설정 파일에 selectedProfileName을 저장한다.
```

서버 실행 중에는 프로필 선택을 비활성화하는 것을 권장한다.

이유:

```text
실행 중인 서버의 설정과 UI 설정이 달라지면 혼동이 생길 수 있다.
```

## 8. 프로필 저장 흐름

프로필 저장 버튼을 누르면 현재 UI 값을 선택된 프로필에 덮어쓴다.

저장 완료 메시지:

```text
프로필을 저장했습니다.
```

서버 실행 중에는 프로필 저장을 막는 것을 권장한다.

문구:

```text
서버 실행 중에는 프로필을 저장할 수 없습니다.
```

## 9. 서버 설정 영역과의 관계

기존 v1.0 서버 설정 영역은 유지한다.

```text
서버 실행 파일
작업 폴더
맵 경로
포트
로그 파일
현재 실행 로그 파일
추가 인자
```

변경점:

```text
서버 설정 입력값은 현재 선택된 프로필의 편집 값으로 본다.
```

## 10. 버튼 활성화 정책

| 상태 | 프로필 선택 | 새 프로필 | 프로필 저장 | 프로필 삭제 |
|---|---|---|---|---|
| 서버 중지 | 활성 | 활성 | 활성 | 활성 |
| 서버 시작 중 | 비활성 | 비활성 | 비활성 | 비활성 |
| 서버 실행 중 | 비활성 권장 | 비활성 권장 | 비활성 권장 | 비활성 권장 |
| 서버 종료 중 | 비활성 | 비활성 | 비활성 | 비활성 |

## 11. UI 문구 기준

모든 UI 문구는 한글을 기준으로 한다.

권장 문구:

```text
프로필
새 프로필
프로필 저장
프로필 삭제
프로필을 저장했습니다.
프로필은 최소 1개 이상 필요합니다.
서버 실행 중에는 프로필을 변경할 수 없습니다.
```
