## 1. 문서 목적

이 문서는 CarFight 차량 원화에서 **차급별 기본 비례를 어떻게 잡을지**를 정의한다.

CarFight의 차량 비례는 실제 자동차 스펙을 정확히 재현하기 위한 수치가 아니다.  
이 문서의 비례 기준은 AI 원화 생성, 3D 메쉬 제작, R1 Gameplay Mid 검수에서 차급이 쉽게 읽히도록 하기 위한 **상대 비례 기준**이다.

이 문서의 목적은 다음과 같다.

- 차급별 길이/폭/높이 인상을 정한다.
- 휠 크기와 차체 높이의 관계를 정한다.
- 보닛, 캐빈, 후방 공간의 비례 기준을 정한다.
- 장갑과 루프 마운트가 차량 비례를 망가뜨리는 한계를 정한다.
- C1 Simple Game Asset 기준에서 초보자가 수정 가능한 비례를 유지한다.
- 이후 `07_ArmorPanelRules.md`에서 장갑 패널 크기와 배치를 정할 기준선을 만든다.

## 3. 비례 판단 원칙

CarFight의 비례 판단은 다음 순서를 따른다.

1. 먼저 차급이 읽히는 길이/높이 인상을 잡는다.
2. 그다음 휠 크기와 휠 위치를 잡는다.
3. 그다음 보닛, 캐빈, 후방 공간을 큰 덩어리로 나눈다.
4. 그다음 장갑판과 루프 마운트를 얹는다.
5. 마지막으로 작은 디테일을 정한다.

중요 기준:

```text
장갑과 무기를 붙인 뒤에도 원래 차량 비례가 남아 있어야 한다.
```

피해야 할 판단:

- 실제 자동차 제원표처럼 정확한 수치를 먼저 맞추지 않는다.
- 멋있어 보인다는 이유로 차급 비례를 무너뜨리지 않는다.
- 무기와 장갑 크기로 차량 크기 인상을 결정하지 않는다.
- 휠을 과장해 장난감 같은 비례로 만들지 않는다.

## 4. 비례 용어 기준

이 문서에서는 정확한 미터 단위 대신 아래 상대 용어를 사용한다.

| 용어 | 의미 |
|---|---|
| 매우 짧음 | Microcar처럼 전체 길이가 가장 짧은 인상 |
| 짧음 | City Car, Subcompact처럼 압축된 인상 |
| 중간 | Compact, Coupe처럼 기본형에 가까운 인상 |
| 김 | Sedan, Wagon, Pickup처럼 앞뒤 길이가 있는 인상 |
| 매우 김 | Van처럼 길고 큰 면이 강한 인상 |
| 낮음 | Coupe, Sedan처럼 루프가 낮은 인상 |
| 중간 높이 | Compact, Subcompact처럼 기본형 높이 |
| 높음 | City Car, SUV, Van처럼 캐빈이 높은 인상 |
| 좁음 | Microcar, City Car처럼 작은 폭 인상 |
| 중간 폭 | Subcompact, Compact, Sedan, Coupe, Wagon |
| 넓음 | SUV, Van, Pickup처럼 굵은 차체 인상 |

이 용어는 원화와 모델링 판단을 위한 기준이다.  
게임 밸런스용 실제 크기 수치는 별도 문서에서 정할 수 있다.

## 5. 차급별 기본 비례

### 5.1 전체 비례 요약

| 차급 | 길이 | 폭 | 높이 | 핵심 비례 |
|---|---|---|---|---|
| Microcar | 매우 짧음 | 좁음 | 중간 | 짧고 작은 덩어리 |
| City Car | 짧음 | 좁음~중간 | 높음 | 짧고 높은 캐빈 |
| Subcompact | 짧음 | 중간 | 중간 | 작은 해치백 |
| Compact | 중간 | 중간 | 중간 | 균형 잡힌 기본형 |
| Sedan | 김 | 중간 | 낮음~중간 | 보닛-캐빈-트렁크 3박스 |
| Coupe | 중간 | 중간 | 낮음 | 낮은 루프와 짧은 캐빈 |
| Wagon | 김 | 중간 | 중간~높음 | 긴 루프와 후방 공간 |
| SUV | 중간~김 | 넓음 | 높음 | 높은 차체와 큰 휠 |
| Van | 매우 김 | 넓음 | 높음 | 긴 박스형 캐빈 |
| Pickup | 김 | 넓음 | 중간~높음 | 캐빈과 열린 짐칸 분리 |

차급 비례는 큰 덩어리로 먼저 맞춘다.  
라이트, 패널 라인, 장갑 고정구 같은 작은 디테일은 차급 비례를 대신할 수 없다.

---

### 5.2 Microcar

| 항목 | 기준 |
|---|---|
| 길이 | 매우 짧음 |
| 폭 | 좁음 |
| 높이 | 중간 |
| 휠 크기 | 작거나 중간. 과장 금지 |
| 보닛/캐빈/후방 | 보닛 짧음, 캐빈 작음, 후방 매우 짧음 |
| 장갑 허용 | 작은 전면/측면 장갑만 권장 |
| 루프 마운트 | 매우 작게 처리 |

유지할 비례:

```text
차체가 작고 짧다는 인상이 가장 먼저 보여야 한다.
```

피해야 할 것:

- 장갑을 키워 City Car나 SUV처럼 보이게 만들기
- 휠을 크게 키워 장난감처럼 보이게 만들기
- 루프 마운트를 차체보다 크게 보이게 만들기

---

|---|---|

| 폭 | 좁음~중간 |
| 높이 | 높음 |

- 차체를 길게 만들어 Compact처럼 보이게 만들기

## 6. 휠 비례 기준

휠은 차량이 민간 차량으로 읽히게 만드는 핵심 요소다.

권장 기준:

| 차급 | 휠 인상 |
|---|---|
| Microcar | 작음~중간 |
| City Car | 작음~중간 |
| Subcompact | 중간 |
| Compact | 중간 |
| Sedan | 중간 |
| Coupe | 중간 |
| Wagon | 중간 |
| SUV | 큼 |
| Van | 중간 |
| Pickup | 중간~큼 |

공통 기준:

- 휠은 R1에서 위치가 읽혀야 한다.
- 휠가드는 휠 위치를 가리지 않아야 한다.
- 큰 휠은 SUV/Pickup 인상을 강화할 때만 사용한다.
- 모든 차급에 큰 휠을 쓰면 차급 구분이 약해진다.
- Microcar/City Car에 큰 휠을 쓰면 장난감 비례가 되기 쉽다.

## 7. 장갑 추가 후 비례 제한

장갑은 차체 비례를 보강해야 한다.

권장 기준:

| 요소 | 제한 |
|---|---|
| 전면 장갑 | 보닛 길이와 전면 높이를 완전히 덮지 않음 |
| 측면 장갑 | 캐빈 위치와 휠 위치를 알아볼 수 있게 남김 |
| 후면 장갑 | 트렁크/해치/짐칸 인상을 가리지 않음 |
| 루프 장갑 | 루프 높이를 과하게 올리지 않음 |
| 휠가드 | 차체 폭을 과하게 넓히지 않음 |

실패 기준:

```text
장갑 추가 후 모든 차급이 SUV나 Van처럼 보이면 비례 조정 실패다.
```

## 8. 루프 마운트와 터렛 크기 기준

루프 마운트와 터렛은 차량보다 먼저 읽히면 안 된다.

권장 기준:

| 차급 | 루프 마운트 크기 |
|---|---|
| Microcar | 매우 작음 |
| City Car | 작음 |
| Subcompact | 작음~중간 |
| Compact | 중간 |
| Sedan | 작음~중간 |
| Coupe | 작음 |
| Wagon | 중간 |
| SUV | 중간 |
| Van | 중간 |
| Pickup | 작음~중간 |

공통 기준:

- 루프 마운트는 차급 루프라인을 완전히 가리지 않는다.
- 터렛은 차량보다 먼저 보이면 안 된다.
- 작은 차급에는 작은 마운트를 사용한다.
- 큰 차급이라도 루프 전체를 무기 플랫폼처럼 만들지 않는다.
- Top View에서 회전 공간과 차량 중심선이 읽혀야 한다.

## 9. C1 모델링 비례 검수

C1 Simple Game Asset 기준에서 비례 검수는 아래 순서로 한다.

1. 색상과 장식을 보기 전에 회색 박스 형태로 차급을 확인한다.
2. Side View에서 길이와 높이 인상을 확인한다.
3. 휠 크기와 위치가 차급과 맞는지 확인한다.
4. 보닛, 캐빈, 후방 공간이 큰 덩어리로 나뉘는지 확인한다.
5. 장갑과 루프 마운트를 붙인 뒤에도 차급이 유지되는지 확인한다.
6. R1 기준으로 축소해서 차급이 읽히는지 확인한다.

통과 질문:

- 차급의 길이/높이 인상이 먼저 읽히는가?
- 휠 크기가 차급과 맞는가?
- 보닛, 캐빈, 후방 공간이 큰 덩어리로 읽히는가?
- 장갑 추가 후에도 원래 차급이 남아 있는가?
- 루프 마운트가 차량보다 먼저 읽히지 않는가?

탈락 질문:

- 모든 차급이 비슷한 SUV형 덩어리로 보이는가?
- 휠이 과장되어 장난감처럼 보이는가?
- 무기와 장갑 때문에 원래 차량 비례가 사라졌는가?
- 실제 차량의 복잡한 곡면을 비례 기준으로 삼고 있는가?
- R1에서 차급이 읽히지 않는가?

## 10. AI 프롬프트 영향

AI 원화 생성 프롬프트에는 차급별 비례 문구를 함께 넣는다.

기본 형식:

```text
[Class Name],
[class silhouette phrase],
[class proportion phrase],
simplified near-future civilian combat car,
clean readable silhouette,
low modeling complexity,
large simple shapes,
large simple armor panels,
proportions readable at gameplay distance,
no real car brand,
no military armored vehicle,
no tank,
no toy-like oversized wheels,
no oversized roof weapon,
orthographic side/front/rear/top concept sheet,
plain background
```

차급별 비례 문구:

| 차급 | 비례 문구 |
|---|---|
| Microcar | very short narrow body, small cabin |
| City Car | short body, tall cabin |
| Subcompact | short hatchback proportions |
| Compact | balanced compact proportions |
| Sedan | long low three-box proportions |
| Coupe | low body, short cabin, sloped roof |
| Wagon | long roof, long rear cargo area |
| SUV | tall wide body, large wheels |
| Van | long tall boxy body |
| Pickup | separated cabin and open rear bed |

권장 금지 문구:

```text
no toy proportions,
no oversized wheels except SUV or pickup,
no oversized roof turret,
no armor hiding the original car proportions,
no tank-like wide low body,
no APC-like box armor
```

## 14. Migration

### v0.1 적용 시 기존 작업 영향

- 앞으로 차량 원화는 실제 차량 제원보다 차급이 읽히는 상대 비례를 먼저 검수한다.
- 기존에 생성된 차량 이미지가 있다면 다음 기준으로 재검토한다.
  - 길이/폭/높이 인상만으로 차급이 읽히는가?
  - 휠 크기가 차급에 맞는가?
  - 보닛, 캐빈, 후방 공간이 큰 덩어리로 구분되는가?
  - 장갑과 루프 마운트가 원래 차량 비례를 덮지 않는가?
  - R1 Gameplay Mid에서 차량보다 무기나 장갑이 먼저 읽히지 않는가?
- 비례가 실패한 차량은 작은 디테일을 추가하기 전에 큰 차체 비례를 먼저 수정한다.
- 이후 `07_ArmorPanelRules.md`는 이 문서의 비례 기준을 바탕으로 장갑판 크기와 배치 한계를 정한다.
