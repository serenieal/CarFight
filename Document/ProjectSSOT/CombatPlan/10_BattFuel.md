## 1. 핵심 정의

CarFight의 자원은 우주선식 에너지 / 열 자원이 아니라, 자동차 기반의 배터리, 연료, 탄약, 중량 자원이어야 한다.

플레이어가 관리해야 하는 전투 자원은 아래처럼 나눈다.

```text
01. 배터리
- 센서, 락온, 전자전, 능동 방어, 터렛 안정화에 쓰는 전장 전력

02. 연료
- 주행, 고출력 주행, 작전 지속력, 추격 / 이탈 여유와 연결되는 자동차 자원

03. 탄약
- 무기별 지속 전투력과 출격 전 피팅 전략을 결정하는 자원

04. 중량
- 배터리 용량, 연료량, 탄수, 장갑, 무기 장착량이 차량 성능에 주는 총합 비용

05. 무기별 열
- 차량 자원이 아니라 무기별 사격 제한 자원
```

---

## 2. 자원 시스템 기본 원칙

CarFight에서 자원은 단순 제한 장치가 아니라, 전투 선택을 만들기 위한 장치다.

```text
전투 전에 무엇을 얼마나 싣고 나갈지 결정한다.
→ 그 선택이 차량 중량과 성능을 바꾼다.
→ 전투 중에는 그 자원을 언제 쓸지 판단한다.
→ 자원이 부족해지면 전투 방식이 바뀐다.
```

| 선택 | 얻는 것 | 잃는 것 |
|---|---|---|
| 탄약을 많이 싣기 | 장기전 가능 | 중량 증가, 기동성 저하 |
| 연료를 많이 싣기 | 장거리 작전, 추격 / 이탈 여유 | 중량 증가 |
| 대용량 배터리 장착 | 센서 / 락온 / 방어장비 운용 강화 | 중량 / 슬롯 / 비용 증가 |
| 장갑을 많이 붙이기 | 생존력 증가 | 가속 / 제동 / 선회 저하 |
| 고화력 무기 장착 | 순간 화력 증가 | 중량, 무기 열, 각속도 부담 |

## 3. 배터리

### 3.1 정의

배터리는 자동차의 전장 전자장비를 움직이는 자원이다.

> 배터리는 총을 쏘기 위한 마나가 아니라, 센서 / 락온 / 터렛 안정화 / 방어장비 / 전자전 장비의 전력원이다.

이 원칙을 반드시 지켜야 한다. 배터리를 모든 무기 발사에 쓰면 CarFight가 다시 우주선식 에너지 전투처럼 느껴진다.

무기가 에너지 계열이라는 이유만으로 차량 배터리를 자동 소비한다고 가정하지 않는다.

```text
Vehicle Battery
= 센서, 락온, 안정화, 능동 방어와 전자전의 차량 전장 전력

Weapon Charge
= 특정 무기 내부의 충전 또는 발사 준비 자원
```

레일건처럼 차량 전력을 직접 사용하는 무기는 해당 무기 데이터에서 명시적으로 Vehicle Battery 소비를 선언한다. 독립 축전기나 내부 충전을 사용하는 무기는 Weapon Charge를 별도 자원으로 관리한다.

### 3.2 배터리 사용처

| 사용처 | 설명 |
|---|---|
| 센서 강화 | 탐지 거리 증가, 정보 품질 향상 |
| 빠른 락온 | 락온 시간 단축 |
| 락온 유지 보조 | 빠른 목표를 추적할 때 안정도 유지 |
| 터렛 안정화 | 조준 흔들림 감소, 안정화 시간 감소 |
| 짐벌 보정 강화 | 제한 시간 동안 추적 성능 향상 |
| 능동 방어 | 연막, 플레어, 요격장치 |
| 전자전 | 재밍, EMP 대응, 센서 교란 |
| 특수 전자기 무기 | 레일건 / 코일건 계열, P1 이후 |

### 3.3 배터리 부족 시 효과

배터리가 부족하다고 차량이 멈추면 안 된다. 주행은 연료와 엔진의 영역이다.

| 배터리 상태 | 전투 영향 |
|---|---|
| 충분함 | 센서 / 락온 / 방어장비 정상 사용 |
| 낮음 | 락온 시간 증가, 터렛 안정화 저하 |
| 매우 낮음 | 연막 / 플레어 / 전자전 사용 제한 |
| 고갈 | 락온 보조, 능동 방어, 전자전 대부분 불가 |

```text
배터리 고갈 = 전자장비 전투력이 약해짐
배터리 고갈 ≠ 차량 주행 불가
```

### 3.4 배터리와 피팅

배터리는 피팅 선택이어야 한다.

| 배터리 선택 | 장점 | 단점 |
|---|---|---|
| 소형 배터리 | 가벼움 | 전자장비 운용 짧음 |
| 표준 배터리 | 균형형 | 특화 없음 |
| 대용량 배터리 | 락온 / 방어장비 오래 사용 | 무거움 |
| 고출력 배터리 | 순간 출력 좋음 | 회복 / 지속력 낮을 수 있음 |
| 차폐 배터리 | EMP 저항 | 중량 / 비용 증가 |

### 3.5 P0 배터리 방향

```text
P0 배터리:
- 단일 배터리 게이지
- 락온 중 천천히 소모
- 연막 / 플레어 사용 시 일정량 소모
- 배터리가 낮으면 락온 속도 저하
```

## 4. 연료

### 4.1 정의

연료는 자동차 정체성을 가장 강하게 보여주는 자원이다.

> 연료는 순간 스킬 자원이 아니라, 작전 지속력 / 추격 / 이탈 / 고출력 주행을 결정하는 자동차 자원이다.

연료를 자주 깎이는 마나처럼 만들면 피로감이 커진다. 대신 전투 전 피팅과 전투 후 지속성에 영향을 주는 것이 좋다.

### 4.2 연료가 영향을 주는 것

| 항목 | 설명 |
|---|---|
| 작전 거리 | 얼마나 멀리 이동하고 오래 싸울 수 있는가 |
| 추격 지속력 | 도망가는 적을 얼마나 오래 쫓을 수 있는가 |
| 이탈 능력 | 불리할 때 고출력 주행으로 빠질 수 있는가 |
| 고출력 주행 | 급가속, 부스트, 험지 탈출 |
| 차량 중량 | 연료를 많이 싣는 만큼 무거워짐 |
| 피격 위험 | P1 이후 연료 계통 손상 / 화재와 연결 가능 |

### 4.3 연료 소비 구조

연료는 기본 주행마다 너무 눈에 띄게 줄면 안 된다.

| 행동 | 연료 소비 방향 |
|---|---|
| 일반 주행 | 낮음 |
| 고속 주행 | 중간 |
| 부스트 / 고출력 주행 | 높음 |
| 험지 / 오르막 / 무거운 차량 | 증가 가능 |
| 엔진 손상 상태 | 효율 저하 가능 |
| 정지 / 저속 대기 | 거의 없음 |

### 4.4 연료 부족 시 효과

| 연료 상태 | 전투 영향 |
|---|---|
| 충분함 | 정상 주행 |
| 낮음 | 장기 추격 / 이탈 판단 필요 |
| 매우 낮음 | 부스트 사용 제한 |
| 고갈 | P0에서는 전투 중 고갈까지는 비추천 |

P0에서는 연료를 너무 직접적으로 벌주는 것보다, 출격 중량과 고출력 주행 제한에 연결한다.

```text
P0 연료:
- 출격 시 연료량 선택 가능
- 연료량은 중량에 반영
- 부스트 / 고출력 주행에만 의미 있게 소비
- 연료 고갈로 차량 완전 정지는 P0에서 제외
```

## 5. 탄약 / 탄수

### 5.1 정의

탄약은 CarFight에서 가장 중요한 피팅 자원 중 하나다.

> 탄약은 단순 잔탄 숫자가 아니라, 전투 지속력과 차량 중량을 동시에 결정하는 출격 자원이다.

플레이어는 출격 전에 아래를 선택해야 한다.

```text
이번 전투는 짧게 끝낼 것인가?
장기전을 준비할 것인가?
철갑탄을 많이 챙길 것인가?
고폭탄을 섞을 것인가?
기동성을 위해 탄을 줄일 것인가?
```

### 5.2 탄약이 영향을 주는 것

| 항목 | 설명 |
|---|---|
| 전투 지속력 | 오래 싸울 수 있는가 |
| 무기 운용 | 어떤 무기를 계속 쓸 수 있는가 |
| 탄종 대응력 | 장갑 / 모듈 / 경량 / 중량 대응 가능 여부 |
| 차량 중량 | 탄수가 많고 무거운 탄종일수록 증가 |
| 기동성 | 중량 증가로 가속 / 선회 / 제동 저하 |
| 심리 압박 | 잔탄 부족 시 교전 선택이 보수적으로 변함 |

### 5.3 탄수와 중량

탄약은 반드시 중량에 반영되어야 한다.

| 탄약 선택 | 결과 |
|---|---|
| 적게 싣기 | 가볍고 민첩하지만 장기전 불리 |
| 많이 싣기 | 오래 싸우지만 둔해짐 |
| 일반탄 중심 | 가볍고 오래 싸움 |
| 철갑탄 중심 | 중장갑 대응 강하지만 무거움 |
| 고폭탄 중심 | 모듈 압박 강하지만 중량 / 부피 부담 |
| 미사일 다량 | 압박력 좋지만 매우 무거움 |

```text
탄약을 많이 싣는 것은 보험이 아니라 중량을 지불하는 전략 선택이다.
```

## 6. 무기별 열

### 6.1 정의

열은 차량 자원이 아니라 무기별 자원이다.

> 뜨거워지는 것은 자동차 전체가 아니라, 계속 사격한 무기다.

따라서 무기 열은 반드시 무기 단위로 관리한다.

### 6.2 무기 열 상태

| 상태 | 설명 |
|---|---|
| 정상 | 일반 사격 가능 |
| 가열 | 명중률 / 분산에 약간 영향 가능 |
| 과열 직전 | UI 경고 |
| 과열 | 해당 무기만 일정 시간 사격 불가 |
| 냉각 | 시간이 지나거나 냉각 장비로 회복 |

### 6.3 무기 열과 다른 자원의 차이

| 자원 | 성격 |
|---|---|
| 배터리 | 전자장비 운용 자원 |
| 연료 | 주행 / 작전 지속 자원 |
| 탄약 | 사격 지속 자원 |
| 무기 열 | 무기별 사격 리듬 제한 |
| 중량 | 피팅 선택의 총 비용 |

```text
배터리 부족 → 락온 / 센서 / 방어장비 약화
연료 부족 → 추격 / 이탈 / 고출력 주행 약화
탄약 부족 → 해당 무기 지속 교전 불가
무기 내부 충전 부족 → 해당 무기의 충전 발사 불가
무기 과열 → 해당 무기만 잠시 사용 불가
중량 증가 → 차량 기동성 저하
```

### 6.4 무기 내부 충전과 재사용 대기시간

무기 내부 충전과 재사용 대기시간은 탄약, 차량 배터리와 무기 열을 대체하는 통합 자원이 아니다.

| 자원 | 의미 |
|---|---|
| 무기 내부 충전 | 무기 자체 축전기 또는 발사 준비량 |
| 재사용 대기시간 | 다음 행동까지의 시간 제한 |
| 재장전 | 탄약을 장전부로 옮기는 행동 상태 |
| 무기 열 | 지속 사격으로 발생한 사격 제한 자원 |

하나의 무기가 여러 자원을 동시에 사용할 수 있다.

## 7. 중량

### 7.1 정의

중량은 자원 시스템 전체를 묶는 비용이다.

> 중량은 CarFight의 피팅 선택을 자동차답게 만드는 핵심 비용이다.

EVE Online식 피팅에서는 전력, CPU, 슬롯 같은 추상 자원이 중요하지만, CarFight에서는 중량이 가장 직관적인 제약이 되어야 한다.

### 7.2 중량을 증가시키는 요소

| 요소 | 중량 영향 |
|---|---|
| 차체 기본 중량 | 차급별 기본값 |
| 장갑 | 두꺼울수록 증가 |
| 무기 | 대구경 / 터렛 / 미사일 런처일수록 증가 |
| 탄약 | 탄수와 탄종에 따라 증가 |
| 연료 | 많이 넣을수록 증가 |
| 배터리 | 대용량일수록 증가 |
| 방어장비 | 요격장치, 수리장치, 차폐장비 등 |
| 설치물 / 지뢰 | 다량 적재 시 증가 |

### 7.3 중량이 영향을 주는 요소

| 차량 성능 | 영향 |
|---|---|
| 가속 | 무거울수록 느림 |
| 제동 | 제동거리 증가 |
| 선회 | 둔해짐 |
| 최고속도 | 일정 이상 중량에서 감소 |
| 접지 | 긍정 / 부정 양쪽 가능 |
| 충돌 | 무거운 차량이 일부 유리 |
| 연료 소비 | 무거울수록 증가 가능 |
| 무기 각속도 대응 | 둔해질수록 빠른 적 대응 어려움 |

중량은 무조건 나쁜 것만은 아니다.

| 무거운 차량의 장점 | 설명 |
|---|---|
| 충돌 안정성 | 가벼운 차량을 밀어붙이기 좋음 |
| 반동 안정성 | 대구경 무기 운용에 유리하게 설정 가능 |
| 정면 압박 | 중장갑과 궁합 좋음 |
| 지속전 | 탄약 / 연료 / 장비를 많이 실을 수 있음 |

하지만 대가도 확실해야 한다.

```text
무거운 차량은 버티고 압박하는 데 강하다.
하지만 빠른 차량을 직접 쫓거나 각속도 싸움을 하는 데 약하다.
```

## 8. 자원별 전투 중 직접 소비 정도

각 자원은 전투 중 소비 체감이 달라야 한다.

| 자원 | 전투 중 소비 체감 | 방향 |
|---|---|---|
| 배터리 | 중간 ~ 높음 | 락온 / 방어장비 / 전자전 사용할 때 줄어듦 |
| 연료 | 낮음 ~ 중간 | 일반 주행보다 부스트 / 고출력 주행에서 의미 있게 줄어듦 |
| 탄약 | 높음 | 사격할 때 직접 줄어듦 |
| 무기 열 | 높음 | 사격 리듬에 직접 영향 |
| 중량 | 소비 안 됨 | 출격 전 선택이 전투 내내 영향 |

---

## 9. 자원 부족이 만드는 전투 상황

### 9.1 배터리 부족

```text
락온이 느려진다.
연막 / 플레어 / 요격장치를 아껴야 한다.
터렛 안정화 보조를 못 쓴다.
전자전 대응력이 약해진다.
```

플레이어 판단:

> 지금 미사일을 쏘기 위해 배터리를 쓸까, 아니면 방어장비용으로 남길까?

### 9.2 연료 부족

```text
부스트를 아껴야 한다.
장기 추격이 어려워진다.
이탈 타이밍을 빨리 잡아야 한다.
무거운 피팅의 부담이 커진다.
```

플레이어 판단:

> 지금 끝까지 추격할까, 아니면 연료를 아끼고 재정비할까?

### 9.3 탄약 부족

```text
무기 선택이 제한된다.
탄종 전환 선택지가 줄어든다.
마무리 실패 시 위험해진다.
장기전에서 불리해진다.
```

플레이어 판단:

> 고폭탄을 바퀴에 쓸까, 아껴서 마무리용으로 남길까?

### 9.4 무기 과열

```text
해당 무기를 잠시 못 쓴다.
보조 무기로 전환해야 한다.
엄폐 / 이탈 / 재접근 타이밍이 생긴다.
```

플레이어 판단:

> 지금 과열을 감수하고 마무리할까, 아니면 식히고 다시 들어갈까?

### 9.5 중량 과다

```text
가속이 느리다.
선회가 둔하다.
제동거리가 길다.
빠른 적의 각속도 플레이에 약하다.
```

플레이어 판단:

> 장갑과 탄약을 줄이고 기동성을 챙길까, 아니면 느리더라도 버티는 세팅으로 갈까?

## 10. 자원 간 상호작용

| 연결 | 의미 |
|---|---|
| 탄약 ↔ 중량 | 많이 싣거나 무거운 탄종이면 차량이 둔해짐 |
| 연료 ↔ 중량 | 많이 넣으면 오래 움직이지만 무거워짐 |
| 장갑 ↔ 중량 | 방어력은 오르지만 기동성 저하 |
| 배터리 ↔ 중량 | 전자장비 운용력은 오르지만 차량이 무거워짐 |
| 무기 ↔ 무기 열 | 강한 무기일수록 열 / 재장전 부담 |
| 무기 ↔ 중량 | 대구경 / 터렛 / 미사일은 차량 성능에 부담 |
| 배터리 ↔ 락온 | 락온을 빠르고 안정적으로 유지하려면 배터리 필요 |
| 연료 ↔ 추격 / 이탈 | 고출력 주행과 장기 추격에 필요 |

## 11. P0 최소 자원 체계

| 자원 | P0 구현 | 이유 |
|---|---|---|
| 배터리 | 포함 | 락온 / 연막 / 방어장비 검증 |
| 연료 | 제한적 포함 | 중량 / 부스트 / 작전 지속력 검증 |
| 탄약 | 포함 | 탄종 / 탄수 / 피팅 검증 |
| 무기별 열 | 포함 | 사격 리듬 검증 |
| 중량 | 포함 | 자동차 피팅 정체성 검증 |

### 11.1 P0 배터리

```text
- 단일 게이지
- 락온 중 초당 소모
- 연막 / 플레어 사용 시 일정량 소모
- 배터리 부족 시 락온 시간 증가
- 배터리 0이어도 주행은 가능
```

### 11.2 P0 연료

```text
- 출격 시 연료량 선택
- 연료량은 중량에 반영
- 부스트 / 고출력 주행 시 소모
- P0에서는 일반 주행 연료 소모는 낮게
- 연료 고갈로 차량 정지는 제외
```

### 11.3 P0 탄약

```text
- 무기별 탄약 보유
- 탄종별 탄수 선택
- 탄종별 중량 반영
- 일반탄 / 철갑탄 / 고폭탄 3종
```

### 11.4 P0 무기 열

```text
- 무기별 열 게이지
- 사격 시 증가
- 시간이 지나면 감소
- 과열 시 해당 무기만 일정 시간 사격 불가
```

### 11.5 P0 중량

```text
- 기본 차체 중량
- 장갑 중량
- 무기 중량
- 탄약 중량
- 연료 중량
- 배터리 중량
- 총중량이 가속 / 제동 / 선회에 영향
```

## 13. 좋은 플레이가 만들어야 하는 판단

탄을 많이 챙기면 오래 싸우지만 차가 둔해진다.
철갑탄을 많이 챙기면 중장갑은 잘 잡지만 경량 차량전에서 무겁다.

연료를 아끼지 않으면 이탈할 때 부스트 여유가 없다.

## 14. 게임플레이 자원과 UI 표시 계약

탄약, 차량 배터리, 무기 내부 충전, 무기 열, 재사용 대기시간과 재장전 상태를 하나의 게임플레이 수치로 통합하지 않는다.

```text
게임플레이 자원
→ 서로 다른 규칙과 소유 시스템 유지

UI 표시
→ 공통 Resource View Data 채널 사용 가능
```

권장 UI 채널 정보:

```text
ResourceType
CurrentValue
MaximumValue
NormalizedValue
PrimaryDisplayText
SecondaryDisplayText
ResourceState
```

권장 ResourceType:

```text
Ammo
ReserveAmmo
VehicleBattery
WeaponCharge
Heat
Cooldown
Reload
None
```

공통 UI 채널은 표시 재사용을 위한 계약이지, 자원 규칙을 하나로 합치는 시스템이 아니다.

## 15. 자원 UI 방향

자원 시스템은 UI가 명확해야 한다.

| UI | 표시 내용 |
|---|---|
| 배터리 게이지 | 현재 배터리 잔량 |
| 연료 게이지 | 현재 연료 잔량 또는 작전 지속력 |
| 무기별 잔탄 | 무기 / 탄종별 남은 탄수 |
| 무기별 열 | 현재 장착 무기의 과열 상태 |
| 총중량 표시 | 출격 전 피팅 화면에서 표시 |
| 중량 영향 표시 | 가속 / 제동 / 선회 변화량 |
| 락온 배터리 소모 표시 | 락온 중 배터리 사용 여부 |
| 방어장비 사용 가능 표시 | 연막 / 플레어 재사용 가능 여부 |

전투 중 UI는 너무 복잡하면 안 된다.

전투 중에는 현재 필요한 자원만 크게 보여주고, 자세한 중량 / 연료 계산은 피팅 화면에서 보여준다.

## 16. 결정안

```text
CarFight Resource System v0.2.0

핵심 정의:
CarFight의 전투 자원은 배터리, 연료, 탄약, 무기별 열, 중량으로 구성된다.
이 자원들은 우주선식 에너지 관리가 아니라 자동차 기반 출격 준비와 전투 운용을 표현한다.

01. 배터리
- 센서, 락온, 터렛 안정화, 방어장비, 전자전에 사용한다.
- 총을 쏘는 마나가 아니다.
- 고갈되어도 차량 주행과 물리 무기 사격은 가능하다.

02. 연료
- 주행, 고출력 주행, 추격, 이탈, 작전 지속력에 연결된다.
- 순간 스킬 자원이 아니라 자동차 작전 자원이다.
- 많이 싣는 만큼 중량이 증가한다.

03. 탄약
- 무기별 지속 전투력을 결정한다.
- 탄종과 탄수는 출격 전 피팅 선택이다.
- 많이 싣거나 무거운 탄종을 선택하면 차량 성능이 떨어진다.

04. 무기별 열
- 차량 전체 열이 아니라 무기별 사격 제한 자원이다.
- 과열되면 해당 무기만 잠시 사격 불가가 된다.

05. 중량
- 차체, 장갑, 무기, 탄약, 연료, 배터리, 방어장비의 총합 비용이다.
- 가속, 제동, 선회, 최고속도, 연료 소비에 영향을 준다.

06. 무기 내부 충전과 UI 계약
- Weapon Charge는 차량 배터리와 다른 무기별 자원일 수 있다.
- 에너지 무기라는 이유만으로 차량 배터리를 자동 소비하지 않는다.
- 탄약, 배터리, 충전, 열, 쿨다운과 재장전은 독립 규칙을 유지한다.
- UI 표현만 공통 Resource View Data 채널로 통합한다.

P0 최소 구현:
- 배터리 게이지
- 연료량과 중량 반영
- 탄종 / 탄수 / 중량 반영
- 무기별 열 게이지
- 총중량에 따른 주행 성능 변화
```
