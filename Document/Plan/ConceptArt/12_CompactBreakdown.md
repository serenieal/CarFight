## 1. 문서 목적

이 문서는 `11_AIPromptRules_CompactPreview.png` 이미지를 기준으로 Compact 차량 후보를 **C1 Simple Game Asset 제작 단위**로 분해한다.

이 문서는 새 차량 규칙을 만드는 문서가 아니다.  
이 문서는 기존 ConceptArt 기준을 실제 3D 메쉬 제작에 옮기기 위한 첫 번째 실전 분해표다.

목적은 다음과 같다.

- AI 생성 Compact 후보를 실제 모델링 파츠 단위로 나눈다.
- 어떤 요소를 메쉬로 만들고 어떤 요소를 텍스처/노멀/머티리얼로 넘길지 정한다.
- 파츠 수가 C1 권장 범위인 10~16개 안에 들어오는지 확인한다.
- AI 모델링 결과를 초보자가 검수·후처리하기 쉬운 순서를 제안한다.
- 이후 같은 방식으로 Sedan, SUV, Pickup 후보도 분해할 수 있는 기준 예시를 만든다.

## 3. C1 파츠 분해 원칙

이 후보는 다음 원칙으로 분해한다.

1. 차량 차급을 만드는 큰 덩어리를 먼저 만든다.
2. 휠 4개는 분리 파츠로 둔다.
3. 유리는 하나의 통합 파츠 또는 3개 이하 파츠로 둔다.
4. 장갑은 큰 판형만 메쉬로 만든다.
5. 루프 하드포인트는 별도 파츠로 둔다.
6. 작은 볼트, 얇은 패널선, 스크래치, 라벨은 텍스처/노멀 처리한다.

기준 문장:

```text
이 차량은 작은 디테일을 많이 만드는 것이 아니라, 큰 파츠를 정확히 나누는 것이 목표다.
```

AI 모델링 전제:

```text
이 분해표는 사람이 처음부터 직접 모델링하기 위한 목록이 아니라, AI 모델링 결과가 어떤 파츠로 나뉘어야 통과인지 판단하는 검수 기준이다.
```

## 5. 선택적으로 합칠 수 있는 파츠

제작 시간이 부족하면 아래처럼 파츠를 합칠 수 있다.

| 합치기 전 | 합친 뒤 | 이유 |
|---|---|---|
| Armor_Front + Bumper_Front | Front_ArmorBlock | 전면 구조를 단순화 |
| Armor_Rear + Bumper_Rear | Rear_ArmorBlock | 후면 구조를 단순화 |
| WheelGuard_FLFR + WheelGuard_RLRR | WheelGuard_Set | 휠가드 형태가 비슷할 때 관리 단순화 |
| Sensor_Light + Mount_Roof | Mount_Roof | 센서가 작으면 별도 파츠 불필요 |
| Glass_Main + Body_Main | Body_Main material slot | 유리를 단순 면/머티리얼로만 처리할 때 |

최소 제작 파츠 목표:

```text
10~12개
```

사용 기준:

- 첫 모델링 시도에서는 10~12개로 줄여도 된다.
- 이후 수정 여유가 있으면 장갑, 범퍼, 마운트만 다시 분리한다.
- 휠 4개와 루프 마운트는 기능 연결 가능성이 있으므로 가능한 한 분리한다.

## 6. 텍스처/노멀 처리 대상

아래 요소는 기본 C1 메쉬 파츠로 만들지 않는다.

| 요소 | 권장 처리 |
|---|---|
| 작은 볼트 | 텍스처/노멀 |
| 얇은 패널 라인 | 텍스처/노멀 |
| 문 손잡이 | 텍스처 또는 단순 돌출 |
| 작은 경고 라벨 | 텍스처 |
| 작은 스크래치 | 텍스처 |
| 장갑판 표면 마모 | 텍스처 |
| 타이어 세부 홈 | 노멀/텍스처 우선 |
| 미세한 센서 내부 구조 | 머티리얼/발광 텍스처 |

기준 문장:

```text
R1 Gameplay Mid에서 읽히지 않는 작은 정보는 메쉬로 만들지 않는다.
```

## 7. 머티리얼 슬롯 후보

이 후보는 아래 6개 슬롯으로 정리한다.

| 슬롯 | 이름 | 적용 대상 |
|---|---|---|
| M01 | Painted_Body | 차체 도장 |
| M02 | Matte_Armor | 장갑판, 보강 범퍼 |
| M03 | Dark_Glass | 전면/측면/후면 유리 |
| M04 | Rubber_Tire | 타이어 |
| M05 | Utility_Plastic | 휠가드, 마운트 하우징, 트림 |
| M06 | Emissive_Decal | 센서등, 작은 발광 포인트 |

권장 기준:

- `M01`과 `M02`의 명도 차이로 차체와 장갑을 구분한다.
- `M06`은 작은 포인트로만 사용한다.
- 실제 브랜드 로고나 레이싱 리버리는 넣지 않는다.

## 8. AI 모델링 검수/후처리 순서

AI 모델링 결과를 받은 뒤 아래 순서로 검수하고 후처리한다.

1. `Body_Main`이 단순 해치백 덩어리로 생성되었는지 확인한다.
2. 휠 4개 위치와 좌우/전후 대칭이 맞는지 확인한다.
3. `Glass_Main` 영역이 큰 유리 면으로 읽히는지 확인한다.
4. 전면/측면/후면 장갑판이 큰 판형으로 분리 가능한지 확인한다.
5. 전후 범퍼 보강대가 차체와 과하게 섞이지 않았는지 확인한다.
6. 휠가드가 너무 얇거나 복잡하지 않은지 확인한다.
7. 루프 중앙의 `Mount_Roof` 위치와 피벗 후보가 명확한지 확인한다.
8. 작은 센서등은 메쉬보다 머티리얼 포인트로 정리 가능한지 확인한다.
9. 작은 볼트/패널선이 과한 기하 구조로 생성되었다면 텍스처 처리 대상으로 낮춘다.

중요:

```text
AI 결과에 모든 작은 디테일이 메쉬로 생성되어 있으면 C1 후보로 보지 않는다.
```

## 12. Migration

### v0.2 적용 시 기존 작업 영향

- 이 문서는 사람이 처음부터 모델링하는 순서표가 아니라 AI 모델링 결과를 판정하는 체크 기준으로 사용한다.
- `Body_Main`, 휠, 유리, 장갑, 루프 마운트가 AI 결과에서 분리·식별되지 않으면 재생성 또는 단순화한다.
- 작은 볼트/패널선이 실제 기하 구조로 과생성된 결과는 C1 후보에서 제외하거나 텍스처 처리 기준으로 낮춘다.

### v0.1 적용 시 기존 작업 영향

- `11_AIPromptRules_CompactPreview.png`는 Compact C1 후보 검토 이미지로 유지한다.
- 이 문서는 기존 ConceptArt 기준을 바꾸지 않고, 첫 Compact 후보에 적용한 실전 분해표로 사용한다.
- 이후 다른 차급 후보를 만들 때도 이 문서의 파츠 분해 방식과 머티리얼 슬롯 구조를 참고한다.
- 실제 3D 제작 중 파츠 수가 20개를 넘으면 `02_ComplexityBudget.md` 기준에 따라 단순화한다.
