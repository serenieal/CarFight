---

## 1. 목적

이 문서는 CarFight의 첫 전투 프로토타입에서 무엇을 반드시 검증해야 하는지 정의한다.

P0의 목표는 모든 시스템을 완성하는 것이 아니다. 목표는 CarFight의 전투 정체성, 즉 `차량 기동 + 직접 조준 + 피팅/중량 + 무기 각속도 + 무기별 열 + 락온 대응`이 실제로 재미있는지 확인하는 것이다.

---

## 2. P0 핵심 검증 질문

```text
01. 차량을 잘 몰면 유리한 사격 위치를 만들 수 있는가?
02. 같은 무기라도 거리와 각도에 따라 결과가 달라지는가?
03. 큰 무기는 강하지만 빠른 목표를 따라가기 어려운가?
04. 탄약/장갑/연료를 많이 싣는 선택이 차량 성능을 바꾸는가?
05. 무기를 계속 쏘면 해당 무기만 과열되는가?
06. 락온은 강하지만 엄폐/연막/횡이동으로 대응 가능한가?
07. 바퀴/엔진/터렛 손상이 전투 흐름을 바꾸는가?
```

---

## 3. P0 전투 루프

```text
탐지
→ 접근
→ 거리/각도 잡기
→ 조준
→ 사격
→ 무기 과열/재장전
→ 모듈 손상
→ 재접근 또는 이탈
→ 파괴 또는 무력화
```

P0는 이 루프가 1대1 전투에서 성립하는지 먼저 확인한다.

---

## 4. P0 포함 시스템

| 시스템 | 포함 범위 |
|---|---|
| 차량 기동 | 가속, 제동, 선회, 속도 차이 |
| 거리/각도 | 거리별 무기 효율, 정면/측면/후면 피해 차이 |
| 조준 | 고정, 짐벌, 터렛, 락온 기본형 |
| 무기 각속도 | 짐벌/터렛 추적 속도와 안정화 |
| 무기 열 | 무기별 열 게이지, 과열 시 해당 무기 사격 불가 |
| 탄종 | 일반탄, 철갑탄, 고폭탄 |
| 방어 | 차체 HP, 장갑 타입 3종, 방향별 피해 계수 |
| 모듈 | 바퀴, 엔진, 터렛 |
| 자원 | 배터리, 연료량, 탄약, 중량 |
| 락온 | 락온 게이지, 배터리 소모, 엄폐/연막 대응 |
| UI | 조준점, 무기 실제 조준점, 열/탄약/배터리/락온/손상 표시 |
| AI | 추격형, 중거리형, 중장갑형, 락온형 |

## 5. P0 무기 구성

| 무기 | 조준 방식 | 검증 목적 |
|---|---|---|
| 소형 짐벌 기관총 | 짐벌 | 빠른 각속도와 초보자 기준 무기 |
| 전방 고정 오토캐논 | 고정 | 차체 조준과 중거리 직접 전투 |
| 대구경 저속 터렛포 | 터렛 | 강하지만 느린 무기의 약점 |
| 경량 락온 미사일 | 락온 | 배터리/락온/대응 구조 |
| 연막 또는 플레어 | 유틸리티 | 락온 대응 수단 |

---

## 6. P0 탄종과 방어

| 탄종 | 역할 |
|---|---|
| 일반탄 | 기준 탄종, 가볍고 범용적 |
| 철갑탄 | 중장갑/정면 대응, 무거움 |
| 고폭탄 | 바퀴/터렛/하부/상부 모듈 피해 |

| 방어 요소 | 범위 |
|---|---|
| 장갑 타입 | 경량 / 표준 / 중장갑 |
| 피격 방향 | 정면 / 측면 / 후면, 상부/하부는 단순 보정 |
| 모듈 | 바퀴 / 엔진 / 터렛 |

---

## 7. P0 피팅 범위

```text
01. 차체 1~2종
02. 장갑 타입 선택
03. 무기 4종 장착
04. 탄종/탄수 선택
05. 연료량 선택
06. 단일 배터리 게이지
07. 총중량 계산
08. 총중량에 따른 가속/제동/선회 변화
```

P0에서는 차급을 많이 늘리지 않는다. 차량 1~2개에서 피팅 차이만으로 감각이 달라지는지 확인한다.

## 8. P0 제외 시스템

| 제외 | 이유 |
|---|---|
| 소이탄 | 화재/연료 계통 상태 시스템 필요 |
| EMP탄/재밍 | 센서/전자전 UI가 먼저 필요 |
| 레일건/코일건 | 배터리/열/관통 복잡도 증가 |
| 수동 유도 무기 | 조작 UX 부담 큼 |
| 지뢰/설치물 | 맵/AI 부담 큼 |
| 복잡한 센서 타입 | P0 검증 범위 초과 |
| 다중 락온 | UI 복잡도 증가 |
| 세부 경제/수리/회수 | 전투 감각 검증 후 진행 |

## 9. P0 성공 기준

P0는 아래 감각이 확인되면 성공이다.

```text
01. 플레이어가 좋은 위치를 만들면 유리하다고 느낀다.
02. 빠른 차량이 느린 대구경 무기의 각속도 한계를 이용할 수 있다.
03. 중장갑 차량은 정면으로 강하지만 측후면이 위험하다.
04. 무기별 열 때문에 쏘고 쉬는 리듬이 생긴다.
05. 탄약/장갑/연료/배터리 중량이 피팅 선택으로 체감된다.
06. 락온은 위협적이지만 대응 가능하다.
07. 모듈 손상으로 전투 흐름이 바뀐다.
```

## 10. 핵심 원칙

```text
01. P0는 완성형 전투가 아니라 방향성 검증이다.
02. 시스템 수보다 상호작용이 중요하다.
03. 무기, 차량, 탄약, 중량, UI, AI가 같은 원칙을 따라야 한다.
04. P0에서 재미가 확인된 시스템만 P1에서 확장한다.
```
