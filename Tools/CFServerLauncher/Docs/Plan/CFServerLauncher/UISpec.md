# CFServerLauncher UI 구성안

문서 버전: v1.0.0  
작성 기준일: 2026-05-26

## 1. UI 목표

v1.0 UI는 서버 설정, 실행 제어, 상태 확인, 실행 인자 미리보기, 최근 로그 확인을 한 화면에서 처리한다.

복잡한 탭 구조는 사용하지 않는다. 서버 운영에 필요한 값이 한눈에 보여야 한다.

## 2. 창 제목

권장 창 제목은 다음 중 하나이다.

```text
CarFight 서버 런처
```

또는

```text
CarFight Dedicated Server Launcher
```

v1.0에서는 한글 문구를 우선하므로 `CarFight 서버 런처`를 기본으로 한다.

## 3. 전체 화면 배치

```text
┌────────────────────────────────────────────┐
│ CarFight 서버 런처                         │
├────────────────────────────────────────────┤
│ 서버 설정                                  │
│ - 서버 실행 파일                           │
│ - 작업 폴더                                │
│ - 맵 경로                                  │
│ - 포트                                     │
│ - 로그 파일                                │
│ - 추가 인자                                │
├────────────────────────────────────────────┤
│ 실행 제어 / 상태                           │
│ [서버 시작] [서버 종료] [설정 저장] ...    │
│ 상태, PID, 시작 시각, 종료 코드, 오류       │
├────────────────────────────────────────────┤
│ 실행 인자 미리보기                         │
├────────────────────────────────────────────┤
│ 최근 서버 로그                             │
└────────────────────────────────────────────┘
```

## 4. 서버 설정 영역

| UI 문구 | 컨트롤 | 기본값 |
|---|---|---|
| 서버 실행 파일 | TextBox + 찾아보기 | `CarFight_ReServer.exe` 절대 경로 |
| 작업 폴더 | TextBox + 찾아보기 | 스테이징 서버 루트 |
| 맵 경로 | TextBox | `/Game/Maps/TestMap` |
| 포트 | TextBox | `7777` |
| 로그 파일 | TextBox + 찾아보기 | `Tools\CFServerLauncher\Logs\server.log` |
| 추가 인자 | TextBox | 빈 문자열 |

## 5. 실행 제어 영역

| 버튼 문구 | 동작 |
|---|---|
| 서버 시작 | 현재 설정을 검증한 뒤 서버를 실행한다. |
| 서버 종료 | 런처가 실행한 서버 프로세스를 종료한다. |
| 설정 저장 | 현재 입력값을 JSON으로 저장한다. |
| 설정 불러오기 | JSON 설정을 다시 읽어 UI에 반영한다. |
| 기본값 적용 | 프로젝트 기본 경로와 기본 포트로 되돌린다. |
| 로그 지우기 | UI에 표시된 로그만 지운다. 로그 파일은 삭제하지 않는다. |

## 6. 상태 표시 영역

| UI 문구 | 예시 |
|---|---|
| 상태 | 실행 중 |
| PID | 15432 |
| 시작 시각 | 2026-05-26 14:35:10 |
| 종료 코드 | 0 |
| 마지막 오류 | 서버 실행 파일을 찾을 수 없습니다. |

상태는 `RunState` enum을 한글 문구로 변환해 표시한다.

## 7. 실행 인자 미리보기 영역

실행 인자 미리보기는 읽기 전용 TextBox로 표시한다.

예시:

```text
"D:\Work\CarFight_git\UE\Saved\StagedBuilds\WindowsServer\CarFight_Re\Binaries\Win64\CarFight_ReServer.exe" /Game/Maps/TestMap -port=7777 -log -unattended -NoSound -LiveCoding=false -AbsLog="D:\Work\CarFight_git\Tools\CFServerLauncher\Logs\server.log"
```

미리보기는 다음 값이 바뀔 때마다 갱신한다.

- 서버 실행 파일
- 작업 폴더
- 맵 경로
- 포트
- 로그 파일
- 추가 인자

## 8. 로그 영역

| UI 문구 | 설명 |
|---|---|
| 최근 서버 로그 | tail 방식으로 읽은 서버 로그를 표시한다. |
| 자동 스크롤 | 새 로그가 추가되면 아래로 이동한다. |
| 로그 지우기 | 화면 표시만 지운다. |

로그 표시 컨트롤 권장 속성은 다음과 같다.

```text
읽기 전용
여러 줄 표시
세로 스크롤 표시
가로 스크롤 표시
고정폭 글꼴 사용
```

## 9. 버튼 활성화 정책

| 상태 | 서버 시작 | 서버 종료 | 설정 저장 | 설정 불러오기 |
|---|---|---|---|---|
| 중지됨 | 활성 | 비활성 | 활성 | 활성 |
| 시작 중 | 비활성 | 비활성 | 비활성 권장 | 비활성 권장 |
| 실행 중 | 비활성 | 활성 | 활성 가능 | 비활성 권장 |
| 종료 중 | 비활성 | 비활성 | 비활성 권장 | 비활성 권장 |
| 종료됨 | 활성 | 비활성 | 활성 | 활성 |
| 오류 | 활성 | 상황별 | 활성 | 활성 |

## 10. 한글 문구 기준

v1.0 UI 문구는 한글 기준으로 작성한다.

| 상황 | 문구 |
|---|---|
| 서버 실행 중 | 서버가 실행 중입니다. |
| 서버 시작 실패 | 서버를 시작하지 못했습니다. |
| 서버 종료 중 | 서버를 종료하는 중입니다. |
| 서버 종료 완료 | 서버가 종료되었습니다. |
| 설정 저장 완료 | 설정을 저장했습니다. |
| 설정 불러오기 완료 | 설정을 불러왔습니다. |
| 경로 오류 | 경로를 확인해야 합니다. |
| 포트 오류 | 포트는 1부터 65535 사이의 숫자여야 합니다. |
