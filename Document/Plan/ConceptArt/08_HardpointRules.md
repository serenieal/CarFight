## 1. 문서 목적

이 문서는 CarFight 차량 원화에서 **무기/터렛 장착부와 하드포인트를 어떻게 단순하게 배치할지**를 정의한다.

CarFight의 하드포인트는 군용 차량의 복잡한 무장 플랫폼이 아니다.  
기본 민간 차량 차체 위에 전투 개조용 마운트를 제한적으로 추가한 구조여야 한다.

이 문서의 목적은 다음과 같다.

- C1 Simple Game Asset 기준의 기본 하드포인트 위치를 정한다.
- 차급별 하드포인트 허용량과 크기를 정한다.
- 루프 마운트, 전방/후방/측면 하드포인트의 사용 우선순위를 정한다.
- 터렛 회전 공간과 차량 실루엣 간섭 기준을 정한다.
- 장갑 패널과 하드포인트가 서로 충돌하지 않도록 배치 기준을 정한다.
- AI 원화 생성 결과가 군용 무장 차량이나 과도한 무기 플랫폼으로 흐르지 않도록 제한한다.

| 항목 | 기준 |
|---|---|
| 기본 제작 목표 | C1 Simple Game Asset 최종 후보 |
| 기본 카메라 기준 | R1 Gameplay Mid |
| 핵심 가독성 | 차급, 방향, 무장 여부, 큰 장갑판 |

| 장갑 기준 | 큰 판형 패널 중심 |
| 루프 마운트 기준 | 차량보다 먼저 읽히지 않음 |

최상위 기준:

```text
하드포인트는 무기를 붙이기 위한 단순한 기준점이며, 차량 실루엣을 압도하면 안 된다.
```

## 3. 하드포인트 판단 원칙

CarFight의 하드포인트 판단 순서는 다음과 같다.

1. 먼저 원래 차급 실루엣이 읽히는지 본다.
2. 그다음 루프 마운트 위치가 명확한지 본다.
3. 그다음 터렛 방향과 회전 공간이 R1에서 읽히는지 본다.
4. 그다음 장갑판, 루프라인, 창문과 간섭하지 않는지 본다.
5. 마지막으로 작은 볼트, 케이블, 고정 브래킷 같은 표면 디테일을 본다.

중요 기준:

```text
무기 장착부는 차량의 전투 개조를 설명해야 하지만, 차량보다 먼저 읽히면 안 된다.
```

피해야 할 판단:

- 무기 크기로 차량 차급을 설명하지 않는다.
- 하드포인트를 많이 붙여 강해 보이게 만들지 않는다.
- 군용 포탑 플랫폼처럼 루프 전체를 덮지 않는다.
- 전투 밸런스, 데미지, 무기 성능은 이 문서에서 정하지 않는다.

## 4. 하드포인트 위치 우선순위

C1 기본 차량에서는 하드포인트 위치를 아래 순서로 검토한다.

| 우선순위 | 위치 | 기본 사용 여부 | 기준 |
|---|---|---|---|
| 1 | Roof Center | 기본 | 가장 읽기 쉽고 회전 공간을 잡기 쉬움 |
| 2 | Rear Bed / Rear Roof | 제한 | Pickup, Van, Wagon에서만 조심스럽게 사용 |
| 3 | Front Bumper | 확장 후보 | 전면 방향성 보강용. 기본 무장 위치 아님 |
| 4 | Rear Bumper | 확장 후보 | 후방 장비용. 초기 기본값 아님 |
| 5 | Side Mount | 제한 | 실루엣과 차폭을 흐리기 쉬워 기본값 아님 |

기본 결정:

```text
초기 차량 원화의 기본 하드포인트는 루프 중앙 1개다.
```

## 5. 하드포인트 크기 등급

하드포인트 크기는 3단계로 나눈다.

| 등급 | 이름 | 처리 기준 | 예시 |
|---|---|---|---|
| H0 | Marker Detail | 텍스처/단순 표시 | 작은 정렬 마킹, 작은 고정선 |
| H1 | Small Mount | 소형 메쉬 | 작은 센서 마운트, 작은 루프 플레이트 |
| H2 | Standard Roof Mount | 기본 메쉬 | C1 기본 루프 터렛 마운트 |

C1 기본 기준:

```text
기본 무기 장착부는 H2 Standard Roof Mount 1개를 우선한다.
```

H0 디테일은 메쉬로 만들지 않고 텍스처/노멀로 처리한다.

## 6. 루프 중앙 마운트 규칙

루프 중앙 마운트는 CarFight 초기 차량의 기본 하드포인트다.

권장 기준:

- 차량 중심선 위에 둔다.
- Side View에서 루프라인을 완전히 가리지 않는다.
- Top View에서 회전 공간이 읽혀야 한다.
- Front/Rear View에서 차체보다 과하게 넓지 않아야 한다.
- 장갑판과 겹치면 장갑판 또는 마운트 중 하나를 단순화한다.
- 작은 차급에는 작은 마운트를 사용한다.

피해야 할 것:

- 루프 전체를 무기 플랫폼처럼 만들기
- 마운트가 차체보다 먼저 보이게 만들기
- 터렛 회전 공간을 장갑판이나 센서 박스로 막기
- 복잡한 링, 케이블, 기어 구조를 노출하기

## 7. 차급별 하드포인트 허용량

| 차급 | 기본 허용량 | 기준 |
|---|---:|---|
| Microcar | 0~1개 | 매우 작은 H1 또는 작은 H2만 허용 |
| City Car | 0~1개 | 작은 루프 마운트 중심 |
| Subcompact | 1개 | 소형~중형 루프 마운트 |
| Compact | 1개 | 기본 H2 루프 마운트 적합 |
| Sedan | 1개 | 낮은 루프라인을 가리지 않게 작게 처리 |
| Coupe | 0~1개 | 작은 H1/H2. 큰 터렛 금지 |
| Wagon | 1개 | 긴 루프 위 중앙 배치 적합 |
| SUV | 1개 | 기본 H2 허용. 과대화 금지 |
| Van | 1개 | 큰 루프를 플랫폼화하지 않음 |
| Pickup | 1개 | 캐빈 위 또는 짐칸 쪽 단순 하드포인트 |

공통 기준:

```text
C1 기본 차량은 하드포인트 1개를 기준으로 검수한다.
```

2개 이상의 하드포인트는 기본값이 아니라 확장 후보로 본다.

## 8. 위치별 하드포인트 기준

### 8.1 Roof Center

가장 안전한 기본 위치다.

권장 기준:

- 차체 중심선에 배치한다.
- 터렛 회전 반경을 Top View에서 확인한다.
- 루프 마운트 주변 장갑은 작게 둔다.
- 차급 루프라인을 완전히 덮지 않는다.

피해야 할 것:

- 루프 전체를 장비로 채우기
- 마운트를 앞이나 뒤로 치우쳐 차량 중심이 불안해 보이게 만들기
- 낮은 Coupe/Sedan 루프 위에 큰 마운트를 올리기

---

### 8.2 Rear Bed / Rear Roof

Pickup, Van, Wagon에서 제한적으로 사용할 수 있다.

권장 기준:

- Pickup은 열린 짐칸의 비어 있는 공간을 활용한다.
- Van/Wagon은 후방 루프 위에 작게 배치한다.
- 후방 공간의 차급 실루엣을 가리지 않는다.
- 후면 장갑판과 겹치지 않게 한다.

피해야 할 것:

- Pickup 짐칸을 무기 플랫폼으로 가득 채우기
- Van을 군용 수송차처럼 보이게 만들기
- 후방 장비가 차량보다 먼저 읽히게 만들기

---

### 8.3 Front Bumper

전방 하드포인트는 초기 기본값이 아니다.

권장 기준:

- 소형 센서, 보조 장비, 전면 방향 표시 정도로 제한한다.
- 전면 장갑과 범퍼 보강대가 이미 있으면 추가하지 않는다.
- 보닛과 라이트 위치를 가리지 않는다.

피해야 할 것:

- 전면 무기를 크게 달아 차량 앞부분을 가리기
- 전면 장갑, 범퍼, 센서, 무기를 모두 겹치기
- 탱크 주포처럼 보이는 긴 전방 무기

---

### 8.4 Rear Bumper

후방 하드포인트도 초기 기본값이 아니다.

권장 기준:

- 작은 후방 센서 또는 장비 박스 정도로 제한한다.
- 테일라이트와 후방 방향성을 남긴다.
- 후면 장갑판과 충돌하면 장비를 줄인다.

피해야 할 것:

- 후방에 큰 무기나 장비를 붙여 후방 실루엣을 가리기
- 냉각구, 배기구, 장갑, 장비 박스를 모두 메쉬로 만들기
- 후방이 군용 장비 덩어리처럼 보이게 만들기

---

### 8.5 Side Mount

측면 하드포인트는 C1 기본값에서 제외한다.

권장 기준:

- 특별한 대표 차량에서만 제한적으로 사용한다.
- 차폭을 과하게 넓히지 않는다.
- 휠 위치와 문/창문 위치를 가리지 않는다.
- 좌우 대칭으로 단순하게 배치한다.

피해야 할 것:

- 측면 무기가 차체보다 먼저 읽히게 만들기
- 얇은 무기 지지대나 케이블을 많이 만들기
- 차량이 군용 전투 플랫폼처럼 보이게 만들기

---

## 9. 터렛 회전 공간 기준

터렛 회전 공간은 Top View에서 먼저 확인한다.

권장 기준:

| 항목 | 기준 |
|---|---|
| 중심축 | 루프 마운트 중앙에 명확히 위치 |
| 회전 반경 | 장갑판, 센서 박스, 루프 장비와 겹치지 않음 |
| 총열 방향 | R1에서 앞/뒤 또는 좌/우 방향이 읽힘 |
| 높이 | 차량 루프라인을 과하게 키우지 않음 |
| 피벗 예측성 | 모델링과 언리얼 배치 시 중심을 찾기 쉬움 |

피해야 할 것:

- 회전 공간을 장갑이나 센서가 막는 구조
- 총열이 차체를 관통해 보이는 구조
- 회전축이 어디인지 알 수 없는 복잡한 마운트
- 작은 기어와 케이블이 많은 노출 구조

---

## 10. 장갑 패널과의 간섭 제한

하드포인트는 장갑 패널과 함께 읽혀야 하지만 서로 겹쳐 복잡해지면 안 된다.

권장 기준:

| 간섭 항목 | 처리 기준 |
|---|---|
| 루프 마운트 + 루프 장갑 | 둘 중 하나를 단순화 |
| 전면 장갑 + 전방 하드포인트 | 기본적으로 동시에 크게 쓰지 않음 |
| 후면 장갑 + 후방 장비 | 후면 방향성이 남게 크기 제한 |
| 측면 장갑 + 측면 하드포인트 | C1 기본값에서는 측면 하드포인트 제외 |
| 센서 박스 + 터렛 회전 공간 | Top View에서 회전 반경 밖에 배치 |

판단 문장:

```text
장갑과 하드포인트가 겹쳐 작은 부품 덩어리처럼 보이면 C1 기준에서 실패다.
```

## 11. 메쉬/텍스처 처리 기준

하드포인트 관련 디테일은 아래 기준으로 나눈다.

| 요소 | 권장 처리 |
|---|---|
| 기본 루프 마운트 | 메쉬 |
| 터렛 회전 베이스 | 단순 메쉬 |
| 큰 지지 플레이트 | 메쉬 |
| 작은 볼트 | 텍스처/노멀 |
| 얇은 케이블 | 기본 제외 또는 텍스처 |
| 작은 정렬 마킹 | 텍스처 |
| 작은 경고 라벨 | 텍스처 |
| 복잡한 기어/링 구조 | 기본 제외 |

판단 기준:

```text
R1에서 무장 여부와 방향을 읽게 만드는 형태만 메쉬로 만든다.
```

## 12. C1 하드포인트 원화 검수

AI 이미지나 수작업 원화를 검수할 때 아래 질문을 사용한다.

통과 질문:

- 루프 중앙 마운트 위치가 명확한가?
- 하드포인트가 차량보다 먼저 읽히지 않는가?
- Top View에서 터렛 회전 공간이 예상되는가?
- 장갑판과 하드포인트가 서로 과하게 겹치지 않는가?
- R1에서 무장 여부와 대략적인 방향이 읽히는가?
- 작은 고정구와 케이블을 텍스처/노멀로 넘길 수 있는가?
- C1 파츠 예산 안에 들어올 수 있는가?

탈락 질문:

- 루프 전체가 무기 플랫폼처럼 보이는가?
- 무기가 차급 실루엣보다 먼저 읽히는가?
- 탱크, APC, 군용 무장 차량처럼 보이는가?
- 하드포인트가 2개 이상이라 차량이 너무 복잡해졌는가?
- 터렛 회전 공간이 장갑/센서와 충돌해 보이는가?
- 작은 기계 부품이 전체 인상을 지배하는가?

## 13. AI 프롬프트 영향

AI 원화 생성 프롬프트에는 하드포인트를 단순화하는 문구를 넣는다.

기본 형식:

```text
[Class Name],
[class silhouette phrase],
[class proportion phrase],
simplified near-future civilian combat car,
single simple roof hardpoint,
small roof turret mount,
clear turret rotation space,
large simple armor panels,
clean readable silhouette,
low modeling complexity,
R1 gameplay readable weapon mount,
minimal small mechanical details,
no real car brand,
no military armored vehicle,
no tank,
no APC,
no oversized weapon,
no multiple weapon platforms,
orthographic side/front/rear/top concept sheet,
plain background
```

권장 포함 문구:

```text
single roof hardpoint,
small roof mount,
simple turret base,
clear rotation space,
weapon mount smaller than vehicle body,
easy to model mount
```

권장 금지 문구:

```text
no oversized turret,
no tank cannon,
no multiple turrets,
no side weapon pods,
no military weapon platform,
no complex exposed cables,
no detailed mechanical gears
```

## 14. 현재 결정 상태

- 기존에 생성된 차량 이미지가 있다면 다음 기준으로 재검토한다.
  - 하드포인트가 차량보다 먼저 읽히지 않는가?
  - 루프 전체가 무기 플랫폼처럼 보이지 않는가?
  - Top View에서 터렛 회전 공간이 예상되는가?
  - 장갑판, 센서 박스, 루프 마운트가 서로 과하게 겹치지 않는가?
  - 탱크, APC, 군용 무장 차량처럼 보이지 않는가?
- 하드포인트가 2개 이상인 차량은 C1 기본 후보가 아니라 확장 후보로 재검토한다.
- 이후 `09_MaterialColorRules.md`는 이 문서의 마운트/장비 기준을 바탕으로 재질과 색상 구분을 정한다.
