## 1. 문서 목적

이 문서는 Compact 차량의 AI 모델링 결과를 받은 뒤, 해당 결과를 **재생성할지, 후처리할지, 언리얼 임포트 후보로 넘길지** 판단하는 체크리스트다.

이 문서는 모델링 방법을 설명하는 문서가 아니다.  
이 문서는 AI가 만든 3D 결과물을 1인 개발자가 빠르게 검수하기 위한 판정 기준이다.

목적은 다음과 같다.

- AI 모델링 결과가 C1 Simple Game Asset 후보인지 판단한다.
- 파츠 분리, 피벗, 머티리얼, 콜리전, LOD 가능성을 확인한다.
- 장시간 수작업 수정이 필요한 결과를 초기에 걸러낸다.
- 후처리 가능한 결과와 재생성해야 하는 결과를 구분한다.
- 언리얼 임포트 전 최소 체크 항목을 정리한다.

## 2. 판정 단계

AI 모델링 결과는 아래 3단계 중 하나로 판정한다.

| 판정 | 의미 | 다음 행동 |
|---|---|---|
| Pass | C1 후보로 유지 가능 | 후처리 후 언리얼 임포트 검토 |
| Fix | 구조는 맞지만 정리가 필요 | 제한된 후처리만 진행 |
| Reject | C1 기준에서 벗어남 | 오래 고치지 않고 재생성 |

기준 문장:

```text
AI 결과가 멋있어도 정리 비용이 크면 Reject다.
```

---

## 3. 1차 빠른 검수

AI 모델링 결과를 처음 받으면 아래 항목부터 확인한다.

| 체크 | Pass 기준 | Reject 기준 |
|---|---|---|
| 차급 | Compact 해치백으로 읽힘 | SUV, 세단, 장갑차처럼 보임 |
| 민간 차량성 | 민간 차량 위에 개조가 붙은 느낌 | 군용 장갑차나 탱크처럼 보임 |
| 큰 형태 | 큰 덩어리가 단순함 | 작은 기계 디테일이 전체를 지배 |
| 휠 | 4개가 명확함 | 휠 수/위치가 불명확 |
| 루프 마운트 | 중앙 하드포인트가 있음 | 없거나 과하게 큼 |
| 장갑 | 큰 판형 위주 | 수십 개의 작은 장갑 조각 |
| 브랜드 회피 | 실제 브랜드처럼 보이지 않음 | 실제 차량 복제 느낌이 강함 |

1차 기준:

```text
이 표에서 Reject가 2개 이상이면 후처리하지 않고 재생성을 우선한다.
```

## 4. 파츠 분리 체크리스트

아래 파츠가 분리되어 있거나, 최소한 후처리로 분리 가능해야 한다.

| 파츠 | 체크 | 판정 |
|---|---|---|
| Body_Main | 차체 기본 덩어리가 하나로 읽힘 | Pass / Fix / Reject |
| Wheel_FL | 앞 왼쪽 휠이 분리 가능 | Pass / Fix / Reject |
| Wheel_FR | 앞 오른쪽 휠이 분리 가능 | Pass / Fix / Reject |
| Wheel_RL | 뒤 왼쪽 휠이 분리 가능 | Pass / Fix / Reject |
| Wheel_RR | 뒤 오른쪽 휠이 분리 가능 | Pass / Fix / Reject |
| Glass_Main | 유리 영역이 차체와 구분됨 | Pass / Fix / Reject |
| Armor_Front | 전면 장갑판이 큰 파츠로 읽힘 | Pass / Fix / Reject |
| Armor_Left | 좌측 장갑판이 큰 파츠로 읽힘 | Pass / Fix / Reject |
| Armor_Right | 우측 장갑판이 큰 파츠로 읽힘 | Pass / Fix / Reject |
| Armor_Rear | 후면 장갑판이 큰 파츠로 읽힘 | Pass / Fix / Reject |
| Mount_Roof | 루프 중앙 마운트가 분리 가능 | Pass / Fix / Reject |

판정 기준:

- `Body_Main`, 휠 4개, `Mount_Roof` 중 하나라도 Reject면 기본적으로 재생성을 검토한다.
- 장갑판은 일부 합쳐져도 C1 후보로 유지할 수 있다.
- 유리는 머티리얼만 분리 가능해도 Fix로 유지할 수 있다.

## 5. 피벗 체크리스트

AI 모델링 결과는 피벗이 정확하지 않을 수 있다.  
따라서 최소한 피벗을 다시 잡기 쉬운 형태인지 확인한다.

| 대상 | 체크 기준 | 판정 |
|---|---|---|
| Body_Main | 차량 중심을 잡기 쉬움 | Pass / Fix / Reject |
| Wheel_FL | 휠 중심축을 잡기 쉬움 | Pass / Fix / Reject |
| Wheel_FR | 휠 중심축을 잡기 쉬움 | Pass / Fix / Reject |
| Wheel_RL | 휠 중심축을 잡기 쉬움 | Pass / Fix / Reject |
| Wheel_RR | 휠 중심축을 잡기 쉬움 | Pass / Fix / Reject |
| Mount_Roof | 회전 중심을 잡기 쉬움 | Pass / Fix / Reject |

Reject 기준:

- 휠이 원형이 아니거나 차체와 심하게 붙어 있다.
- 루프 마운트 중심을 추정하기 어렵다.
- 차체가 비대칭으로 크게 뒤틀려 중심축을 잡기 어렵다.

## 6. 스케일/방향 체크리스트

언리얼 임포트 전에는 실제 크기보다 방향성과 상대 비례를 먼저 확인한다.

| 체크 | 기준 | 판정 |
|---|---|---|
| 전방 방향 | 차량 앞/뒤가 명확함 | Pass / Fix / Reject |
| 좌우 대칭 | 기본 차체와 휠이 좌우 대칭에 가까움 | Pass / Fix / Reject |
| 차체 비례 | Compact 해치백 비례 유지 | Pass / Fix / Reject |
| 휠 크기 | 차체 대비 과하지 않음 | Pass / Fix / Reject |
| 루프 마운트 크기 | 차량보다 먼저 읽히지 않음 | Pass / Fix / Reject |
| 장갑 돌출 | 차급 실루엣을 덮지 않음 | Pass / Fix / Reject |

Fix 기준:

- 방향축만 틀린 경우는 후처리 가능하다.
- 스케일만 너무 크거나 작은 경우는 후처리 가능하다.
- 차급 자체가 바뀐 경우는 Reject다.

---

## 7. 머티리얼 슬롯 체크리스트

머티리얼은 5~6개 슬롯으로 정리되는 것이 기본이다.

| 슬롯 | 대상 | 체크 |
|---|---|---|
| M01 Painted_Body | 차체 도장 | 차체와 장갑이 구분되는가 |
| M02 Matte_Armor | 장갑판 | 큰 장갑판에 적용 가능한가 |
| M03 Dark_Glass | 유리 | 유리 영역이 분리되는가 |
| M04 Rubber_Tire | 타이어 | 휠/타이어 재질이 구분되는가 |
| M05 Utility_Plastic | 트림/마운트/휠가드 | 보조 파츠에 적용 가능한가 |
| M06 Emissive_Decal | 센서등 | 작은 발광 포인트만 있는가 |

판정 기준:

- 6개 안에 정리되면 Pass다.
- 7~8개는 Fix로 보고 통합한다.
- 9개 이상이 필요하면 구조가 과한 것으로 보고 재생성을 검토한다.

---

## 8. 콜리전 체크리스트

C1 후보는 단순 콜리전으로 근사 가능해야 한다.

| 대상 | 권장 콜리전 | 판정 |
|---|---|---|
| Body_Main | 단순 박스 또는 컨벡스 | Pass / Fix / Reject |
| Wheel_* | 원통 또는 단순 캡슐/컨벡스 | Pass / Fix / Reject |
| Armor_* | 차체 콜리전에 포함하거나 단순 박스 | Pass / Fix / Reject |
| Mount_Roof | 작은 박스 또는 차체 콜리전에 포함 | Pass / Fix / Reject |

Reject 기준:

- 차체 실루엣이 너무 복잡해 단순 콜리전으로 근사하기 어렵다.
- 얇은 돌출부가 많아 콜리전 정리가 오래 걸린다.
- 하부 구조가 복잡하게 노출되어 콜리전 기준이 흐려진다.

---

## 9. LOD 체크리스트

AI 모델링 결과는 가까이서 보기 좋은 세부 구조보다 멀리서 유지되는 큰 실루엣이 중요하다.

| 체크 | Pass 기준 | Reject 기준 |
|---|---|---|
| LOD1 | 작은 볼트/라벨 제거 후에도 차급 유지 | 작은 디테일을 지우면 형태가 무너짐 |
| LOD2 | 큰 차체/휠/마운트만 남아도 차량으로 읽힘 | 실루엣이 장갑 덩어리처럼 보임 |
| 머티리얼 축소 | 발광/라벨이 없어도 인상 유지 | 작은 발광에 의존함 |
| 휠 가독성 | 멀리서 4개 휠 덩어리 유지 | 휠이 차체에 묻힘 |

기준:

```text
LOD에서 작은 디테일을 없애도 Compact 차급이 유지되어야 한다.
```

---

## 10. 후처리 허용 범위

아래 작업은 Fix 판정 후 진행해도 된다.

| 후처리 | 허용 여부 |
|---|---|
| 파츠 이름 정리 | 허용 |
| 피벗 재설정 | 허용 |
| 스케일/방향 정리 | 허용 |
| 머티리얼 슬롯 통합 | 허용 |
| 작은 볼트/패널선 제거 | 허용 |
| 단순 콜리전 추가 | 허용 |
| 가벼운 LOD 단순화 | 허용 |

아래 작업이 필요하면 Reject를 우선한다.

| 후처리 | 이유 |
|---|---|
| 차체 실루엣 대수정 | 차급 기준 실패 |
| 휠 위치 대수정 | 차량 구조 실패 |
| 장갑판 대부분 재제작 | 프롬프트 기준 실패 |
| 루프 마운트 새로 제작 | 하드포인트 기준 실패 |
| 작은 디테일 수백 개 삭제 | AI 과생성 실패 |
| 머티리얼 구조 대수정 | 후처리 비용 과다 |

```text

- 큰 형태:
- 휠:
- 루프 마운트:
- 장갑:
- 브랜드 회피:

파츠 분리:
- Body_Main:
- Wheel_FL/FR/RL/RR:
- Glass_Main:
- Armor_*:
- Mount_Roof:

언리얼 적용성:
- 피벗:
- 스케일/방향:
- 머티리얼 슬롯:

최종 판정:
- Pass / Fix / Reject

다음 행동:
- 후처리 진행 / 프롬프트 단순화 후 재생성 / 후보 폐기
```
