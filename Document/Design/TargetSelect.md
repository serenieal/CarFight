## 1. 문서 목적

이 문서는 CarFight의 **타겟 선택 시스템**에 대한 단일 기획 기준(SSOT)을 정의한다.

타겟 선택 시스템은 플레이어가 화면에 보이는 차량·장치·환경 오브젝트 중 하나를 명시적으로 선택하고, 선택된 대상의 정보를 확인하거나 미사일·스캐너·해킹·수리·견인 등 다른 시스템에 대상을 전달하기 위한 공통 기반이다.

이 기능은 자동 조준 시스템이 아니다. 플레이어의 직접 조준과 발사 방향은 계속 크로스헤어와 무기 조준 체계가 담당한다.

---

## 2. 핵심 설계 원칙

### 2.1 직접 조준 우선

플레이어가 크로스헤어로 직접 가리킨 대상은 다른 모든 근접 후보보다 우선한다.

### 2.2 선택과 조준 분리

- **조준 대상**: 현재 크로스헤어가 가리키는 순간적인 대상
- **선택 후보**: 선택 입력을 사용하면 선택될 가능성이 가장 높은 대상
- **선택 대상**: 플레이어가 명시적으로 확정한 지속 대상
- **장비 고정 대상**: 장비가 별도 조건을 만족하여 획득한 락온 또는 연결 대상

선택 대상이 존재하더라도 기관총과 같은 직접 조준 무기는 크로스헤어 방향으로 발사한다.

### 2.3 선택과 장비 락온 분리

타겟 선택은 즉시 확정될 수 있지만, 미사일 락온·해킹·스캔·견인 연결은 장비별 거리, 각도, 시야, 시간과 자원 조건을 별도로 검사한다.

선택 입력과 락온 입력이 반드시 별도로 존재할 필요는 없다. 기본 락온 방식은 선택된 타겟을 유효 조준 영역에 유지하는 동안 해당 장비의 락온 진행도가 자동으로 상승하는 방식으로 시작할 수 있다.

```text
TargetSelect
= 선택 대상 참조와 변경 이벤트 소유

Weapon / Equipment Lock
= 락온 가능 여부, 진행도, 완료, 감쇠와 상실 소유
```

무기 또는 장비는 `CrosshairHold`, `TargetCone`, `SensorTrack`, `ManualDesignate`, `LaserGuide` 등 서로 다른 획득 방식을 사용할 수 있다. 타겟 선택 시스템은 이 방식들을 직접 계산하지 않는다.

### 2.4 플레이어 의도 우선

위협도, 적대 여부, 월드 거리 등의 전술 정보가 크로스헤어에 가까운 대상보다 먼저 적용되어서는 안 된다.

### 2.5 초기 단일 선택

P0에서는 플레이어당 하나의 선택 대상만 유지한다. 다중 타겟과 다중 락온은 후속 단계로 분리한다.

### 2.6 변경 가능한 기본값

본 문서의 추천 수치와 표시 정책은 초기 검증용 기본값이다. 구현 시 설정 데이터로 분리하여 코드 수정 없이 조정할 수 있어야 한다.

## 3. 용어 및 상태

| 용어 | 정의 | 소유 시스템 |
|---|---|---|
| 조준 대상 | 크로스헤어 중앙 판정에 현재 맞은 대상 | 조준/무기 |
| 선택 후보 | 현재 선택 입력 시 선택될 대상 | 타겟 선택 |
| 선택 대상 | 플레이어가 확정한 대상 | 타겟 선택 |
| 장비 획득 중 | 장비가 선택 대상에 락온·스캔 등을 진행 중인 상태 | 개별 장비 |
| 장비 고정 | 장비가 사용 조건을 충족한 상태 | 개별 장비 |
| 추적 상태 | 가시, 가림, 추정, 신호 소실 등 센서 상태 | 센서/타겟 선택 연동 |
| 타겟 포인트 | 선택 거리와 표시 위치 계산에 사용하는 대상 내부 기준점 | 선택 가능 대상 |

### 3.1 코어 상태 모델

타겟 선택 코어는 다음 상태만 직접 관리한다.

1. `NoCandidate`
2. `CandidateAvailable`
3. `TargetSelected`
4. `SelectedTargetInvalid`

장비 획득 진행도와 장비 고정 상태는 장비 시스템이 관리한다. 타겟 선택 시스템은 선택 대상 참조와 변경 이벤트만 제공한다.

## 4. 선택 입력 기본 동작

### 4.1 선택 입력

1. 현재 선택 컨텍스트를 확인한다.
2. 크로스헤어 중앙 직접 판정을 실행한다.
3. 직접 판정에 유효 대상이 있으면 해당 대상을 최우선 후보로 확정한다.
4. 직접 대상이 없으면 크로스헤어 근처 후보를 수집한다.
5. 후보를 사전 필터링하고 우선순위 규칙으로 정렬한다.
6. 가장 높은 후보를 선택 대상으로 확정한다.
7. 유효 후보가 없으면 기존 선택 대상을 유지한다.

### 4.2 선택 해제 입력

현재 선택 대상을 명시적으로 해제한다.

### 4.3 같은 대상 재선택

선택된 대상을 다시 선택해도 상태를 변경하지 않는다. 선택 해제는 별도 입력으로만 수행한다.

### 4.4 다음·이전 타겟 입력

P0 범위에서 제외한다. P1에서 후보 목록 순환 방식으로 추가한다.

## 5. 후보 수집

### 5.1 직접 조준 후보

카메라의 크로스헤어 중앙에서 전방으로 판정을 수행한다.

직접 조준 후보는 다음 조건을 모두 만족해야 한다.

- 타겟 선택 기능을 제공하는 대상
- 파괴·비활성·제거 대기 상태가 아님
- 현재 선택 컨텍스트에서 선택 허용
- 최대 직접 판정 거리 안에 존재
- 직접 선택 시 필요한 가시성 조건을 만족

직접 판정은 대상의 실제 차체나 선택용 충돌을 검사할 수 있다. 맞은 컴포넌트가 부위여도 P0에서는 소유 액터를 선택 대상으로 승격한다.

### 5.2 근접 후보

직접 조준 후보가 없을 때 카메라 전방의 제한된 거리와 각도 안에서 후보를 수집한다.

근접 후보의 주요 비교 기준은 **월드 거리보다 화면상 크로스헤어 근접도**다.

권장 계산 기준:

- 카메라 전방 벡터와 타겟 포인트 방향 벡터 사이의 각도
- 또는 해상도 독립적인 정규화 화면 좌표 거리

고정 픽셀 반경만 사용하는 방식은 울트라와이드와 해상도 차이에 취약하므로 주 기준으로 사용하지 않는다.

### 5.3 타겟 포인트

액터 원점만으로 선택 위치를 평가하지 않는다.

P0 최소 요구사항:

- 대상당 대표 타겟 포인트 1개
- 대표 포인트가 없으면 바운딩 박스 중심을 임시 사용
- 차량은 차체 중앙 또는 시각적 중심 근처를 기본 포인트로 사용

향후 확장:

- 엔진
- 바퀴
- 무기 장착부
- 조종석
- 상호작용 소켓

대상 선택과 부위 선택은 별도의 계층으로 유지한다.

## 6. 후보 사전 필터

우선순위 평가 전에 다음 항목을 검사한다.

1. 대상 참조가 유효한가
2. 자기 자신 선택이 허용되는 컨텍스트인가
3. 대상이 선택 가능 인터페이스를 제공하는가
4. 현재 컨텍스트에서 허용되는 대상 종류인가
5. 최대 선택 거리 안인가
6. 대상이 파괴·비활성 상태가 아닌가
7. 새 선택에 필요한 가시성 규칙을 만족하는가
8. 임시 제외 목록에 포함되지 않았는가

아군, 중립, 적대 대상은 기본적으로 모두 선택 가능하다. 적만 선택하는 동작은 별도 필터 또는 별도 입력으로 제공한다.

## 7. 우선순위 규칙

가중치 총합 하나로 모든 후보를 비교하지 않고, 플레이어 의도를 보존하는 **계층형 비교**를 사용한다.

| 비교 단계 | 기준 | 설명 |
|---:|---|---|
| 1 | 직접 조준 여부 | 직접 맞은 대상이 무조건 우선 |
| 2 | 크로스헤어 근접도 | 각도 또는 정규화 화면 거리 |
| 3 | 후보 유지 보정 | 기존 후보와 차이가 작으면 기존 후보 유지 |
| 4 | 가시성 | 완전 가시 후보 우선 |
| 5 | 월드 거리 | 앞 단계가 거의 같을 때 가까운 대상 우선 |
| 6 | 관계/컨텍스트 보정 | 명시적 필터가 활성화된 경우에만 적용 |
| 7 | 결정적 정렬값 | 결과가 프레임마다 바뀌지 않도록 고정 비교 |

### 7.1 위협도 사용 정책

위협도는 기본 클릭·선택 우선순위에 사용하지 않는다.

다음 기능에서는 사용할 수 있다.

- 가장 위험한 적 선택
- 자동 방어 장비
- AI 타겟 평가
- 경고 UI
- 동일 조건 후보의 최종 보조 비교

## 8. 후보 안정화

크로스헤어 근처에 여러 대상이 겹칠 때 후보가 매 프레임 바뀌지 않도록 히스테리시스를 적용한다.

원칙:

- 새 후보가 기존 후보보다 아주 조금 유리한 경우 기존 후보 유지
- 새 후보가 명확히 더 중앙에 들어온 경우 변경
- 직접 조준 판정이 발생하면 즉시 직접 대상에게 변경
- 기존 후보가 무효가 되면 즉시 재평가

후보 유지 보정값은 설정 데이터로 분리한다.

## 9. 선택 유지와 해제

### 9.1 유지 조건

다음 상황에서도 선택 대상을 유지한다.

- 크로스헤어가 대상에서 벗어남
- 카메라가 다른 방향을 봄
- 대상이 화면 밖으로 이동
- 다른 대상이 크로스헤어에 들어옴
- 대상이 일시적으로 장애물 뒤에 숨음
- 현재 장비에서 사용할 수 없는 상태가 됨

### 9.2 자동 해제 조건

다음 상황에서는 선택을 자동 해제한다.

- 대상 액터가 제거됨
- 대상이 선택 불가 상태로 전환됨
- 대상이 완전히 파괴됨
- 추적 가능 최대 범위를 장시간 벗어남
- 게임 상태 전환으로 선택 시스템이 비활성화됨
- 플레이어 차량이 파괴되어 전투 HUD가 종료됨

### 9.3 장애물 뒤 유지

추천 기본 정책:

- 새 대상을 선택할 때는 직접 시야가 필요하다.
- 이미 선택한 대상은 일정 시간 가려져도 선택을 유지한다.
- 유예 시간 이후에도 센서 추적이 가능하면 제한된 정보로 유지한다.
- 센서 신호가 완전히 소실되면 선택 표시를 숨기거나 선택을 해제한다.

P0에서는 간단한 가림 유예까지만 구현하고, 센서 기반 추정 위치는 P2로 미룬다.

## 10. 선택 컨텍스트와 장비 연동

### 10.1 기본 선택 컨텍스트

평상시에는 다음 종류를 선택할 수 있다.

- 적대 차량
- 아군 차량
- 중립 차량
- 주요 환경 오브젝트
- 상호작용 가능한 장치

### 10.2 장비 호환성

선택 가능 여부와 현재 장비 사용 가능 여부를 분리한다.

예:

- 적 차량 선택 가능
- 수리 장비 사용 불가
- HUD에 `현재 장비 사용 불가` 표시

장비가 선택 대상을 사용할 때는 자체적으로 다음을 검사한다.

- 대상 종류
- 관계
- 거리
- 각도
- 시야
- 에너지
- 열
- 쿨다운
- 장비별 획득 시간

### 10.3 대상 변경 이벤트

타겟 선택 시스템은 최소한 다음 변경 알림을 제공해야 한다.

- 선택 후보 변경
- 선택 대상 변경
- 선택 대상 해제
- 선택 대상 유효성 변경
- 선택 대상 추적 상태 변경

다른 시스템은 매 프레임 대상을 검색하지 않고 변경 이벤트 또는 안전한 조회 함수를 통해 대상을 참조한다.

## 11. 정보 공개 단계

선택했다고 모든 정보를 공개하지 않는다.

## 12. HUD 표시

### 12.1 선택 후보

- 얇은 모서리 브래킷 또는 작은 마름모
- 낮은 시각 강도
- 이름과 상세 정보는 표시하지 않음
- 선택 입력 준비 중 또는 근접 조건 충족 시에만 표시

### 12.2 선택 대상

- 네 모서리 브래킷
- 관계 아이콘
- 거리
- 식별된 이름 또는 종류
- 현재 장비 호환 상태
- 장비 획득 진행 상태는 장비 UI에서 추가

### 12.3 화면 밖 선택 대상

센서가 방향 정보를 유지할 때만 화면 가장자리 표식을 표시한다.

표시 후보:

- 대상 방향
- 거리
- 관계
- 선택 대상 표식
- 센서 상태

### 12.4 장애물 뒤 선택 대상

색상만 바꾸지 않고 형태도 함께 변경한다.

- 실선에서 점선
- 정상 브래킷에서 추정 위치 아이콘
- 불투명에서 반투명
- `가시`, `가림`, `마지막 확인 위치` 아이콘 구분

### 12.5 정보 패널

화면 중앙에는 즉시 필요한 정보만 표시하고, 상세 정보는 별도 패널에 표시한다.

## 14. 예외 처리

### 14.1 대상이 겹친 경우

직접 판정에 맞은 대상을 우선한다. 직접 판정이 없으면 대표 타겟 포인트의 화면상 근접도를 비교한다.

### 14.2 아군이 적 앞을 가린 경우

기본 선택에서는 실제로 맞은 아군을 후보로 사용한다. 적 전용 필터가 켜진 경우에만 아군을 제외한다.

### 14.3 큰 대상이 범위를 독점하는 경우

근접 후보 평가는 바운딩 박스 전체가 아니라 타겟 포인트를 기준으로 한다.

### 14.4 대상 파괴

선택을 해제하고 파괴 알림을 잠시 표시할 수 있다. 다음 타겟을 자동 선택하지 않는다.

### 14.5 자신 선택

기본 컨텍스트에서는 자신을 제외한다. 자체 수리·자체 진단 장비는 장비가 명시적으로 자신을 대상으로 사용할 수 있다.

## 18. 확정 결정

다음 항목은 현재 구현 기준으로 잠금한다.

1. 직접 조준 대상이 최우선이다.
2. 직접 대상이 없으면 크로스헤어에 가장 가까운 대상을 선택한다.
3. 화면 근접도가 월드 거리보다 우선한다.
4. 선택과 직접 조준은 분리한다.
5. 선택과 장비 락온은 분리한다.
6. 선택 대상은 크로스헤어가 벗어나도 유지한다.
7. 화면 밖에서도 기본 선택 참조를 유지한다.
8. 장애물 뒤에서는 일정 시간 선택을 유지한다.
9. 대상 없는 곳에서 선택 입력 시 기존 선택을 유지한다.
10. 같은 대상 재선택 시 아무 동작도 하지 않는다.
11. 아군도 기본 선택 가능하다.
12. 적 우선은 별도 필터 또는 입력에서만 적용한다.
13. 모든 정보는 즉시 공개하지 않고 센서 단계에 따라 공개한다.
14. 자동 다음 타겟 선택은 기본 사용하지 않는다.
15. P0는 단일 선택만 지원한다.

## 21. 검증 시나리오

1. 크로스헤어 중앙에 적이 있고 주변에 더 가까운 아군이 있어도 적이 선택된다.
2. 중앙에 대상이 없으면 크로스헤어에 가장 가까운 후보가 선택된다.
3. 월드상 가까운 대상보다 화면상 중앙에 가까운 대상이 선택된다.
4. 두 후보가 비슷하게 움직여도 후보 표시가 빠르게 흔들리지 않는다.
5. 선택 후 카메라를 돌려도 선택이 유지된다.
6. 대상이 화면 밖으로 나가도 선택 참조가 유지된다.
7. 대상이 잠시 장애물 뒤에 가려져도 즉시 해제되지 않는다.
8. 선택할 대상이 없는 상태에서 선택 입력을 눌러도 기존 선택이 유지된다.
9. 선택된 대상을 다시 선택해도 해제되지 않는다.
10. 선택 대상이 파괴되면 안전하게 해제된다.
11. 아군 대상도 선택할 수 있다.
12. 수리 장비로 적을 선택했을 때 선택은 유지되지만 사용 불가가 표시된다.
13. 대상의 센서 단계보다 많은 정보가 표시되지 않는다.
14. 자동으로 다른 타겟이 선택되지 않는다.
