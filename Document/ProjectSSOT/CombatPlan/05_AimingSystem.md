# 05. 조준 방식

- 문서 버전: v0.2
- 작성일: 2026-06-08
- 최근 갱신일: 2026-06-08
- 문서 상태: Current
- 담당 범위: 고정 / 짐벌 / 터렛 / 락온 / 수동 유도 조준 방식 정의

---

## 1. 목적

이 문서는 CarFight의 조준 방식을 정의한다.

CarFight의 조준은 에임만 잘하면 되는 FPS식 조준도 아니고, 락온하면 알아서 맞히는 자동전투도 아니다.

핵심 정의:

> CarFight의 조준은 플레이어 직접 조준을 기반으로 하되, 무기 장착 방식, 각속도, 조준 가능 각도, 안정화 시간, 센서/락온, 배터리 보조에 의해 실제 명중 가능성이 결정된다.

---

## 2. 조준 방식 전체 분류

CarFight의 조준 방식은 5개로 나눈다.

```text
01. 고정 무기
02. 짐벌 무기
03. 터렛 무기
04. 락온 무기
05. 수동 유도 무기
```

각 방식은 좋고 나쁨의 관계가 아니라 역할이 다르다.

| 조준 방식 | 조준 주체 | 장점 | 약점 |
|---|---|---|---|
| 고정 무기 | 차체 방향 | 강한 화력, 운전 실력 반영 | 차체를 직접 맞춰야 함 |
| 짐벌 무기 | 플레이어 조준 + 제한 보정 | 빠른 목표 대응 | 화력/각도 제한 |
| 터렛 무기 | 포탑 회전 | 차체 방향 의존 낮음 | 각속도/안정화 제한 |
| 락온 무기 | 센서/락온 | 추격, 압박, 장거리 견제 | 배터리/락온 방해에 취약 |
| 수동 유도 무기 | 발사 후 플레이어 조작 | 높은 숙련도 보상 | 운전과 조작 부담 큼 |

---

## 3. 조준의 기본 구조

CarFight에서는 조준점을 하나만 두면 부족하다.

최소한 아래 3개 개념이 필요하다.

| 조준 요소 | 설명 |
|---|---|
| 플레이어 조준점 | 플레이어가 화면에서 직접 겨누는 지점 |
| 무기 실제 조준점 | 무기가 현재 실제로 바라보는 지점 |
| 예측 조준점 | 움직이는 목표를 맞히기 위해 쏴야 하는 위치 |

플레이어가 조준점을 적에게 맞췄다고 해서 무기가 즉시 그 방향을 바라보면 안 된다.

특히 짐벌/터렛/락온 무기는 다음 제한을 받는다.

```text
무기 조준 가능 각도
무기 각속도
조준 안정화 시간
차량 흔들림
센서/락온 품질
배터리 보조 여부
```

즉, 플레이어 조준은 명령이고, 무기 실제 조준은 무기가 그 명령을 따라가는 결과다.

---

## 4. 핵심 원칙: 무기 실제 조준점은 늦게 따라온다

이 원칙이 있어야 무기 밸런스가 살아난다.

```text
플레이어 조준점이 목표를 향함
→ 무기가 자기 각속도만큼 회전함
→ 목표 방향에 도달함
→ 조준 안정화 시간이 지나야 정확도가 올라감
→ 사격 가능
```

대구경 무기는 한 방은 강하지만, 빠르게 옆으로 붙은 적을 바로 따라가지 못해야 한다.

반대로 소구경 무기는 피해는 낮지만, 빠른 목표를 잘 따라가고 근거리 대응이 좋아야 한다.

---

## 5. 고정 무기

고정 무기는 차량의 차체 방향이 곧 무기 조준 방향이다.

대표 예시:

- 전방 고정 기관총
- 전방 고정 오토캐논
- 전방 고정 로켓
- 차체 장착 레일건
- 차체 정면 대구경포

전투 감각:

```text
차를 돌린다
→ 조준선이 돌아간다
→ 적을 정면에 넣는다
→ 발사한다
```

즉, 고정 무기는 운전 실력과 조준 실력이 강하게 연결된다.

장점:

| 장점 | 설명 |
|---|---|
| 높은 화력 가능 | 보정 장치가 적으므로 강한 화력을 줄 수 있음 |
| 반응이 직관적 | 차체가 보는 방향으로 쏨 |
| 운전 실력 보상 | 선회, 제동, 드리프트가 조준과 직결 |
| 구조 단순 | P0 구현에 적합 |

약점:

| 약점 | 설명 |
|---|---|
| 측면 대응 약함 | 적이 옆에 붙으면 차체를 돌려야 함 |
| 후방 대응 불가 | 전방 고정이면 뒤를 못 쏨 |
| 선회력 의존 | 무거운 차량은 조준이 느림 |
| 지형 영향 큼 | 차체가 흔들리면 조준도 흔들림 |

설계 원칙:

> 고정 무기는 가장 강한 직접 조준 무기지만, 차량을 잘 못 몰면 가장 쓰기 어려운 무기여야 한다.

고정 무기는 숙련자용 무기에 가깝게 둔다.

## 6. 짐벌 무기

짐벌 무기는 차체 전방 기준으로 제한된 각도 안에서 목표를 보정해서 따라가는 무기다.

쉽게 말하면, 차량을 대략 적 쪽으로 향하게 하면 무기가 제한 각도 안에서 조준을 보정해주는 방식이다.

전투 감각:

```text
차체를 적 근처로 맞춤
→ 플레이어 조준점으로 목표를 잡음
→ 짐벌이 제한각 안에서 따라감
→ 각속도가 충분하면 명중 가능
```

장점:

| 장점 | 설명 |
|---|---|
| 사용하기 쉬움 | 차체 방향을 완벽히 맞추지 않아도 됨 |
| 빠른 목표 대응 | 소형/중형 짐벌은 각속도가 빠름 |
| P0 테스트에 좋음 | 조준 보정 감각을 확인하기 좋음 |
| 직접 조준감 유지 | 완전 자동이 아니라 플레이어 조준 필요 |

약점:

| 약점 | 설명 |
|---|---|
| 화력 제한 | 고정 무기보다 약해야 함 |
| 조준각 제한 | 차체 방향이 너무 틀어지면 못 쏨 |
| 각속도 제한 | 빠른 목표는 여전히 놓칠 수 있음 |
| 배터리 보조 가능성 | 고급 짐벌은 배터리 사용 여지 있음 |

짐벌 무기의 핵심 스탯:

| 스탯 | 의미 |
|---|---|
| 조준 가능 각도 | 전방 기준 몇 도까지 보정되는가 |
| 수평 각속도 | 좌우로 얼마나 빨리 따라가는가 |
| 수직 각속도 | 위아래로 얼마나 빨리 따라가는가 |
| 안정화 시간 | 목표에 맞춘 뒤 정확해지는 시간 |
| 보정 강도 | 플레이어 조준을 얼마나 도와주는가 |

설계 원칙:

> 짐벌 무기는 초보자와 중거리 교전의 기준 무기지만, 고정 무기보다 화력 효율은 낮아야 한다.

편한 만큼 대가가 있어야 한다.

## 7. 터렛 무기

터렛 무기는 차체 방향과 독립적으로 회전할 수 있는 무기다.

단, 어디든 자유롭게 쏘는 만능 무기가 되면 안 된다.

터렛의 핵심 제약:

```text
회전 가능 각도
무기 각속도
조준 안정화 시간
차량 흔들림
터렛 크기/중량
배터리 보조 여부
```

전투 감각:

```text
차량은 이동과 장갑 방향을 관리함
→ 터렛은 목표 방향으로 회전함
→ 회전 속도가 목표 움직임을 따라가야 함
→ 안정화 후 사격함
```

터렛은 차체 방향 의존도를 줄여주지만, 대신 무기 자체의 회전 성능이 중요하다.

장점:

| 장점 | 설명 |
|---|---|
| 차체 방향과 독립 | 운전과 사격 방향 분리 |
| 추격/도주 중 사격 가능 | 측면/후방 견제 가능 |
| 중장갑 차량과 궁합 좋음 | 정면 장갑을 세운 채 사격 가능 |
| 역할 다양 | 소형 방어 터렛부터 대구경 주포까지 가능 |

약점:

| 약점 | 설명 |
|---|---|
| 각속도 제한 | 빠르게 붙는 적을 못 따라갈 수 있음 |
| 안정화 필요 | 돌린 직후 정확도가 낮을 수 있음 |
| 중량 증가 | 큰 터렛은 차량 성능 저하 |
| 피격 부위화 | 터렛 자체가 손상될 수 있음 |
| 사각 존재 가능 | 차체 구조물에 가려지는 영역 |

터렛 크기별 방향:

| 터렛 크기 | 역할 | 각속도 | 피해 | 약점 |
|---|---|---:|---:|---|
| 소형 터렛 | 근접 방어, 빠른 목표 대응 | 빠름 | 낮음 | 장갑 관통 약함 |
| 중형 터렛 | 주력 교전 | 보통 | 보통 | 극근거리 대응 제한 |
| 대형 터렛 | 한 방, 장갑 대응, 길목 장악 | 느림 | 높음 | 빠른 차량에 취약 |

설계 원칙:

> 터렛은 자유도를 주는 대신, 각속도와 안정화로 약점을 만들어야 한다.

특히 대형 터렛은 빠른 차량을 직접 쫓아가며 맞히는 무기가 아니라, 미리 방향을 잡고 공간을 통제하는 무기여야 한다.

## 8. 락온 무기

락온 무기는 센서로 목표를 일정 시간 추적한 뒤 발사하는 무기다.

대표 예시:

- 유도 미사일
- 추적 로켓
- EMP 미사일
- 대장갑 유도탄
- 드론/설치형 추적 장비

전투 감각:

```text
목표를 센서 범위 안에 둠
→ 락온 게이지 상승
→ 목표가 엄폐/연막/전자전에 걸리면 락온 약화
→ 락온 완료 후 발사
→ 발사체가 자체 추적 성능으로 목표 추적
```

장점:

| 장점 | 설명 |
|---|---|
| 빠른 목표 압박 | 직접 조준보다 추격에 유리 |
| 이탈 방해 | 도망가는 적을 계속 압박 가능 |
| 장거리 견제 | 센서 성능이 좋으면 먼저 압박 |
| 전술적 부담 | 상대에게 회피/방어장비 사용 강요 |

약점:

| 약점 | 설명 |
|---|---|
| 배터리 의존 | 센서/락온 유지에 배터리 사용 |
| 락온 시간 | 즉발이 아님 |
| 엄폐에 약함 | 건물/지형 뒤로 숨으면 끊김 |
| 연막/플레어/재밍에 약함 | 방어 수단으로 대응 가능 |
| 탄약 중량 | 미사일은 무겁고 탄수 제한이 큼 |

락온 안정도를 흔드는 요소:

| 요소 | 영향 |
|---|---|
| 목표의 횡방향 속도 | 락온 안정도 감소 |
| 목표의 급가속/급제동 | 락온 흔들림 |
| 엄폐물 | 락온 차단 |
| 연막 | 광학/열 추적 방해 |
| 전자전 | 레이더/통신 추적 방해 |
| 내 배터리 부족 | 락온 유지력 감소 |
| 센서 강화 | 락온 안정도 증가 |

설계 원칙:

> 락온 무기는 강한 압박 수단이지만, 배터리·탄약·엄폐·방어장비로 명확히 대응 가능해야 한다.

락온 무기가 너무 강하면 직접 조준과 차량 기동이 죽는다. 따라서 락온은 확정 명중이 아니라 상대의 선택을 강요하는 무기로 본다.

## 9. 수동 유도 무기

수동 유도 무기는 발사 후 플레이어가 직접 조작하거나, 조준점을 계속 유지해서 유도하는 무기다.

대표 예시:

- 유도 로켓
- 유선 유도 미사일
- 드론식 탄두
- 목표 지시 레이저
- 조준점 유지형 특수 무기

전투 감각:

```text
발사
→ 플레이어가 조준점 유지 또는 탄도 조작
→ 운전 집중력이 떨어짐
→ 맞히면 높은 보상
```

장점:

| 장점 | 설명 |
|---|---|
| 숙련도 보상 큼 | 잘 쓰면 강함 |
| 엄폐 뒤 목표 압박 가능 | 일부 특수 무기에 적합 |
| 락온 방해를 일부 우회 | 완전 센서 의존이 아님 |
| 독특한 무기 감각 | 고급 무기군으로 적합 |

약점:

| 약점 | 설명 |
|---|---|
| 운전과 조작 충돌 | 발사 후 운전 집중이 어려움 |
| 근거리 난전 취약 | 조작 시간이 없음 |
| 숙련도 요구 높음 | 초보자에게 어려움 |
| P0 우선순위 낮음 | 구현/UX 부담이 큼 |

설계 원칙:

> 수동 유도 무기는 P0 핵심이 아니라, P1 이후 숙련자용 특수 무기로 둔다.

## 10. 직접 조준과 자동 보정의 비율

CarFight는 직접 조준 게임이어야 하지만, 모든 무기가 완전 수동이면 차량 전투의 전략성이 줄어들 수 있다.

조준 방식별 자동 보정 비율은 다르게 둔다.

| 조준 방식 | 직접 조준 비중 | 자동 보정 비중 | 설명 |
|---|---:|---:|---|
| 고정 무기 | 높음 | 없음 | 운전 실력이 곧 조준 |
| 짐벌 무기 | 중간~높음 | 중간 | 제한각 안에서 보정 |
| 터렛 무기 | 중간 | 중간 | 목표 지정 후 각속도 제한으로 추적 |
| 락온 무기 | 낮음~중간 | 높음 | 센서/락온/대응 장비 중심 |
| 수동 유도 | 높음 | 낮음 | 발사 후 조작 숙련도 중심 |

중요 기준:

```text
편한 무기일수록 화력, 탄약, 중량, 배터리, 각속도, 락온 취약성 중 하나로 대가를 치러야 한다.
```

## 11. 조준 방식별 밸런스 원칙

### 11.1 고정 무기

```text
가장 강한 직접 화력
가장 높은 운전 의존도
차량 선회력과 제동력이 중요
```

추천 역할:

- 숙련자용 주력 무기
- 고속 교차 사격
- 정면 돌파
- 대구경 한 방

### 11.2 짐벌 무기

```text
가장 기본적인 전투 무기
초보자 친화적
중거리 교전 기준점
```

추천 역할:

- P0 기준 무기
- 기관총/오토캐논
- 경량~중형 차량 주력
- 빠른 목표 대응

### 11.3 터렛 무기

```text
차체 방향과 사격 방향을 분리
대신 각속도와 안정화 제한
중량과 피격 부위 리스크 존재
```

추천 역할:

- 중량 차량 주포
- 방어 터렛
- 후방/측면 견제
- 공간 장악

### 11.4 락온 무기

```text
센서/배터리 기반 압박
확정 명중이 아니라 대응 가능한 위협
탄약 중량과 방어장비로 밸런스
```

추천 역할:

- 추격전
- 이탈 방해
- 장거리 견제
- 빠른 목표 압박

### 11.5 수동 유도 무기

```text
고숙련 특수 무기
P1 이후 확장
운전과 조작 집중을 충돌시킴
```

추천 역할:

- 특수 빌드
- 고위험 고보상
- 엄폐전
- 보스전/정예전 연출

## 12. 조준 UI 방향

조준 방식이 여러 개면 UI가 명확해야 한다.

최소한 아래 표시가 필요하다.

| UI 요소 | 필요한 이유 |
|---|---|
| 플레이어 조준점 | 내가 어디를 보고 있는지 |
| 무기 실제 조준점 | 무기가 실제 어디를 보고 있는지 |
| 조준 가능 범위 | 짐벌/터렛이 따라갈 수 있는 한계 |
| 조준 안정화 표시 | 지금 정확히 쏠 수 있는지 |
| 락온 게이지 | 락온 진행/유지 상태 |
| 예측 조준점 | 탄속 있는 무기의 리드샷 보조 |
| 과열 표시 | 해당 무기가 계속 쏠 수 있는지 |
| 탄종/잔탄 | 현재 무기 운용 상태 |

특히 중요한 UI는 무기 실제 조준점이다.

플레이어가 중앙 조준점을 적에게 맞췄는데 터렛이 아직 못 따라왔다면, 그걸 UI로 보여줘야 한다.

예시:

```text
중앙 조준점: 플레이어가 겨누는 위치
작은 보조 조준점: 무기가 실제 바라보는 위치
두 조준점이 겹치면 정확도 상승
```

이 UI가 있어야 플레이어가 아래처럼 이해할 수 있다.

> 내가 조준은 했는데, 무기가 아직 못 따라와서 안 맞았구나.

이 정보가 없으면 플레이어는 판정을 불공정하게 느낄 수 있다.

## 13. 무기 각속도 / 안정화 스탯 구조

이후 데이터 설계에서 사용할 수 있도록 개념 스탯을 미리 잡아둔다.

| 스탯 이름 후보 | 의미 |
|---|---|
| `WeaponYawSpeed` | 무기의 좌우 회전 속도 |
| `WeaponPitchSpeed` | 무기의 상하 회전 속도 |
| `YawLimitAngle` | 좌우 조준 가능 각도 |
| `PitchLimitAngle` | 상하 조준 가능 각도 |
| `AimSettleTime` | 조준 후 안정화까지 걸리는 시간 |
| `AimSpreadWhileMoving` | 차량 이동 중 분산 증가 |
| `TrackingStability` | 목표 추적 안정성 |
| `LockOnTime` | 락온 완료까지 걸리는 시간 |
| `LockOnHoldAngle` | 락온 유지 가능 각도 |
| `BatteryUsePerSecond` | 조준/락온 보조 배터리 사용량 |

## 14. 배터리와 조준 보조

배터리는 모든 무기 발사에 쓰는 자원이 아니어야 한다.

배터리는 전자장비와 조준 보조에 연결한다.

| 배터리 사용처 | 설명 |
|---|---|
| 센서 강화 | 탐지 거리/정확도 상승 |
| 락온 유지 | 락온 안정도 증가 |
| 짐벌 보정 강화 | 일시적으로 추적 안정성 향상 |
| 터렛 안정화 | 흔들림 감소, 안정화 시간 감소 |
| 능동 방어 | 플레어, 연막, 요격장치 |
| 전자전 | 재밍, EMP 대응 |

핵심 원칙:

> 배터리는 총을 쏘기 위한 마나가 아니라, 조준·센서·방어장비를 보조하는 자동차 전장 전력이다.

## 15. 무기 열과 조준 방식

열은 차량 전체가 아니라 무기별로 존재한다.

조준 방식에 따라 열 관리도 다르게 느껴지게 할 수 있다.

| 무기 방식 | 열 관리 방향 |
|---|---|
| 고정 무기 | 강한 화력, 점사/타이밍 중요 |
| 짐벌 무기 | 지속 사격 시 분산 증가 |
| 터렛 무기 | 대형일수록 냉각/재장전 리듬 중요 |
| 락온 무기 | 열보다 재장전/락온/탄수 중심 |
| 수동 유도 | 열보다 발사 후 조작 부담 중심 |

중요 원칙:

```text
과열되면 해당 무기만 잠시 사격 불가
차량 전체 전투가 멈추지는 않음
```

## 16. P0에서 구현할 조준 방식

처음부터 5개를 다 만들지 않는다.

P0에서는 전투 정체성을 검증할 수 있는 최소 조합이 필요하다.

P0 권장 조합:

```text
01. 고정 무기 1종
02. 짐벌 무기 1종
03. 터렛 무기 1종
04. 간단한 락온 보조 또는 락온 무기 1종
```

수동 유도 무기는 P0에서 제외한다.

P0 무기 예시:

| 무기 | 조준 방식 | 검증 목적 |
|---|---|---|
| 전방 고정 오토캐논 | 고정 | 차체 조준/운전 실력 검증 |
| 소형 짐벌 기관총 | 짐벌 | 빠른 목표 대응/초보자 기준 무기 |
| 대구경 저속 터렛포 | 터렛 | 무기 각속도 약점 검증 |
| 소형 락온 로켓 | 락온 | 배터리/락온/엄폐 대응 검증 |

이 조합이 좋은 이유:

```text
고정 무기 → 운전 실력
짐벌 무기 → 직접 조준 + 보정
터렛 무기 → 각속도와 안정화
락온 무기 → 센서/배터리/대응 장비
```

CarFight의 핵심 조준 구조를 최소한으로 모두 테스트할 수 있다.

## 17. P0에서는 피할 것

P0에서 아래는 아직 하지 않는다.

| 제외 항목 | 이유 |
|---|---|
| 완전 수동 유도 미사일 | 조작/UX 부담 큼 |
| 복잡한 다중 락온 | UI와 AI 부담 큼 |
| 무기별 세부 조준 모드 10종 | 밸런스 전에 구조가 흐려짐 |
| 너무 강한 자동 터렛 | 차량 기동과 조준 실력 약화 |
| 전방위 확정 명중 미사일 | 대응 없는 불쾌감 발생 |
| 지나친 탄도 계산 | P0에서는 감각 검증이 우선 |

P0의 목표는 현실적인 탄도 시뮬레이터가 아니라, CarFight식 조준 구조가 재미있는지 확인하는 것이다.

## 19. 결정안

```text
CarFight Aiming System v0.1

핵심 정의:
CarFight의 조준은 플레이어 직접 조준을 기반으로 하되,
무기 장착 방식, 각속도, 조준 가능 각도, 안정화 시간,
센서/락온, 배터리 보조에 의해 실제 명중 가능성이 결정된다.

조준 방식:
01. 고정 무기
- 차체 방향이 곧 조준 방향이다.
- 강한 화력을 줄 수 있지만 차량 선회와 운전 실력에 크게 의존한다.

02. 짐벌 무기
- 차체 전방 제한각 안에서 조준을 보정한다.
- 초보자 친화적이고 중거리 교전의 기준이지만, 고정 무기보다 화력 효율은 낮다.

03. 터렛 무기
- 차체 방향과 독립적으로 회전한다.
- 대신 무기 각속도, 조준 안정화, 중량, 사각, 터렛 손상 위험을 가진다.

04. 락온 무기
- 센서와 배터리를 사용해 목표를 추적한다.
- 강한 압박 수단이지만 엄폐, 연막, 플레어, 전자전으로 대응 가능해야 한다.

05. 수동 유도 무기
- 발사 후 플레이어 조작 또는 조준 유지가 필요하다.
- P1 이후 숙련자용 특수 무기로 둔다.

핵심 원칙:
- 편한 조준 방식일수록 화력, 중량, 탄약, 배터리, 각속도, 락온 취약성 중 하나로 대가를 치른다.
- 고정 무기는 강하지만 어렵다.
- 짐벌 무기는 편하지만 약하다.
- 터렛은 자유롭지만 느리다.
- 락온은 강한 압박이지만 대응 가능해야 한다.
- 수동 유도는 강하지만 조작 부담이 크다.

P0 조준 방식:
- 전방 고정 오토캐논
- 소형 짐벌 기관총
- 대구경 저속 터렛포
- 소형 락온 로켓
```
