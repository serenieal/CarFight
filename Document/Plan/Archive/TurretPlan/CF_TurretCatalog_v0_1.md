# CarFight - 터렛 카탈로그

> 역할: CarFight에 추가할 차량용 터렛 후보를 P0 / P1 / P2 단계로 분류하고, 각 터렛의 전투 역할, 장착 조건, 약점, 데이터화 기준을 정의한다.  
> 문서 버전: v0.1  
> 작성일(Asia/Seoul): 2026-07-08  
> 상태: Draft / Planning / Turret Catalog  
> 기준 프로젝트: CarFight

---

## 1. 목적

이 문서는 CarFight에 들어갈 터렛 목록을 정리하기 위한 기획 문서다.

여기서 말하는 터렛은 단순히 차량 위에 달린 총이 아니라, 아래 조건을 가진 차량용 무장 패키지다.

```text
터렛 = 장착 위치 + 회전 가능한 거치대 + 실제 무기 + 탄종 / 발사체 + Damage 규칙 + 중량 / 각속도 / 안정화 제한
```

P0에서는 모든 터렛을 구현하지 않는다.

P0의 목적은 아래 하나를 검증하는 것이다.

```text
차량은 이동과 장갑 방향을 관리하고,
터렛은 플레이어 조준 방향을 늦게 따라가며,
빠른 차량은 느린 터렛의 각속도 한계를 이용할 수 있어야 한다.
```

```text
P0 확정 터렛:
```

나머지 터렛은 아직 확정된 구현 대상이 아니라, 전투 시스템 확장 후보로 관리한다.

## 4. 터렛 설계 원칙

### 4.1 터렛은 만능 무기가 아니다

터렛은 차체 방향과 독립적으로 회전할 수 있다.

하지만 터렛이 모든 상황에서 자유롭게 맞히는 무기가 되면 CarFight의 차량 조작, 위치 선정, 각속도 싸움이 무의미해진다.

따라서 모든 터렛은 아래 제한 중 일부를 가져야 한다.

| 제한 | 설명 |
|---|---|
| Yaw 제한 | 차체 구조물 또는 장착 위치 때문에 좌우 회전각 제한이 생긴다. |
| Pitch 제한 | 포신 하향 / 상향 한계 때문에 근접 또는 고저차 대응이 제한된다. |
| 각속도 제한 | 빠른 목표를 바로 따라가지 못한다. |
| 안정화 시간 | 목표 방향으로 돌린 직후에는 정확도가 낮다. |
| 중량 | 차량 가속, 제동, 선회, 무게중심에 영향을 준다. |
| 노출 모듈 | 터렛 자체가 피격 / 손상 대상이 될 수 있다. |
| 배터리 보조 | 고급 안정화나 추적 보정은 배터리를 소모할 수 있다. |

설계 원칙:

```text
자유도가 높은 터렛일수록 각속도, 안정화, 중량, 피격 위험으로 대가를 치러야 한다.
```

### 4.2 크기별 기본 방향

| 터렛 크기 | 역할 | 각속도 | 피해 | 대표 약점 |
|---|---|---:|---:|---|
| 소형 터렛 | 근접 방어, 빠른 목표 대응, 외부 모듈 견제 | 빠름 | 낮음 | 중장갑 정면에 약함 |
| 중형 터렛 | 중거리 주력 교전, 범용 화력 | 보통 | 보통 | 극근거리 고속 선회전에 취약 |
| 대형 터렛 | 한 방, 장갑 대응, 길목 장악, 공간 통제 | 느림 | 높음 | 빠른 차량에 측후면을 잡히면 취약 |

## 6. P0 확정 터렛

### 6.1 `TRT_RoofHeavyCannon`

| 항목 | 값 |
|---|---|
| 표시 이름 | 루프 대구경 저속 터렛포 |
| 영문 이름 | Roof-Mounted Large-Caliber Slow Turret Cannon |
| 단계 | P0 |
| 크기 | Large |
| MountType | `Turret` |
| 기준 하드포인트 | `Top_01` |
| 기준 MountProfile | `RoofTurret_MediumOrLarge` |
| 주 무기군 | 대구경포 |
| 주 교전 거리 | 중거리 후반 ~ 장거리 |
| 주 역할 | 한 방, 중장갑 대응, 선제타격, 길목 장악, 공간 통제 |
| 핵심 검증 | 플레이어 조준점과 실제 터렛 조준점이 다르게 움직이는 구조 |

전투 감각:

```text
강한 한 방을 가진다.
하지만 빠른 목표를 즉시 따라가지 못한다.
조준 방향으로 천천히 회전하고, 안정화가 끝난 뒤 정확도가 높아진다.
빠른 차량은 이 터렛의 측후면으로 파고들어 각속도 한계를 이용해야 한다.
```

장점:

| 장점 | 설명 |
|---|---|
| 강한 순간 피해 | 맞히면 전투 흐름을 바꿀 수 있다. |
| 중장갑 대응 | 정면 장갑이 강한 차량을 압박할 수 있다. |
| 공간 통제 | 좁은 길목이나 엄폐물 사이를 장악하기 좋다. |
| 터렛 시스템 검증 | 각속도, 안정화, 실제 발사 원점 검증에 적합하다. |

약점:

| 약점 | 설명 |
|---|---|
| 느린 Yaw | 빠른 측면 접근을 따라가기 어렵다. |
| 느린 Pitch | 고저차나 초근거리 대응이 제한된다. |
| 안정화 필요 | 돌린 직후 바로 정확히 맞히기 어렵다. |
| 높은 중량 | 차량 기동성을 낮춘다. |
| 노출 부위 | 루프에 장착되어 피격 위험이 높다. |
| 긴 재장전 / 쿨다운 | 한 발을 빗맞히면 빈틈이 커야 한다. |

P0 시작 수치 후보:

| 필드 | 값 | 설명 |
|---|---:|---|
| `MinYawDeg` | -160 | 좌측 회전 제한 |
| `MaxYawDeg` | 160 | 우측 회전 제한 |
| `MinPitchDeg` | -8 | 하향 제한 |
| `MaxPitchDeg` | 25 | 상향 제한 |
| `YawTurnRateDegPerSec` | 35 | 좌우 회전 속도 |
| `PitchTurnRateDegPerSec` | 20 | 상하 회전 속도 |
| `AimSettleTimeSeconds` | 0.35 | 안정화 시간 |
| `MountWeightKg` | 350 | 터렛 장착 중량 |

P0 판정 기준:

```text
이 터렛은 강하지만 느려야 한다.
빠른 차량이 근접 측면으로 붙었을 때 포탑이 못 따라가는 상황이 반드시 나와야 한다.
```

```text
화력은 낮지만 빠르게 돈다.
```

장점:

| 장점 | 설명 |
|---|---|

| 낮은 중량 | 경량 / 중형 차량에도 장착 후보가 될 수 있다. |
| 쉬운 이해 | 플레이어가 역할을 바로 이해하기 쉽다. |
| 모듈 견제 | 바퀴, 센서, 노출 터렛을 갉아먹기 좋다. |

약점:

| 약점 | 설명 |
|---|---|
| 낮은 장갑 관통 | 중장갑 정면에는 거의 효과가 없어야 한다. |
| 탄 소모 | 지속 사격 시 탄약 관리가 필요하다. |
| 낮은 결정력 | 단독 주무기로 전투를 끝내기 어렵다. |

구현 전제:

```text
P0 대구경 터렛의 회전 / 안정화 / FireOrigin 구조가 안정된 뒤 추가한다.
```

## 10. 터렛이 아닌 인접 장비

아래 장비는 터렛 카탈로그와 연결되지만, 기본 분류는 터렛이 아니다.

| 장비 | 분류 | 이유 |
|---|---|---|
| 전방 고정 오토캐논 | Fixed Weapon | 차체 방향 기반 무기라 터렛이 아니다. |
| 소형 짐벌 기관총 | Gimbal Weapon | 제한각 보정 무기이며 독립 회전 터렛과 다르다. |
| 경량 락온 미사일 | Launcher / Missile | 런처 회전각은 있을 수 있지만 핵심은 락온이다. |
| 연막 | Utility | 방어 / 시야 차단 장비다. |
| 플레어 | Utility | 미사일 대응 장비다. |
| 지뢰 / 스파이크 | Deployable | 설치물이며 차량 장착 터렛이 아니다. |
| 자동 방어 터렛 설치물 | Deployable Turret | 차량 루프 장착 터렛이 아니라 맵 / 설치물 시스템에 가깝다. |

## 11. 데이터화 기준

터렛 카탈로그 항목 하나는 최종적으로 아래 데이터로 쪼개진다.

| 계층 | 예시 | 역할 |
|---|---|---|
| `EquipmentPresetData` | `EQP_RoofHeavyCannon` | 유저에게 보이는 완성 장비 패키지 |
| `TurretMountData` | `TM_RoofHeavySlow` | 회전 제한, 피벗, 메쉬, 총구, 안정화, 중량 |
| `WeaponData` | `WPN_HeavyCannon` | 발사속도, 사거리, 탄창, 열, 기본 발사체 |
| `ProjectileData` | `PRJ_HeavyShell` | 탄속, 중력, 수명, 폭발 여부 |
| `DamageData` | `DMG_HeavyAP` | 피해량, 관통, 충격량, 모듈 피해 규칙 |

P0에서는 아래만 우선 확정한다.

```text
EquipmentPresetData:
  EQP_RoofHeavyCannon

TurretMountData:
  TM_RoofHeavySlow

WeaponData:
  WPN_HeavyCannon
```

ProjectileData와 DamageData는 P0 1차에서 Dummy HitScan 또는 단순 Projectile 검증에 맞춰 최소화한다.

## 15. Migration

### v0.1 적용 시 해야 할 일

1. 터렛 후보를 새로 논의할 때 이 문서의 `터렛 ID`를 기준으로 부른다.
2. 기존 문서의 `대구경 저속 터렛포`, `대구경 저속 회전포탑`, `P0 Roof Turret Cannon`은 모두 `TRT_RoofHeavyCannon`의 표시명 / 별칭으로 본다.
3. P0 코드 작업에서는 이 문서의 전체 후보를 구현 범위로 보지 않는다.
4. P0 코드 작업 범위는 `TRT_RoofHeavyCannon`과 `Top_01 + RoofTurret_MediumOrLarge`로 제한한다.
5. P1 이후 터렛 추가 시 이 문서의 후보 항목을 실제 DataAsset 이름으로 승격한다.

### 명칭 정리

| 기존 표현 | v0.1 기준 |
|---|---|
| 대구경 저속 터렛포 | `TRT_RoofHeavyCannon` 표시명 |
| 대구경 저속 회전포탑 | `TRT_RoofHeavyCannon` 유저 노출명 후보 |
| P0 Roof Turret Cannon | `TRT_RoofHeavyCannon` 영문 별칭 |
