## 1. 문서 목적

이 문서는 CarFight 차량 원화를 **3D 메쉬 제작에 바로 참고할 수 있는 시트 형식**으로 구성하는 기준을 정의한다.

CarFight의 원화는 감상용 일러스트가 아니라 C1 Simple Game Asset 최종 후보를 만들기 위한 제작 기준선이다.  
따라서 원화 시트는 멋진 구도보다 정사영 뷰, 실루엣 가독성, 파츠 위치, 장갑/마운트/재질 콜아웃을 우선해야 한다.

이 문서의 목적은 다음과 같다.

- 차량 원화 시트의 필수 뷰를 정한다.
- Side/Front/Rear/Top View의 배치와 역할을 정한다.
- 파츠 분리 표시와 콜아웃 기준을 정한다.
- 장갑, 하드포인트, 유리, 휠, 재질 정보를 한 번에 전달할 수 있게 한다.
- AI 원화 생성 결과가 감상용 이미지로 흐르지 않고 모델링 전달용 시트가 되도록 제한한다.
- 이후 `11_AIPromptRules.md`에서 프롬프트 형식을 만들 기준선을 제공한다.

## 3. 시트 구성 판단 원칙

CarFight 원화 시트는 다음 순서로 정보를 보여준다.

1. Side View에서 차급 실루엣을 먼저 보여준다.
2. Front/Rear View에서 폭, 높이, 전후 방향을 보여준다.
3. Top View에서 루프 마운트, 중심선, 터렛 회전 공간을 보여준다.
4. 장갑판, 하드포인트, 휠, 유리의 주요 파츠를 표시한다.
5. 색상/재질 콜아웃을 간단히 붙인다.
6. 작은 디테일은 텍스처/노멀 처리 대상으로만 표시한다.

중요 기준:

```text
시트를 보고 바로 차급, 큰 파츠, 장갑 위치, 마운트 위치, 재질군을 파악할 수 있어야 한다.
```

피해야 할 판단:

- 3/4 뷰 하나만으로 차량을 설명하지 않는다.
- 배경, 조명, 효과로 품질을 올리려 하지 않는다.
- 작은 볼트나 스크래치 콜아웃을 과하게 늘리지 않는다.
- 실제 제작에 쓰지 않을 내부 구조를 시트에 넣지 않는다.

### 3.1 AI 모델링 입력 기준

원화 시트는 AI 모델링 도구가 차량 구조를 오해하지 않게 만드는 입력 자료로도 사용한다.

AI 모델링용 시트에서는 다음 정보가 특히 중요하다.

| 정보 | 이유 |
|---|---|
| 같은 차량의 4뷰 | 뷰마다 디자인이 다르면 AI 모델링 결과가 섞일 수 있음 |
| 큰 파츠 콜아웃 | Body, Wheel, Glass, Armor, Mount 구분을 유도 |
| 단순한 배경 | 차량 외곽선과 파츠 경계를 흐리지 않게 함 |
| 머티리얼 콜아웃 | 생성 후 머티리얼 슬롯 정리에 필요 |
| 작은 디테일 제외 | AI가 작은 장식을 불필요한 메쉬로 만들 가능성을 줄임 |

기준 문장:

```text
AI 모델링에 넘길 시트는 예쁜 그림보다 파츠가 헷갈리지 않는 그림이어야 한다.
```

## 4. 필수 뷰 구성

C1 차량 원화 시트의 필수 뷰는 다음과 같다.

| 뷰 | 필요 여부 | 목적 |
|---|---|---|
| Side View | 필수 | 차급 실루엣, 길이, 보닛/캐빈/후방 비례 확인 |
| Front View | 필수 | 폭, 높이, 전면 방향성, 전면 장갑 확인 |
| Rear View | 필수 | 후방 방향성, 후면 장갑, 테일라이트/냉각부 확인 |
| Top View | 필수 | 루프 마운트, 터렛 회전 공간, 중심선, 차체 폭 확인 |
| 3/4 View | 선택 | 전체 인상 확인용. 모델링 기준 뷰는 아님 |
| Detail Callout | 선택 | 큰 파츠 또는 재질 설명용. 작은 디테일 남발 금지 |

기본 결정:

```text
CarFight 차량 시트는 Side/Front/Rear/Top View 4뷰를 기본으로 한다.
```

## 5. 시트 배치 기준

권장 시트 배치는 다음과 같다.

| 위치 | 내용 | 이유 |
|---|---|---|
| 상단 | Side View | 차급 실루엣을 가장 먼저 확인 |
| 중단 좌측 | Front View | 전면 폭/높이 확인 |
| 중단 중앙 | Rear View | 후면 방향성 확인 |
| 중단 우측 | Top View | 마운트와 중심선 확인 |
| 하단 | 파츠/재질 콜아웃 | 모델링 전달 정보 정리 |
| 여백 | 축소 검수용 작은 썸네일 | R1/R2 가독성 확인 |

배치 원칙:

- 각 뷰는 같은 차량으로 보여야 한다.
- 뷰마다 장갑판과 마운트 위치가 서로 맞아야 한다.
- 차량은 평면 배경 위에 둔다.
- 시트 안의 장식 배경, 강한 조명, 연출 효과는 줄인다.

## 6. 정사영 기준

모델링 전달용 시트는 정사영에 가깝게 구성한다.

권장 기준:

- Side View는 카메라 왜곡 없이 옆면을 보여준다.
- Front/Rear View는 차량 중심선이 수직으로 보이게 한다.
- Top View는 루프 마운트와 터렛 회전 공간이 보이게 한다.
- 3/4 View를 넣더라도 필수 뷰를 대체하지 않는다.
- 강한 원근감, 렌즈 왜곡, 역동적 구도는 사용하지 않는다.

피해야 할 것:

- 멋있는 원근 구도만 있고 정사영 뷰가 없는 시트
- Front/Rear View가 기울어져 폭과 높이를 판단하기 어려운 시트
- Top View가 없어 루프 마운트 위치를 알 수 없는 시트
- 그림자나 조명 때문에 실루엣이 흐려지는 시트

## 7. 파츠 분리 표시 기준

시트에서는 모델링에 필요한 큰 파츠만 표시한다.

필수 표시 후보:

| 파츠 | 표시 기준 |
|---|---|
| Body_Main | 차체 기본 덩어리 |
| Wheel_FL/FR/RL/RR | 휠 4개 위치 |
| Glass_Main | 유리 영역 |
| Armor_Front | 전면 큰 장갑판 |
| Armor_Left/Right | 측면 큰 장갑판 |
| Armor_Rear | 후면 큰 장갑판 |
| Mount_Roof | 루프 중앙 마운트 |
| Bumper_Front/Rear | 보강 범퍼가 있을 때만 |
| Sensor_Box | 큰 센서 박스가 있을 때만 |

표시하지 않아도 되는 것:

- 작은 볼트
- 얇은 패널 라인
- 작은 스크래치
- 작은 경고 라벨
- 작은 케이블
- 미세한 용접 자국

기준 문장:

```text
시트의 파츠 표시는 C1 메쉬로 만들 큰 덩어리만 대상으로 한다.
```

## 8. 장갑 콜아웃 기준

장갑 콜아웃은 큰 장갑판만 대상으로 한다.

권장 표시:

- 장갑판 이름
- 위치
- 메쉬/텍스처 처리 여부
- 차급 실루엣을 가리지 않는지 여부
- 좌우 대칭 재사용 가능 여부

권장 표기 예시:

```text
Armor_Left_A2
큰 측면 장갑판 / 메쉬 / 좌우 대칭 재사용
```

피해야 할 것:

- 작은 볼트마다 콜아웃 붙이기
- 장갑 두께나 방어 수치를 설정하기
- 군용 장갑차식 복합 장갑 구조 설명하기

---

## 9. 하드포인트 콜아웃 기준

하드포인트 콜아웃은 루프 중앙 마운트를 우선 표시한다.

필수 표시:

- Mount_Roof 위치
- 터렛 회전 중심
- Top View 회전 공간
- 장갑판/센서와의 간섭 여부

권장 표기 예시:

```text
Mount_Roof_H2
루프 중앙 마운트 / 메쉬 / Top View 회전 공간 확인
```

피해야 할 것:

- 여러 무기 성능이나 데미지 설명
- 복잡한 기어/케이블 구조 콜아웃
- 전방/측면 하드포인트를 기본값처럼 표시하기

## 10. 색상/재질 콜아웃 기준

색상/재질 콜아웃은 머티리얼 슬롯 관리에 도움이 되어야 한다.

권장 콜아웃:

| 콜아웃 | 내용 |
|---|---|
| M01 Painted_Body | 저채도 차체 도장 |
| M02 Matte_Armor | 무광/반무광 장갑판 |
| M03 Dark_Glass | 어두운 유리 |
| M04 Rubber_Tire | 어두운 고무 타이어 |
| M05 Utility_Plastic | 범퍼/마운트/센서 하우징 |
| M06 Emissive_Decal | 작은 발광/마킹 텍스처 |

권장 기준:

- 기본 5~6개 슬롯 안에서 정리한다.
- 색상 이름보다 재질 역할을 먼저 적는다.
- 발광은 작은 포인트로만 표시한다.
- 실제 브랜드 색상명이나 로고명을 쓰지 않는다.

## 11. 축소 검수 표시

원화 시트에는 축소 검수용 썸네일을 넣을 수 있다.

권장 방식:

- Side View 또는 전체 시트를 25% 크기로 줄인 썸네일을 하단에 둔다.
- 10% 크기 검수는 별도 파일 또는 작은 미리보기로 확인한다.
- 썸네일에서 차급, 방향, 무장 여부가 읽히는지 본다.

검수 순서:

1. 전체 크기로 형태를 본다.
2. 50% 크기로 큰 색면과 장갑을 본다.
3. 25% 크기로 차급과 방향을 본다.
4. 10% 크기로 큰 실루엣만 본다.

통과 기준:

```text
25% 크기에서도 차급, 방향, 무장 여부가 읽혀야 한다.
```

## 12. 시트 배경과 스타일 기준

원화 시트 배경은 단순해야 한다.

권장 기준:

- 평면 배경
- 낮은 대비의 회색 또는 밝은 중립색
- 뷰별 정렬선 또는 기준선은 허용
- 강한 그림자와 반사는 줄임
- UI 장식 프레임은 최소화

피해야 할 것:

- 복잡한 도시 배경
- 강한 네온 조명
- 연기, 폭발, 속도선 같은 연출 효과
- 차량 아래 복잡한 그림자
- 배경 때문에 실루엣이 흐려지는 구성

---

## 13. AI 원화 시트 검수 기준

AI 이미지 생성 결과를 시트로 사용할 때 아래 기준을 확인한다.

통과 질문:

- Side/Front/Rear/Top View가 모두 있는가?
- 각 뷰의 차량이 같은 디자인으로 보이는가?
- Side View에서 차급이 읽히는가?
- Top View에서 루프 중앙 마운트와 회전 공간이 읽히는가?
- 장갑판과 하드포인트 위치가 뷰마다 일관되는가?
- 큰 파츠와 재질 콜아웃을 붙일 수 있는가?
- 배경이 단순한가?

탈락 질문:

- 3/4 렌더만 있고 정사영 뷰가 없는가?
- 뷰마다 차량 디자인이 달라 보이는가?
- 배경/조명/효과가 차량 형태를 가리는가?
- 작은 디테일만 많고 큰 파츠 구분이 안 되는가?
- 실제 브랜드 차량처럼 보이는가?
- 군용 장갑차, 탱크, APC처럼 보이는가?

## 14. AI 프롬프트 영향

AI 원화 생성 프롬프트에는 시트 형식을 명확히 넣는다.

기본 형식:

```text
[Class Name],
[class silhouette phrase],
[class proportion phrase],
simplified near-future civilian combat car,
C1 simple game asset concept sheet,
orthographic side view,
orthographic front view,
orthographic rear view,
orthographic top view,
plain background,
large simple armor panels,
single roof hardpoint,
clear material color callouts,
clean readable silhouette,
low modeling complexity,
no real car brand,
no dramatic perspective,
no action scene,
no complex background
```

권장 포함 문구:

```text
orthographic concept sheet,
side front rear top views,
plain background,
part callouts,
material color callouts,
game asset reference sheet,
easy to model
```

권장 금지 문구:

```text
no cinematic render,
no action scene,
no dramatic perspective,
no complex background,
no inconsistent views,
no real brand logo,
no excessive small details
```

## 18. Migration

### v0.2 적용 시 기존 작업 영향

- 기존 원화 시트는 3D 모델러 전달용뿐 아니라 AI 모델링 입력 자료로도 검수한다.
- 4뷰가 서로 다르거나 배경/텍스트/장식이 차량 외곽선을 방해하면 AI 모델링 입력으로 바로 쓰지 않는다.
- 파츠 콜아웃이 부족한 이미지는 `Body`, `Wheel`, `Glass`, `Armor`, `Mount` 단위가 드러나도록 보강하거나 재생성한다.

### v0.1 적용 시 기존 작업 영향

- 앞으로 차량 원화는 감상용 이미지보다 Side/Front/Rear/Top View가 있는 모델링 전달용 시트로 검수한다.
- 기존에 생성된 차량 이미지가 있다면 다음 기준으로 재검토한다.
  - Side/Front/Rear/Top View가 있는가?
  - 각 뷰가 같은 차량 디자인으로 보이는가?
  - 장갑판, 루프 마운트, 휠, 유리 위치가 뷰마다 일관되는가?
  - 파츠/재질 콜아웃을 붙일 수 있을 정도로 큰 구조가 명확한가?
  - 배경과 조명이 차량 실루엣을 가리지 않는가?
- 3/4 View만 있는 이미지는 C1 모델링 기준 시트로 바로 쓰지 않고 보조 참고 이미지로만 본다.
- 이후 `11_AIPromptRules.md`는 이 문서의 시트 형식을 기본 출력 형식으로 사용한다.
