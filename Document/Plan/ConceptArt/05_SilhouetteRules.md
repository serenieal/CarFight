## 1. 문서 목적

이 문서는 CarFight 차량 원화에서 **차급별 실루엣을 어떻게 읽히게 할지**를 정의한다.

CarFight의 차량은 단순화된 근미래 민간 차량 개조 전투차다.  
따라서 전투 장갑, 루프 마운트, 센서, 범퍼 보강대가 붙어도 먼저 읽혀야 하는 것은 **민간 차량 차급 실루엣**이다.

이 문서의 목적은 다음과 같다.

- 차급별 Side/Front/Rear/Top View 실루엣 기준을 정한다.
- R1 Gameplay Mid에서 차급이 읽히는 최소 조건을 정한다.
- 장갑과 마운트가 차급 실루엣을 가리는 한계를 정한다.
- AI 원화 생성 결과를 축소 검수할 때 사용할 기준을 만든다.
- 이후 `06_ProportionRules.md`에서 수치 비례를 정할 수 있는 기준선을 만든다.

## 3. 실루엣 판단 원칙

실루엣은 작은 디테일이 아니라 큰 외곽선으로 판단한다.

CarFight에서 실루엣 판단 순서는 다음과 같다.

1. 차량 전체 길이와 높이 인상을 본다.
2. 보닛, 캐빈, 후방 공간의 큰 덩어리 관계를 본다.
3. 휠 위치와 휠 간격을 본다.
4. 루프 형태와 루프 마운트 위치를 본다.
5. 전투 개조가 원래 차급을 가리는지 본다.
6. 마지막으로 장갑판, 라이트, 센서 같은 중간 디테일을 본다.

중요 기준:

```text
작게 봤을 때 차급이 사라지면, 디테일을 더할 문제가 아니라 큰 실루엣을 다시 잡을 문제다.
```

## 4. 뷰별 공통 실루엣 규칙

### 4.1 Side View

Side View는 차급 판정의 1순위다.

반드시 확인할 요소:

- 보닛 길이
- 캐빈 위치
- 루프 높이와 루프 길이
- 트렁크 또는 후방 적재 공간
- 휠베이스 인상
- 앞/뒤 오버행 인상
- 루프 마운트가 차급 루프라인을 가리는지 여부

Side View 통과 기준:

```text
색상과 작은 디테일을 제거해도 차급이 읽혀야 한다.
```

---

### 4.2 Front View

Front View는 차량의 폭, 높이, 전면 방향성을 확인하는 뷰다.

반드시 확인할 요소:

- 전면 폭
- 차체 높이
- 휠 간격
- 전면 라이트 또는 센서 위치
- 전면 범퍼와 장갑판 크기
- 루프 마운트가 전면 실루엣을 과하게 키우는지 여부

Front View 통과 기준:

```text
전면 장갑이 붙어도 민간 차량의 전면 폭과 높이 인상이 남아야 한다.
```

---

### 4.3 Rear View

Rear View는 추격 상황과 후방 식별성을 확인하는 뷰다.

반드시 확인할 요소:

- 후면 폭
- 후면 높이
- 테일라이트 또는 후면 발광 포인트
- 트렁크, 해치, 적재 공간의 형태
- 후면 장갑판 크기
- 후면 범퍼와 냉각구의 큰 덩어리

Rear View 통과 기준:

```text
후면에서도 Sedan, Wagon, Van, Pickup처럼 후방 형태 차이가 읽혀야 한다.
```

---

### 4.4 Top View

Top View는 차체 비례와 루프 마운트 배치를 확인하는 뷰다.

반드시 확인할 요소:

- 전체 길이와 폭 인상
- 보닛, 루프, 후방 공간의 면적 관계
- 휠 위치
- 루프 마운트 위치
- 터렛 회전 공간
- 장갑판이 차체 폭을 과하게 넓히는지 여부

Top View 통과 기준:

```text
무기와 장갑을 제거하지 않아도 차체의 앞/뒤 방향과 중심선이 읽혀야 한다.
```

## 5. 차급별 핵심 실루엣 규칙

### 5.1 Microcar

| 뷰 | 실루엣 기준 |
|---|---|
| Side | 매우 짧은 차체, 짧은 보닛, 작은 캐빈, 짧은 앞/뒤 오버행 |
| Front | 좁고 작은 전면, 과하게 넓지 않은 휠 간격 |
| Rear | 작은 후면, 단순한 해치 또는 짧은 후방 덩어리 |
| Top | 짧고 좁은 전체 면적, 작은 루프 마운트 |

반드시 유지할 것:

```text
매우 짧은 길이와 작은 차체 인상
```

피해야 할 것:

- 큰 장갑판으로 SUV처럼 보이게 만들기
- 루프 무기를 크게 올려 차체보다 먼저 보이게 만들기
- 휠과 휠가드를 과장해 장난감처럼 보이게 만들기

---

### 5.2 City Car

| 뷰 | 실루엣 기준 |
|---|---|
| Side | 짧은 차체, 높은 캐빈, 짧은 후방 |
| Front | 좁거나 중간 폭, 둥글거나 단순한 전면 |
| Rear | 짧고 높은 해치형 후면 |
| Top | 짧은 루프와 작은 전체 길이 |

반드시 유지할 것:

```text
짧고 높은 도심형 민간 차량 인상
```

피해야 할 것:

- 실제 경차의 복잡한 곡면을 따라가기
- 전면 장갑을 세워 군용 장갑차처럼 만들기
- 작은 창문 분할을 과하게 늘리기

---

### 5.3 Subcompact

| 뷰 | 실루엣 기준 |
|---|---|
| Side | 작은 해치백, 짧은 후방, 적당한 루프 높이 |
| Front | 중간보다 작은 폭, 단순한 전면 |
| Rear | 짧은 해치와 넓지 않은 후면 |
| Top | 짧은 보닛, 짧은 후방, 루프 중앙 마운트 배치 가능 |

반드시 유지할 것:

```text
작은 해치백 실루엣
```

피해야 할 것:

- Compact와 구분되지 않을 정도로 길게 만들기
- 작은 장갑 조각을 많이 붙이기
- 측면 스커트와 휠가드로 차체를 과하게 넓히기

---

### 5.4 Compact

| 뷰 | 실루엣 기준 |
|---|---|
| Side | Subcompact보다 길고 안정적인 차체, 보닛과 캐빈 구분 |
| Front | 균형 잡힌 폭과 높이 |
| Rear | 해치 또는 짧은 트렁크 느낌 허용 |
| Top | 보닛, 루프, 후방이 균형 있게 나뉨 |

반드시 유지할 것:

```text
작지도 크지도 않은 기본형 민간 차량 인상
```

피해야 할 것:

- Sedan처럼 너무 긴 트렁크를 만들기
- Wagon처럼 긴 루프를 만들기
- Coupe처럼 너무 낮은 루프라인을 만들기

---

### 5.5 Sedan

| 뷰 | 실루엣 기준 |
|---|---|
| Side | 보닛-캐빈-트렁크가 분리된 낮고 긴 3박스 형태 |
| Front | 낮고 넓은 전면, 과하게 높은 장갑 금지 |
| Rear | 트렁크 덩어리와 테일라이트 위치가 읽힘 |
| Top | 보닛, 루프, 트렁크 면적이 구분됨 |

반드시 유지할 것:

```text
보닛-캐빈-트렁크 3박스 실루엣
```

피해야 할 것:

- 루프 마운트가 세단의 낮은 루프를 완전히 가리기
- 트렁크를 짧게 만들어 해치백처럼 보이게 하기
- 고급 승용차식 얇은 라인과 복잡한 곡면에 의존하기

---

### 5.6 Coupe

| 뷰 | 실루엣 기준 |
|---|---|
| Side | 낮은 차체, 짧은 캐빈, 완만하게 내려가는 루프 |
| Front | 낮고 넓은 전면, 단순한 라이트 영역 |
| Rear | 짧고 낮은 후방 |
| Top | 좁고 길게 흐르는 차체, 작은 루프 면적 |

반드시 유지할 것:

```text
낮고 날렵한 루프라인
```

피해야 할 것:

- 슈퍼카처럼 복잡한 곡면과 깊은 흡기구를 많이 만들기
- 큰 장갑판으로 낮은 실루엣을 없애기
- 네온 스포츠카 방향으로 과하게 꾸미기

---

### 5.7 Wagon

| 뷰 | 실루엣 기준 |
|---|---|
| Side | 긴 루프, 긴 후방 캐빈, 세단보다 큰 후방 덩어리 |
| Front | 세단/컴팩트보다 약간 높은 캐빈 허용 |
| Rear | 넓고 높은 해치형 후면 |
| Top | 긴 루프와 긴 후방 공간이 분명함 |

반드시 유지할 것:

```text
긴 루프와 후방 적재 공간
```

피해야 할 것:

- Van처럼 완전한 박스형으로 만들기
- 측면 창문과 문 경계를 너무 많이 쪼개기
- 군용 수송차처럼 보이게 장갑을 두껍게 세우기

---

### 5.8 SUV

| 뷰 | 실루엣 기준 |
|---|---|
| Side | 높은 차체, 큰 휠, 짧거나 중간 길이의 보닛 |
| Front | 높은 전면, 굵은 차체, 넓은 휠 간격 |
| Rear | 높은 후면과 넓은 차체 |
| Top | 넓은 차체, 큰 루프, 중앙 마운트 배치 가능 |

반드시 유지할 것:

```text
높은 차체와 큰 휠 인상
```

피해야 할 것:

- APC처럼 수직 박스 장갑으로 덮기
- 탱크처럼 낮고 넓은 장갑 덩어리로 만들기
- 복잡한 오프로드 서스펜션을 노출하기

---

### 5.9 Van

| 뷰 | 실루엣 기준 |
|---|---|
| Side | 높고 긴 박스형 차체, 짧은 보닛, 긴 측면 |
| Front | 높고 넓은 전면, 단순한 큰 면 |
| Rear | 넓고 높은 평면형 후면 |
| Top | 긴 사각형 차체, 큰 루프 면적 |

반드시 유지할 것:

```text
높고 긴 박스형 민간 밴 실루엣
```

피해야 할 것:

- 군용 수송차나 APC처럼 만들기
- 측면을 작은 패널로 과하게 분할하기
- 내부 장비나 좌석 구조를 보이게 만들기

---

### 5.10 Pickup

| 뷰 | 실루엣 기준 |
|---|---|
| Side | 앞쪽 캐빈과 뒤쪽 열린 짐칸이 분리되어 보임 |
| Front | SUV와 비슷하게 굵지만 캐빈 높이는 과하지 않음 |
| Rear | 짐칸 후면 또는 테일게이트 인상 |
| Top | 캐빈 면적과 열린 짐칸 면적이 분리됨 |

반드시 유지할 것:

```text
캐빈과 뒤쪽 짐칸의 분리
```

피해야 할 것:

- 짐칸을 무기와 적재물로 가득 채워 차급을 가리기
- 군용 테크니컬 차량처럼 무기가 먼저 읽히게 만들기
- 얇은 롤케이지나 복잡한 적재물로 파츠 수를 늘리기

## 6. 장갑/마운트 실루엣 제한

전투 개조는 차급 실루엣을 보강해야 하며, 차급을 대체하면 안 된다.

권장 기준:

| 요소 | 실루엣 제한 |
|---|---|
| 전면 장갑판 | 보닛/전면 높이를 완전히 덮지 않음 |
| 측면 장갑판 | 문과 캐빈 위치를 알아볼 수 있게 남김 |
| 후면 장갑판 | 트렁크/해치/짐칸 형태를 가리지 않음 |
| 휠가드 | 휠 위치가 계속 읽히도록 단순하게 처리 |
| 루프 마운트 | 루프라인을 완전히 가리지 않음 |
| 센서 박스 | 차급보다 먼저 읽히지 않도록 1~2개 중심 |

공통 금지 기준:

```text
장갑과 마운트를 제거해야만 차급이 읽히는 디자인은 실패로 본다.
```

## 7. R1/R2 축소 검수 기준

실루엣은 축소 상태에서 검수한다.

검수 순서:

1. Side View를 25% 크기로 줄인다.
2. 차급이 읽히는지 확인한다.
3. Front/Rear View에서 전후 방향이 읽히는지 확인한다.
4. Top View에서 루프 마운트와 중심선이 읽히는지 확인한다.
5. 10% 크기에서 소형/중형/대형과 차체 종류가 대략 읽히는지 확인한다.

R1 통과 기준:

```text
차량을 2~3초 보는 동안 차급, 방향, 무장 여부가 읽힌다.
```

R2 통과 기준:

```text
멀리서도 소형/중형/대형 인상과 큰 지붕 윤곽이 읽힌다.
```

## 8. 제작/모델링 영향

이 문서의 실루엣 규칙은 모델링에서 다음처럼 사용한다.

1. 차급을 선택한다.
2. Side View 기준으로 큰 외곽선을 먼저 만든다.
3. Front/Rear View로 폭과 높이 인상을 맞춘다.
4. Top View로 루프 마운트와 중심선을 확인한다.
5. 장갑과 마운트를 붙인다.
6. 축소 검수에서 차급이 흐려지면 장갑과 마운트를 줄인다.
7. 작은 디테일은 텍스처/노멀/머티리얼로 넘긴다.

C1 기준에서 메쉬로 우선 만들 요소:

| 요소 | 이유 |
|---|---|
| 차체 큰 외곽선 | 차급을 결정함 |
| 휠 위치 | 차량성과 움직임을 결정함 |
| 루프 마운트 | 무장 여부와 중심선을 결정함 |
| 큰 장갑판 | 전투 개조 인상을 만듦 |
| 큰 범퍼 | 전후 방향성을 보강함 |

## 9. AI 프롬프트 영향

AI 원화 생성 프롬프트에는 차급 실루엣을 명확히 넣는다.

기본 형식:

```text
[Class Name],
[class silhouette phrase],
simplified near-future civilian combat car,
clean readable silhouette,
R1 gameplay readable silhouette,
large simple shapes,
large simple armor panels,
small roof mount,
no real car brand,
no military armored vehicle,
no tank,
no silhouette-breaking armor,
orthographic side/front/rear/top concept sheet,
plain background
```

차급별 실루엣 문구:

| 차급 | 실루엣 문구 |
|---|---|
| Microcar | very short tiny civilian car silhouette |
| City Car | short tall city car silhouette |
| Subcompact | small hatchback silhouette |
| Compact | balanced compact hatchback silhouette |
| Sedan | long low three-box sedan silhouette |
| Coupe | low coupe roofline silhouette |
| Wagon | long roof wagon silhouette |
| SUV | tall civilian SUV silhouette with large wheels |
| Van | tall boxy civilian van silhouette |
| Pickup | cabin and open rear bed silhouette |

권장 금지 문구:

```text
no APC,
no tank body,
no mech,
no military vehicle silhouette,
no oversized weapon,
no excessive armor covering the original car class,
no complex tiny panels
```

## 10. 원화 검수 체크리스트

원화 1장을 보고 아래 질문을 확인한다.

통과 질문:

- Side View에서 차급이 바로 읽히는가?
- Front View에서 차량 폭과 높이가 과하지 않은가?
- Rear View에서 후방 형태가 차급과 맞는가?
- Top View에서 앞/뒤 방향과 루프 마운트 위치가 읽히는가?
- 장갑을 붙여도 원래 차급이 남아 있는가?
- R1 기준에서 차급, 방향, 무장 여부가 읽히는가?
- R2 기준에서 큰 지붕 윤곽과 휠 위치가 읽히는가?

탈락 질문:

- 장갑이 차급 실루엣을 완전히 덮는가?
- 무기가 차량보다 먼저 읽히는가?
- 탱크, APC, 군용 수송차처럼 보이는가?
- 작은 디테일을 봐야만 차급을 알 수 있는가?
- 실제 브랜드 차량의 고유 실루엣에 너무 가까운가?
- C1 기준보다 훨씬 복잡한 파츠 수가 필요해 보이는가?

최종 판정:

```text
실루엣이 실패하면 색상과 디테일로 해결하지 않는다.
```

## 14. Migration

### v0.1 적용 시 기존 작업 영향

- 앞으로 차량 원화는 Side View에서 차급이 먼저 읽히는지 검수한다.
- 기존에 생성된 차량 이미지가 있다면 다음 기준으로 재검토한다.
  - 25% 축소 상태에서도 차급이 읽히는가?
  - 장갑과 마운트가 원래 차급 실루엣을 덮지 않는가?

  - Top View에서 루프 마운트와 차체 중심선이 읽히는가?
  - 탱크, APC, 군용 장갑차처럼 보이지 않는가?
- 실루엣이 실패한 차량은 색상, 마킹, 작은 디테일을 추가하기 전에 큰 외곽선을 먼저 수정한다.
- 이후 `06_ProportionRules.md`는 이 문서의 실루엣 기준을 바탕으로 차급별 비례를 정한다.
