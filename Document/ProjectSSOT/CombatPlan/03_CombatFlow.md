# 03. 교전 흐름

- 문서 버전: v0.2
- 작성일: 2026-06-08
- 최근 갱신일: 2026-06-08
- 문서 상태: Current
- 담당 범위: 탐지 / 접근 / 위치 선점 / 교전 / 재정비 / 추격 / 이탈 흐름 정의

---

## 1. 목적

이 문서는 CarFight에서 전투 한 번이 어떤 순서와 리듬으로 흘러가야 하는지 정의한다.

CarFight의 교전은 단순히 발견 → 조준 → 사격 → 파괴로 끝나면 안 된다.

목표 흐름:

> 준비한 피팅으로 유리한 교전 조건을 만들고, 차량 기동으로 위치를 잡고, 조준/락온/무기 각속도/탄약/배터리/연료를 관리하면서, 공격·재정비·추격·이탈을 반복하는 차량 전투.

---

## 2. 전체 교전 흐름

```text
01. 탐지
02. 접근
03. 위치 선점
04. 락온 / 조준 준비
05. 1차 교전
06. 압박 / 회피 / 재정비
07. 추격 또는 이탈
08. 마무리
09. 전투 후 회수 / 보급
```

이 흐름은 한 번만 직선으로 진행되는 구조가 아니다. 실제 전투는 교전과 재정비, 재접근과 이탈을 반복한다.

반복 구조:

```text
탐지
  ↓
접근
  ↓
위치 선점
  ↓
락온 / 조준
  ↓
교전
  ↓
재정비
  ↓
재접근 또는 이탈
  ↓
마무리
```

---

## 3. 1단계 — 탐지

탐지는 전투 시작 전 단계다.

적을 먼저 발견하면 플레이어는 다음 선택권을 가진다.

- 싸울지 말지 결정
- 어떤 거리에서 시작할지 결정
- 정면으로 갈지 우회할지 결정
- 락온을 먼저 걸지 결정
- 엄폐물을 끼고 접근할지 결정
- 탄종/무기 그룹을 미리 준비할지 결정

탐지는 단순 UI 표시가 아니라 교전 주도권이다.

### 탐지에 영향을 주는 요소

| 요소 | 영향 |
|---|---|
| 센서 성능 | 적 발견 거리 증가 |
| 배터리 사용 | 능동 스캔, 락온 보조 |
| 차량 속도 | 고속 주행 시 탐지 안정성 저하 가능 |
| 지형 | 건물/언덕 뒤 적 탐지 제한 |
| 적의 전자전 | 탐지 거리 감소, 신호 교란 |
| 적의 엔진/무장 상태 | 열원, 소음, 전파 신호로 감지 가능 |

핵심 원칙:

> 탐지는 EVE Online식 정보전의 역할을 하되, 표현은 자동차 기반 센서/소음/시야/지형으로 풀어야 한다.

---

## 4. 2단계 — 접근

접근은 내가 원하는 교전 거리로 들어가는 단계다.

무기마다 싸우고 싶은 거리가 다르기 때문에, 접근 방식은 전투 조건을 결정한다.

### 접근 방식

| 접근 방식 | 설명 | 어울리는 차량/무기 |
|---|---|---|
| 정면 접근 | 빠르게 거리 좁힘 | 중장갑, 산탄, 기관총 |
| 측면 우회 | 상대 장갑 약점 노림 | 경량 차량, 근접 무기 |
| 장거리 유지 | 거리 벌리고 선제타격 | 레일건, 미사일, 대구경포 |
| 엄폐 접근 | 건물/지형 끼고 접근 | 약한 장갑, 고화력 무기 |
| 고속 교차 | 빠르게 스쳐 지나가며 공격 | 고정 무기, 로켓, 짐벌 |
| 느린 압박 | 정면 장갑으로 밀고 들어감 | 중장갑 차량, 대구경 터렛 |

접근 단계의 판단:

```text
내 무기의 최적 사거리는 어디인가?
상대 무기의 최적 사거리는 어디인가?
내 차량은 붙어야 하는가, 벌려야 하는가?
상대 무기 각속도를 이길 수 있는가?
내 배터리를 스캔/락온에 쓸 것인가?
연료를 써서 고출력 주행을 할 것인가?
```

핵심 원칙:

> 접근은 이동이 아니라, 전투 조건을 만드는 단계다.

---

## 5. 3단계 — 위치 선점

위치 선점은 내가 맞기 어려우면서 상대를 때리기 쉬운 위치를 잡는 단계다.

### 좋은 위치의 조건

| 조건 | 의미 |
|---|---|
| 내 무기 최적 거리 | 피해량/명중률이 좋은 거리 |
| 상대 무기 비효율 거리 | 상대가 제대로 못 맞히는 거리 |
| 상대 약한 장갑 방향 | 측면/후면/상부 노출 |
| 내 강한 장갑 방향 | 정면 장갑 노출 |
| 상대 무기 각속도 한계 | 터렛/짐벌이 따라오기 어려운 각 |
| 이탈 경로 | 불리할 때 빠질 수 있는 길 |
| 엄폐물 | 재장전/냉각/락온 끊기 가능 |

무기 각속도는 위치 선점의 핵심 요소다.

예시:

| 상황 | 결과 |
|---|---|
| 빠른 차량이 대구경 터렛 측면에 붙음 | 포탑이 못 따라옴 |
| 중장갑 차량이 정면 장갑으로 길목 장악 | 느린 대포도 미리 조준 가능 |
| 경량 차량이 근거리 원형 기동 | 대구경 무기 조준 안정화 방해 |
| 엄폐 뒤에서 짧게 노출 후 사격 | 상대 재조준 강요 |

핵심 원칙:

> 좋은 위치는 내 무기는 편하게 쏘고, 상대 무기는 불편하게 쏘게 만드는 상태다.

---

## 6. 4단계 — 락온 / 조준 준비

실제 피해를 넣기 직전의 준비 단계다.

플레이어는 다음 상태를 맞춰야 한다.

- 조준선
- 무기 회전 방향
- 무기 각속도
- 조준 안정화
- 락온 상태
- 탄종
- 무기 그룹
- 배터리 사용 여부
- 사격 타이밍

### 조준 준비 요소

| 요소 | 설명 |
|---|---|
| 직접 조준 | 플레이어가 조준점을 목표에 맞춤 |
| 무기 각속도 | 무기가 목표 방향을 따라갈 수 있는지 |
| 조준 안정화 | 무기가 돌아간 직후 바로 정확한지, 잠깐 안정화가 필요한지 |
| 락온 | 미사일/터렛 보정/센서 정보 확보 |
| 탄종 선택 | 장갑/모듈/전자장비 대응 |
| 무기 그룹 선택 | 거리와 상황에 맞는 무기 묶음 선택 |

핵심 원칙:

> 사격 버튼을 누르기 전에 이미 명중 여부의 상당 부분이 결정되어야 한다.

---

## 7. 5단계 — 1차 교전

실제로 피해가 오가는 단계다.

CarFight의 1차 교전은 서로 멈춰서 DPS를 교환하는 구조가 아니어야 한다.

### 1차 교전에서 발생하는 일

| 요소 | 설명 |
|---|---|
| 직접 사격 | 고정/짐벌/터렛/미사일 무기 사용 |
| 장갑 방향 판정 | 정면/측면/후면/상부 피해 차이 |
| 무기 열 증가 | 사격할수록 해당 무기 과열 |
| 탄약 소비 | 탄종별 탄수 감소 |
| 배터리 소비 | 락온, 센서, 전자전, 방어장비 사용 |
| 모듈 손상 | 바퀴, 엔진, 센서, 터렛, 배터리 계통 |
| 위치 변화 | 사격 중에도 계속 이동/선회 |

교전 중 판단:

```text
계속 쏠 것인가?
무기 열을 식힐 것인가?
탄종을 바꿀 것인가?
상대 측면을 잡을 것인가?
정면 장갑으로 버틸 것인가?
락온을 유지할 것인가?
연막/플레어/전자전을 쓸 것인가?
배터리를 지금 쓸 것인가, 아낄 것인가?
```

핵심 원칙:

> 교전은 화력 교환이 아니라, 위치·자원·조준 상태를 동시에 관리하는 구간이다.

---

## 8. 6단계 — 압박 / 회피 / 재정비

1차 교전 후에는 압박, 회피, 재정비 중 하나가 발생해야 한다.

| 선택 | 의미 |
|---|---|
| 압박 | 적이 불리할 때 더 몰아붙임 |
| 회피 | 적의 강한 무기 타이밍을 피함 |
| 재정비 | 재장전, 무기 냉각, 배터리 회복, 위치 재설정 |
| 엄폐 | 락온 끊기, 조준선 차단 |
| 거리 재조절 | 내 무기 최적 거리로 다시 이동 |

재정비가 필요한 이유:

| 시스템 | 재정비 필요성 |
|---|---|
| 무기별 열 | 계속 쏘면 해당 무기 과열 |
| 재장전 | 탄창/발사대 재준비 필요 |
| 배터리 | 센서/락온/방어장비 사용 후 회복 필요 |
| 무기 각속도 | 목표가 바뀌면 다시 회전/안정화 필요 |
| 장갑 방향 | 피격 방향을 다시 조정해야 함 |
| 연료 | 고출력 주행을 남발하면 장기전 불리 |

핵심 원칙:

> 전투 중 쉬는 시간도 전술이다.

---

## 9. 7단계 — 추격 또는 이탈

불리해졌다고 전투가 바로 끝나면 안 된다. 자동차 전투답게 추격전과 이탈전이 중요해야 한다.

### 추격

| 추격에 중요한 요소 | 설명 |
|---|---|
| 최고속도 | 장거리 추격 능력 |
| 가속 | 짧은 거리에서 따라붙는 능력 |
| 연료 | 추격 지속 가능 여부 |
| 락온 | 도주 중인 적 압박 |
| 장거리 무기 | 이탈하는 적 마무리 |
| 바퀴/엔진 피해 | 적 기동력 차단 |
| 지형 이해 | 도주 경로 예측 |

### 이탈

| 이탈에 중요한 요소 | 설명 |
|---|---|
| 연료 | 고출력 주행, 장거리 탈출 |
| 엄폐 | 락온/사선 차단 |
| 연막/플레어 | 추적 방해 |
| 후방 장갑/방어장비 | 도주 중 피격 대응 |
| 지형 | 골목, 언덕, 장애물 활용 |
| 차량 중량 | 가벼울수록 빠르게 빠질 가능성 |

핵심 원칙:

> 전투는 체력이 0이 될 때 끝나는 게 아니라, 한쪽이 추격하거나 이탈할 수 없을 때 끝나야 한다.

---

## 10. 8단계 — 마무리

마무리는 적을 완전히 제압하는 단계다.

파괴만 승리 조건으로 두지 않는다.

| 방식 | 설명 |
|---|---|
| 차체 파괴 | 일반적인 킬 |
| 엔진 무력화 | 도주 불가 |
| 바퀴 파괴 | 조향/속도 붕괴 |
| 무기 무력화 | 반격 능력 제거 |
| 센서 무력화 | 락온/정보전 차단 |
| 배터리 계통 파괴 | 전자장비 사용 제한 |
| 연료 계통 손상 | 화재/폭발/출력 저하 |

핵심 원칙:

> CarFight의 승리는 적을 터뜨리는 것뿐 아니라, 적이 더 이상 싸우거나 도망갈 수 없게 만드는 것도 포함해야 한다.

---

## 11. 9단계 — 전투 후 회수 / 보급

P0 필수는 아니지만, 전략성을 키우는 데 중요하다.

전투 후에는 다음 상태가 다음 교전에 영향을 줘야 한다.

| 항목 | 의미 |
|---|---|
| 남은 탄약 | 다음 교전 가능성 |
| 남은 연료 | 귀환/추격/이탈 가능성 |
| 배터리 상태 | 전자장비 사용 가능성 |
| 무기 손상 | 다음 전투 화력 저하 |
| 차체/바퀴/엔진 손상 | 이동 능력 저하 |
| 회수 가능한 탄약/부품 | 보급/경제 시스템 연결 가능 |

핵심 원칙:

> 전투 하나의 결과가 다음 전투의 조건을 바꿔야 한다.

---

## 12. P0 교전 루프

P0에서는 아래 흐름만 검증한다.

```text
탐지
→ 접근
→ 거리/각도 잡기
→ 조준
→ 사격
→ 무기 과열/재장전
→ 재접근 또는 이탈
→ 파괴
```

### P0에서 반드시 느껴져야 하는 것

| 검증 항목 | 설명 |
|---|---|
| 거리 차이 | 가까운 무기/먼 무기의 유불리가 다름 |
| 각도 차이 | 정면/측면/후면 피격 결과가 다름 |
| 무기 각속도 | 큰 무기는 빠른 목표를 따라가기 어려움 |
| 무기 열 | 계속 쏘면 해당 무기만 쉬어야 함 |
| 탄약 중량 | 많이 싣는 선택이 주행에 영향 |
| 배터리 사용 | 락온/센서 보조에 제한이 있음 |
| 이탈 가능성 | 불리하면 무조건 죽는 게 아니라 빠질 수 있음 |

## 13. 결정안

```text
CarFight Combat Flow v0.1

01. 탐지
- 센서, 시야, 소음, 지형을 통해 적을 발견하고,
  싸울지 피할지 판단한다.

02. 접근
- 내 무기의 최적 거리로 들어가거나,
  상대 무기의 강한 거리를 피한다.

03. 위치 선점
- 내 장갑 방향, 상대 약점 방향, 엄폐, 이탈 경로,
  상대 무기의 각속도 한계를 고려해 유리한 위치를 잡는다.

04. 락온 / 조준 준비
- 직접 조준, 락온, 탄종, 무기 그룹,
  무기 각속도와 조준 안정화 상태를 맞춘다.

05. 1차 교전
- 사격, 장갑 방향 판정, 무기 열, 탄약 소비,
  배터리 사용, 모듈 손상이 동시에 발생한다.

06. 압박 / 회피 / 재정비
- 무기 냉각, 재장전, 락온 끊기, 배터리 회복,
  위치 재설정을 통해 다음 교전을 준비한다.

07. 추격 또는 이탈
- 유리하면 추격하고, 불리하면 연료/엄폐/방어장비를 사용해 이탈한다.

08. 마무리
- 적을 파괴하거나, 엔진/바퀴/무기/센서를 무력화해
  더 이상 싸우거나 도망갈 수 없게 만든다.

09. 전투 후 회수 / 보급
- 남은 탄약, 연료, 배터리, 손상 상태가 다음 교전의 조건이 된다.
```
