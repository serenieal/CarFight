---

## 1. 목적

이 문서는 CarFight의 피팅 시스템 방향을 정의한다.

CarFight의 피팅은 EVE Online식 전략성을 참고하지만, 우주선의 전력/CPU 중심 구조를 그대로 복제하지 않는다. 자동차 게임이므로 피팅의 핵심 비용은 `중량`, `장착 위치`, `탄약/연료 적재량`, `배터리 용량`, `장갑 방향`, `차량 기동성 변화`여야 한다.

---

## 2. 핵심 정의

> 피팅은 출격 전에 차량이 어떤 전투를 할 수 있는지 결정하는 전략 선택이다.

피팅은 아래 요소를 함께 결정한다.

| 요소 | 전투 영향 |
|---|---|
| 차급 | 기본 중량, 크기, 장착 가능 하드포인트, 기동성 |
| 무기 | 교전 거리, 조준 방식, 화력, 열, 각속도 |
| 탄종/탄수 | 지속 전투력, 장갑 대응, 모듈 피해, 중량 |
| 장갑 | 방향별 생존력, 중량, 기동성 저하 |
| 배터리 | 센서, 락온, 방어장비, 전자전 지속력 |
| 연료 | 작전 지속력, 추격/이탈 여유, 중량 |
| 방어장비 | 연막, 플레어, 냉각, 수리, 차폐 등 |

---

## 3. 슬롯 분류

P0~P1 기준 슬롯은 다음처럼 단순하게 시작한다.

| 슬롯 | 역할 |
|---|---|
| Weapon Slot | 주무기/보조무기 장착 |
| Utility Slot | 연막, 플레어, 냉각, 수리, 센서 보조 |
| Armor Slot | 방향별 장갑 또는 장갑 타입 선택 |
| Battery Slot | 배터리 용량/출력 선택 |
| Ammo Loadout | 탄종과 탄수 선택 |
| Fuel Loadout | 연료량 선택 |

하드포인트는 슬롯과 분리해서 본다. 슬롯은 `장비 종류 제한`이고, 하드포인트는 `장착 위치 제한`이다.

## 4. 핵심 비용: 중량

중량은 피팅 선택의 총비용이다.

```text
총중량 = 차체 기본 중량 + 장갑 + 무기 + 탄약 + 연료 + 배터리 + 유틸리티 장비
```

중량은 아래 성능에 영향을 준다.

| 성능 | 영향 |
|---|---|
| 가속 | 무거울수록 저하 |
| 제동 | 무거울수록 제동거리 증가 |
| 선회 | 무거울수록 둔화 |
| 최고속도 | 일정 중량 이상에서 감소 |
| 연료 소비 | 무거울수록 증가 가능 |
| 충돌 | 무거운 차량이 일부 유리 |
| 반동 안정성 | 무거운 차량이 대구경 운용에 일부 유리 |

중량은 무조건 단점만은 아니다. 무거운 차량은 정면 압박, 충돌, 대구경 무기 운용, 장기전에 강할 수 있다. 대신 빠른 적의 각속도 플레이에 약해야 한다.

---

## 5. 피팅 선택의 교환 관계

| 선택 | 장점 | 단점 |
|---|---|---|
| 중장갑 | 정면 교전 강함 | 둔해짐, 연료 부담 증가 |
| 탄약 다량 | 장기전 유리 | 가속/선회 저하 |
| 철갑탄 중심 | 중장갑 대응 | 무거움, 경량전 비효율 |
| 고폭탄 중심 | 바퀴/터렛 무력화 | 정면 장갑 관통 약함 |
| 대용량 배터리 | 락온/방어장비 지속력 | 중량 증가 |
| 연료 다량 | 장거리 작전/추격 | 중량 증가 |
| 대구경 무기 | 한 방과 공간 통제 | 각속도/열/중량 부담 |
| 소형 무기 | 빠른 반응 | 장갑 대응 약함 |

---

## 6. 차급과 피팅 방향

| 차급 방향 | 피팅 정체성 |
|---|---|
| 경량 차량 | 적게 싣고 빠르게 움직이며 각속도 한계를 깨는 빌드 |
| 중형 차량 | 중거리 주력, 상황 대응, 무기/탄종 균형 빌드 |
| 중량 차량 | 장갑, 대구경, 지속전, 공간 통제 빌드 |

같은 차급 안에서도 피팅에 따라 역할이 갈라져야 한다. 예를 들어 Compact 차량도 경량 추격차, 중거리 오토캐논차, 센서 보조차로 갈라질 수 있어야 한다.

## 7. P0 최소 피팅 구조

```text
P0 Fitting Scope

01. 차체 기본 중량
02. 장갑 타입: 경량 / 표준 / 중장갑
03. 무기 장착: 고정 오토캐논, 짐벌 기관총, 터렛포, 락온 미사일
04. 탄종/탄수: 일반탄 / 철갑탄 / 고폭탄
05. 배터리 게이지와 기본 용량
06. 연료량 선택과 중량 반영
07. 총중량에 따른 가속/제동/선회 변화
08. 유틸리티 1종: 연막 또는 플레어
```

P0에서는 복잡한 전력망, 발전기, 탄약 부피, 세부 슬롯 제한은 제외한다. 먼저 중량과 장착 위치가 전투 감각을 바꾸는지 검증한다.

## 8. 피팅 UI 요구

피팅 화면은 플레이어에게 선택의 대가를 명확히 보여줘야 한다.

| UI 항목 | 표시 내용 |
|---|---|
| 총중량 | 현재 피팅의 총중량 |
| 성능 변화 | 가속, 제동, 선회, 최고속도 변화 |
| 탄약 중량 | 탄종/탄수별 중량 |
| 연료 중량 | 연료량에 따른 중량 |
| 배터리 용량 | 전자장비 운용 가능 시간 |
| 하드포인트 | 장착 위치와 사각 |
| 무기 그룹 | 전투 중 발사 그룹 |

## 9. 핵심 원칙

```text
01. 차량은 클래스가 아니라 플랫폼이다.
02. 피팅은 전투 방식을 결정해야 한다.
03. 중량은 피팅 선택의 핵심 비용이다.
04. 탄약과 연료도 장착물처럼 중량을 가진다.
05. 강한 장비는 화력뿐 아니라 중량, 각속도, 열, 배터리, 탄약 비용을 가져야 한다.
06. P0에서는 중량 기반 피팅 감각부터 검증한다.
```
