# CFServerLauncher v1.0 검증 체크리스트

문서 버전: v1.0.0  
작성 기준일: 2026-05-26

## 1. 목적

이 문서는 `CFServerLauncher` v1.0 구현 후 기능 검증에 사용할 체크리스트이다.

검증 목표는 다음과 같다.

1. 설정 저장/불러오기가 안정적으로 동작하는지 확인한다.
2. 잘못된 입력값이 서버 실행 전에 차단되는지 확인한다.
3. 실행 인자가 의도대로 조립되는지 확인한다.
4. 서버 프로세스 시작/종료가 동작하는지 확인한다.
5. `-AbsLog=...` 기반 로그 tail이 동작하는지 확인한다.

## 2. 설정 검증

| 번호 | 항목 | 기대 결과 |
|---|---|---|
| C-001 | `server.local.json`이 없을 때 앱 실행 | 기본 설정값이 표시된다. |
| C-002 | 설정 저장 클릭 | `server.local.json`이 생성된다. |
| C-003 | 앱 종료 후 재실행 | 이전 설정값이 복원된다. |
| C-004 | JSON 파일을 일부러 손상 | 오류 메시지가 표시되고 앱은 종료되지 않는다. |
| C-005 | 누락된 선택 필드 존재 | 기본값으로 보정된다. |
| C-006 | `server.sample.json` 확인 | 기본 샘플 설정을 확인할 수 있다. |

## 3. 경로 검증

| 번호 | 항목 | 기대 결과 |
|---|---|---|
| P-001 | 서버 EXE 경로 정상 | 서버 시작 가능 상태가 된다. |
| P-002 | 서버 EXE 경로가 존재하지 않음 | 서버 시작이 차단된다. |
| P-003 | 서버 EXE 확장자가 `.exe`가 아님 | 서버 시작이 차단된다. |
| P-004 | 작업 폴더 정상 | 서버 시작 가능 상태가 된다. |
| P-005 | 작업 폴더 없음 | 서버 시작이 차단된다. |
| P-006 | 로그 폴더 없음 | 시작 전에 폴더가 생성된다. |
| P-007 | 로그 파일 삭제 불가 | 서버 시작이 차단되고 오류가 표시된다. |
