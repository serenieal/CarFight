# 08. 방어 타입과 장갑 방향

- 문서 버전: v0.2
- 작성일: 2026-06-08
- 최근 갱신일: 2026-06-08
- 문서 상태: Current
- 담당 범위: CarFight의 방어 구조, 장갑 방향, 장갑 타입, 모듈 손상, P0 방어 범위 정의

---

## 1. 목적

이 문서는 CarFight의 방어 타입과 장갑 방향을 정의한다.

CarFight의 방어는 단순 체력바가 아니라 다음 요소가 결합된 구조여야 한다.

```text
장갑 방향
장갑 타입
차체 내구도
모듈 손상
차량 기능 저하
```

이 문서에서 결정하는 범위는 다음과 같다.

| 항목 | 설명 |
|---|---|
| 방어 구조 | 장갑, 차체 내구도, 모듈 내구도의 관계 |
| 장갑 방향 | 정면, 측면, 후면, 상부, 하부의 방어 의미 |
| 장갑 타입 | P0 기준 경량/표준/중장갑 |
| 피해 타입 관계 | 물리, 관통, 폭발, 전자 피해와 장갑의 관계 |
| 모듈 손상 | 바퀴, 엔진, 터렛, 센서, 배터리, 연료 계통 손상 방향 |
| P0 범위 | 최초 프로토타입에서 구현할 최소 방어/손상 범위 |

이 문서에서 아직 최종 결정하지 않는 범위는 다음과 같다.

| 항목 | 상태 |
|---|---|
| 최종 피해 공식 | 아직 정하지 않음 |
| 최종 장갑 수치 | 아직 정하지 않음 |
| 모듈별 세부 HP | 아직 정하지 않음 |
| P1 이후 전자 피해 수치 | 아직 정하지 않음 |
| 연료 화재/폭발 세부 규칙 | 아직 정하지 않음 |

## 2. 현재 기준

이전 문서 기준으로 확정된 상위 원칙은 다음과 같다.

```text
CarFight는 자동차 기반 전략형 차량 전투 게임이다.
전략 구조는 EVE Online을 참고하지만, 자원과 전투 표현은 자동차 기반으로 재해석한다.
전투 조작은 Elite Dangerous식 직접 조준, 하드포인트, 무기 그룹, 무기 각속도 개념을 참고한다.
```

방어 시스템에 직접 연결되는 기존 결정은 다음과 같다.

| 기존 결정 | 방어 시스템에 주는 영향 |
|---|---|
| 거리/각도/속도 관리 | 정면/측면/후면 피격 방향이 전투 결과에 영향을 줘야 함 |
| 무기 각속도 | 빠른 차량은 맞지 않는 위치를 만들고, 느린 대구경 무기를 무력화할 수 있어야 함 |
| 탄종/피해 타입 | 일반탄, 철갑탄, 고폭탄이 장갑/모듈에 다르게 작동해야 함 |
| 탄약/장갑 중량 | 방어력을 올리면 차량 기동성이 떨어져야 함 |
| 배터리/연료 | P1 이후 센서, 락온, 방어장비, 연료 계통 손상과 연결 가능 |

## 3. 핵심 정의

CarFight의 방어는 다음처럼 정의한다.

```text
CarFight의 방어는 단순 체력바가 아니라,
장갑 방향, 장갑 타입, 차체 내구도, 모듈 손상이 결합된 시스템이다.
```

적을 이기는 방식은 항상 차체 내구도를 0으로 만드는 것만이 아니어야 한다.

다음과 같은 전투 결과도 의미 있는 제압으로 인정할 수 있어야 한다.

```text
적의 바퀴를 망가뜨려 기동 불가 상태로 만든다.
적의 엔진을 망가뜨려 추격/이탈 능력을 없앤다.
적의 터렛을 망가뜨려 반격 능력을 낮춘다.
적의 센서를 망가뜨려 락온/정보전을 무력화한다.
적의 배터리 계통을 압박해 방어장비와 전자장비를 못 쓰게 한다.
```

## 4. 방어 시스템 기본 구조

차량 방어는 3층 구조로 잡는다.

```text
01. 장갑
02. 차체 내구도
03. 모듈 내구도
```

| 계층 | 의미 | 역할 |
|---|---|---|
| 장갑 | 피해를 줄이거나 막는 외부 방어층 | 방향, 탄종, 피해 타입과 상호작용 |
| 차체 내구도 | 차량 전체 생존력 | 0이 되면 차량 파괴 |
| 모듈 내구도 | 바퀴, 엔진, 터렛, 센서 등 기능 부품 | 손상되면 차량 성능 저하 |

핵심 원칙은 다음과 같다.

```text
차체 내구도가 남아 있어도,
모듈이 망가지면 전투 능력은 크게 떨어질 수 있다.
```

## 5. 장갑 방향

자동차 전투에서 장갑 방향은 직관적이어야 한다.

| 방향 | 방어 의미 | 주요 약점/특징 |
|---|---|---|
| 정면 | 가장 튼튼한 방향 | 정면 압박, 돌파, 중량 차량의 핵심 |
| 측면 | 전술적 약점 | 선회전 중 자주 노출됨 |
| 후면 | 큰 약점 | 엔진, 연료 계통, 배터리 접근 위험 |
| 상부 | 특수 약점 | 미사일, 고각탄, 폭발, 낙하 공격에 취약 |
| 하부 | 특수 약점 | 지뢰, 충돌, 점프 착지, 하부 폭발에 취약 |

### 5.1 P0 방향별 피해 계수 초안

P0에서는 복잡한 장갑 판정보다 방향별 피해 계수로 시작한다.

| 피격 방향 | 피해 계수 | 의도 |
|---|---:|---|
| 정면 | 1.0x | 기준 방어 방향 |
| 측면 | 1.2x | 전술적 약점 |
| 후면 | 1.5x | 확실한 약점 |
| 상부 | 1.3x | 고폭/미사일 특화 약점 |
| 하부 | 1.6x | 지뢰/하부 폭발 특화 약점 |

이 수치는 최종 밸런스가 아니라 테스트용이다.

목표 감각은 다음과 같다.

```text
정면으로 버티는 건 가능하지만,
측면과 후면을 내주면 확실히 위험하다.
```

## 6. 장갑 타입

P0에서는 장갑 타입을 3개만 사용한다.

| 장갑 타입 | 특징 | 장점 | 단점 |
|---|---|---|---|
| 경량 장갑 | 가볍고 얇음 | 기동성 유지 | 관통/폭발에 약함 |
| 표준 장갑 | 기본형 | 균형형 | 특화 장점 없음 |
| 중장갑 | 두껍고 무거움 | 정면 방어 강함 | 가속/제동/선회 저하 |

### 6.1 P1 이후 확장 장갑 후보

| 장갑 타입 | 역할 |
|---|---|
| 복합 장갑 | 철갑/관통 피해에 강함 |
| 공간 장갑 | 고폭/로켓/미사일 폭발 피해 완화 |
| 전자 차폐 장갑 | EMP/전자 피해 저항 |
| 반응 장갑 | 일부 폭발/관통 피해를 1회성으로 경감 |
| 모듈 보호 키트 | 바퀴/엔진/터렛 등 특정 부위 보호 |

P0에서는 경량/표준/중장갑만으로 충분하다.

## 7. 피해 타입과 장갑의 관계

이전 문서 기준 피해 타입은 다음과 같다.

```text
물리 피해
관통 피해
폭발 피해
전자 피해
```

장갑과의 관계는 다음과 같이 잡는다.

| 피해 타입 | 장갑과의 관계 | 주요 탄종 |
|---|---|---|
| 물리 피해 | 기본 피해. 표준 장갑 기준 | 일반탄 |
| 관통 피해 | 장갑을 뚫는 데 강함 | 철갑탄 |
| 폭발 피해 | 모듈/바퀴/상부/하부에 강함 | 고폭탄 |
| 전자 피해 | 센서/배터리/락온 계통에 강함 | EMP탄 |

P0에서는 전자 피해를 제외하고 아래 3개만 사용한다.

```text
P0 피해 타입:
01. 물리
02. 관통
03. 폭발
```

## 8. 방어 판정 흐름

CarFight의 피해 판정 흐름은 다음과 같다.

```text
01. 어느 방향에서 맞았는가?
02. 어떤 탄종/피해 타입인가?
03. 맞은 방향의 장갑이 얼마나 막는가?
04. 차체 피해가 얼마나 들어가는가?
05. 주변 모듈에 피해가 들어가는가?
06. 모듈 상태가 정상/손상/치명/무력화 중 어디까지 내려갔는가?
```

게임 시스템 관점에서는 다음과 같이 정리한다.

```text
피격
→ 피격 방향 판정
→ 장갑 타입 판정
→ 탄종/피해 타입 판정
→ 차체 피해 적용
→ 모듈 피해 적용
→ 기능 저하 적용
```

## 9. 모듈 손상 단계

모듈은 `정상/파괴` 2단계가 아니라 4단계로 잡는다.

| 상태 | 의미 |
|---|---|
| 정상 | 성능 저하 없음 |
| 손상 | 약한 성능 저하 |
| 치명 손상 | 큰 성능 저하 |
| 무력화 | 해당 기능 거의 또는 완전 상실 |

예를 들어 바퀴는 다음처럼 작동할 수 있다.

| 바퀴 상태 | 효과 |
|---|---|
| 정상 | 문제 없음 |
| 손상 | 접지/선회 약간 저하 |
| 치명 손상 | 조향 불안정, 최고속도 저하 |
| 무력화 | 차량이 한쪽으로 쏠림, 고속 주행 위험 |

## 10. 주요 모듈별 손상 효과

### 10.1 바퀴

바퀴는 CarFight에서 가장 중요한 모듈 중 하나다.

| 손상 정도 | 효과 |
|---|---|
| 손상 | 접지력 감소, 선회력 저하 |
| 치명 손상 | 차량이 흔들림, 제동/가속 불안정 |
| 무력화 | 한쪽으로 쏠림, 고속 주행 거의 불가 |

바퀴에 강한 피해는 다음과 같다.

| 피해/탄종 | 이유 |
|---|---|
| 고폭탄 | 폭발로 바퀴/서스펜션에 피해 |
| 산탄 | 근거리에서 바퀴 타격 |
| 지뢰/스파이크 | 하부/타이어 특화 |
| 충돌 | 물리적 파손 |

핵심 원칙은 다음과 같다.

```text
빠른 차량을 잡는 방법은 HP를 깎는 것만이 아니라,
바퀴를 망가뜨려 속도를 죽이는 것이다.
```

### 10.2 엔진

엔진은 가속, 최고속도, 이탈 능력과 연결된다.

| 손상 정도 | 효과 |
|---|---|
| 손상 | 가속 저하 |
| 치명 손상 | 최고속도/부스트 제한 |
| 무력화 | 이동 불가 또는 매우 느린 이동만 가능 |

엔진에 강한 피해는 다음과 같다.

| 피해/탄종 | 이유 |
|---|---|
| 철갑탄 | 후면/엔진룸 관통 |
| 고폭탄 | 폭발로 엔진/냉각계 손상 |
| 소이탄 | P1 이후 화재/연료 계통 연계 |

핵심 원칙은 다음과 같다.

```text
후면을 잡는 가장 큰 보상은
엔진과 연료 계통을 위협할 수 있다는 점이다.
```

### 10.3 터렛 / 무장부

터렛은 무기 각속도 시스템과 직접 연결된다.

| 손상 정도 | 효과 |
|---|---|
| 손상 | 무기 각속도 감소 |
| 치명 손상 | 조준 안정화 시간 증가, 분산 증가 |
| 무력화 | 해당 무기 사격 불가 또는 제한 사격 |

터렛에 강한 피해는 다음과 같다.

| 피해/탄종 | 이유 |
|---|---|
| 고폭탄 | 외부 장착부 손상 |
| 일반탄 지속 사격 | 노출된 터렛을 갉아먹음 |
| 철갑탄 | 장갑형 포탑 관통 가능 |

핵심 원칙은 다음과 같다.

```text
대구경 터렛은 강하지만,
느리고 노출된 고가치 모듈이어야 한다.
```

이 구조가 있으면 빠른 차량이 대구경 차량을 상대할 때 차체를 못 뚫어도 터렛을 무력화한다는 선택지가 생긴다.

### 10.4 센서

센서는 락온, 정보전, 예측 조준 보조와 연결된다.

| 손상 정도 | 효과 |
|---|---|
| 손상 | 탐지 거리 감소 |
| 치명 손상 | 락온 시간 증가, 약점 정보 감소 |
| 무력화 | 락온 불가 또는 매우 제한적 |

센서에 강한 피해는 다음과 같다.

| 피해/탄종 | 이유 |
|---|---|
| 고폭탄 | 외부 센서 손상 |
| EMP탄 | 전자장비 방해 |
| 기관총 지속 사격 | 노출 장비 파괴 |

P0에서는 센서 손상은 제외한다.
락온 시스템이 어느 정도 자리 잡은 뒤 P1에서 넣는다.

### 10.5 배터리 계통

배터리는 전자장비, 능동 방어, 락온 보조와 연결된다.

| 손상 정도 | 효과 |
|---|---|
| 손상 | 배터리 회복/출력 감소 |
| 치명 손상 | 락온/방어장비 사용 제한 |
| 무력화 | 전자장비 대부분 사용 불가 |

배터리에 강한 피해는 다음과 같다.

| 피해/탄종 | 이유 |
|---|---|
| EMP탄 | 직접 카운터 |
| 철갑탄 | 내부 배터리 관통 |
| 고폭탄 | 배선/제어장치 손상 |

P0에서는 배터리 자원만 먼저 두고, 배터리 계통 손상은 P1 이후로 둔다.

### 10.6 연료 계통

연료는 자동차 아이덴티티를 선명하게 만드는 자원이다.

| 손상 정도 | 효과 |
|---|---|
| 손상 | 연료 누출, 작전 지속력 감소 |
| 치명 손상 | 고출력 주행 제한, 화재 위험 |
| 무력화 | 이동 지속 불가 또는 화재/폭발 위험 |

연료 계통에 강한 피해는 다음과 같다.

| 피해/탄종 | 이유 |
|---|---|
| 후면 피격 | 연료 탱크/라인 취약점 |
| 고폭탄 | 폭발 충격 |
| 소이탄 | P1 이후 화재 유발 |
| 철갑탄 | 내부 관통 가능 |

P0에서는 연료 계통 손상은 제외하고, 연료는 출격 중량과 작전 지속력 정도로만 둔다.

---

## 11. 차체 내구도와 모듈 내구도의 관계

모듈 피해와 차체 피해는 완전히 같은 것이 아니어야 한다.

| 피해 종류 | 설명 |
|---|---|
| 차체 피해 | 차량 전체 HP를 깎음 |
| 모듈 피해 | 특정 기능을 약화시킴 |
| 관통 피해 | 장갑을 넘어 내부 차체/엔진에 피해 |
| 폭발 피해 | 주변 모듈에 피해를 나눠줌 |

예시는 다음과 같다.

```text
철갑탄이 후면을 관통함
→ 차체 피해 증가
→ 엔진 모듈에도 피해

고폭탄이 바퀴 근처에서 폭발함
→ 차체 피해는 중간
→ 바퀴/터렛/센서 모듈 피해 증가
```

핵심 원칙은 다음과 같다.

```text
차체를 빠르게 부수는 탄과,
기능을 망가뜨리는 탄은 달라야 한다.
```

## 12. 장갑과 중량의 관계

장갑은 반드시 중량과 연결되어야 한다.

| 장갑 선택 | 장점 | 단점 |
|---|---|---|
| 경량 장갑 | 빠르고 잘 돎 | 잘 뚫림 |
| 표준 장갑 | 균형적 | 특화 장점 없음 |
| 중장갑 | 정면 교전 강함 | 둔하고 연료 소모 증가 |
| 후면 보강 | 도주/추격 중 생존력 증가 | 중량 증가 |
| 측면 보강 | 선회전 생존력 증가 | 가속/선회 저하 |
| 하부 보강 | 지뢰/충돌 대응 | 중량 증가 |

장갑 강화 흐름은 다음처럼 작동해야 한다.

```text
장갑을 많이 붙인다
→ 잘 버틴다
→ 하지만 무거워진다
→ 가속/제동/선회가 나빠진다
→ 상대 무기 각속도를 깨기 어려워진다
```

이 구조가 CarFight의 전략성과 자동차 정체성을 동시에 살린다.

## 13. 차급별 방어 정체성

### 13.1 경량 차량

| 특징 | 방향 |
|---|---|
| 방어 방식 | 맞지 않는 것이 방어 |
| 장갑 | 경량 또는 표준 |
| 약점 | 후면/측면/바퀴 |
| 생존 방식 | 속도, 선회, 엄폐, 락온 끊기 |

경량 차량의 핵심은 다음과 같다.

```text
경량 차량의 방어는 장갑이 아니라 위치와 속도다.
```

### 13.2 중형 차량

| 특징 | 방향 |
|---|---|
| 방어 방식 | 균형형 |
| 장갑 | 표준 + 일부 방향 보강 |
| 약점 | 피팅에 따라 달라짐 |
| 생존 방식 | 거리 조절, 장갑 방향 관리, 보조 장비 |

중형 차량은 플레이어 선택에 따라 정체성이 갈려야 한다.

### 13.3 중량 차량

| 특징 | 방향 |
|---|---|
| 방어 방식 | 정면 장갑과 공간 통제 |
| 장갑 | 중장갑 |
| 약점 | 후면, 측면, 터렛, 바퀴 |
| 생존 방식 | 정면 노출, 길목 장악, 보조 터렛/방어장비 |

중량 차량은 무조건 튼튼한 차량이 아니라, 정면은 강하지만 측후면과 기동성이 약한 차량이어야 한다.

## 14. 방어 장비와 장갑의 차이

장갑과 방어 장비는 역할이 다르다.

| 구분 | 역할 |
|---|---|
| 장갑 | 맞았을 때 피해를 줄임 |
| 방어 장비 | 맞기 전 상황을 바꿈 |
| 모듈 보호 | 특정 기능 손상을 줄임 |
| 능동 방어 | 미사일/락온/폭발을 대응함 |

방어 장비 예시는 다음과 같다.

| 장비 | 역할 |
|---|---|
| 연막 | 락온/시야 차단 |
| 플레어 | 미사일 대응 |
| 요격장치 | 로켓/미사일 격추 |
| 냉각 장치 | 무기 열 감소 |
| 긴급 수리 | 바퀴/엔진 임시 복구 |
| 전자 차폐 | EMP 저항 |
| 장갑 키트 | 특정 방향 방어 강화 |

P0에서는 방어 장비를 많이 넣지 않는다.
미사일이 P0에 들어간다면 연막 또는 플레어 1종만 먼저 넣는다.

## 15. P0 방어/손상 범위

처음부터 모든 모듈을 넣으면 복잡도가 너무 크다.

| 시스템 | P0 포함 여부 | 이유 |
|---|---:|---|
| 차체 내구도 | 포함 | 기본 전투 성립 |
| 방향별 피해 계수 | 포함 | 거리/각도 전투 검증 |
| 경량/표준/중장갑 | 포함 | 피팅과 중량 검증 |
| 바퀴 손상 | 포함 권장 | 차량 전투 정체성 핵심 |
| 엔진 손상 | 포함 권장 | 추격/이탈 흐름 검증 |
| 터렛 손상 | 포함 권장 | 무기 각속도 시스템과 연결 |
| 센서 손상 | P1 | 락온/정보 UI 정리 후 |
| 배터리 계통 손상 | P1 | 배터리 시스템 안정화 후 |
| 연료 계통 손상 | P1 | 화재/누출/작전 지속력 정리 후 |
| 상부/하부 세부 판정 | P1 | P0에서는 방향 계수만 |
| 방어장비 다종 | P1 | P0에서는 1종만 |

### 15.1 P0 최소 구현안

정말 최소로 가면 아래만 있어도 된다.

```text
01. 차체 HP
02. 방향별 피해 계수
03. 장갑 타입 3종: 경량 / 표준 / 중장갑
04. 바퀴 모듈
05. 엔진 모듈
06. 터렛 모듈
```

미사일이 P0에 들어간다면 추가로 다음이 필요하다.

```text
07. 연막 또는 플레어 1종
```

## 16. P0 손상 효과 초안

### 16.1 바퀴 손상

| 상태 | 효과 |
|---|---|

| 상태 | 효과 |
|---|---|
| 손상 | 무기 각속도 감소 |

| 무력화 | 해당 터렛 사격 불가 |

## 18. 핵심 설계 원칙

### 18.1 정면은 강해야 한다

정면 장갑이 의미 있어야 중량 차량의 정체성이 생긴다.

```text
중량 차량은 정면으로 버틴다.
경량 차량은 정면을 피하고 측후면을 잡는다.
```

### 18.2 후면은 확실한 보상이어야 한다

후면을 잡는 것은 쉬운 일이 아니므로 확실한 보상이 있어야 한다.

```text
후면 피격
→ 피해 증가
→ 엔진/연료 계통 위험
→ 이탈 능력 저하
```

### 18.3 바퀴 손상은 차량 게임의 핵심이다

```text
빠른 적을 못 죽여도
바퀴를 망가뜨리면 전투 흐름을 바꿀 수 있다.
```

### 18.4 대구경 터렛은 강하지만 취약해야 한다

```text
대구경 터렛:
강한 한 방
느린 각속도
긴 안정화
높은 중량
노출된 고가치 모듈
```

### 18.5 장갑은 공짜 방어력이 아니다

```text
장갑 증가
→ 중량 증가
→ 가속/제동/선회 저하
→ 연료 소비 증가 가능
→ 빠른 적 대응 어려움
```
