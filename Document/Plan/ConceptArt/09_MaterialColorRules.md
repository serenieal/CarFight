## 1. 문서 목적

이 문서는 CarFight 차량 원화에서 **재질과 색상을 어떻게 단순하게 제한할지**를 정의한다.

CarFight의 차량은 단순화된 근미래 민간 차량 개조 전투차다.  
따라서 재질과 색상은 화려한 쇼카나 네온 중심 사이버펑크가 아니라, 저채도 민간 차량 차체 위에 기능적인 장갑판과 제한적인 발광 요소가 붙은 방향이어야 한다.

이 문서의 목적은 다음과 같다.

- C1 Simple Game Asset 기준의 기본 재질군을 정한다.
- 차량 1대당 색상과 머티리얼 슬롯을 과하게 늘리지 않는 기준을 정한다.
- R1 Gameplay Mid에서 큰 색면으로 차체, 장갑, 유리, 휠, 마운트가 구분되게 한다.
- 발광 색상과 경고 마킹을 제한한다.
- AI 원화 생성 결과가 과도한 네온, 실제 브랜드 색상 복제, 복잡한 표면 재질로 흐르지 않도록 제한한다.
- 이후 `10_ConceptSheetFormat.md`에서 색상/재질 콜아웃을 정할 기준선을 만든다.

## 3. 재질/색상 판단 원칙

CarFight의 재질과 색상 판단 순서는 다음과 같다.

1. 먼저 차급 실루엣이 색상 없이도 읽히는지 본다.
2. 그다음 큰 색면으로 차체와 장갑판이 구분되는지 본다.
3. 그다음 유리, 휠, 마운트, 센서가 단순하게 구분되는지 본다.
4. 그다음 제한적인 발광 포인트를 배치한다.
5. 마지막으로 경고 마킹, 오염, 스크래치 같은 작은 텍스처 정보를 더한다.

중요 기준:

```text
색상은 실루엣과 비례를 보완해야 하며, 실패한 형태를 대신 해결하는 수단이 아니다.
```

피해야 할 판단:

- 색상이 화려하면 좋은 원화라고 보지 않는다.
- 발광 라인을 많이 넣어 근미래 느낌을 대신하지 않는다.
- 실제 브랜드나 특정 레이싱 리버리를 복제하지 않는다.
- 재질 수를 많이 늘려 퀄리티를 올리는 방향을 기본값으로 삼지 않는다.

## 4. 기본 재질군

C1 차량 1대의 기본 재질군은 아래 범위를 우선한다.

| 재질군 | 용도 | 기준 |
|---|---|---|
| Painted_Body | 차체 도장 금속 | 저채도 기본색, 큰 면 중심 |
| Matte_Armor | 장갑판 | 차체보다 어둡거나 탁한 무광/반무광 |
| Dark_Glass | 유리/강화유리 | 어둡고 단순한 색면 |
| Rubber_Tire | 타이어 | 어두운 고무 느낌 |
| Utility_Plastic | 범퍼/몰딩/센서 하우징 | 어두운 플라스틱/복합재 느낌 |
| Bare_Metal | 마운트/힌지/보강부 | 제한적 금속 포인트 |
| Emissive_Point | 센서/상태등 | 작은 발광 포인트 |
| Decal_Marking | 번호/경고 마킹 | 텍스처 중심 |

기본 결정:

```text
차량 1대는 적은 재질군으로 차체, 장갑, 유리, 휠, 마운트를 구분한다.
```

## 5. 머티리얼 슬롯 예산

C1 Simple Game Asset 기준의 머티리얼 슬롯은 적게 유지한다.

| 기준 | 슬롯 수 |
|---|---:|
| 최소 기준 | 3~4개 |
| 기본 권장 | 5~6개 |
| 상한 권장 | 8개 이하 |
| 초과 주의 | 9개 이상 |

권장 기본 슬롯:

| 슬롯 | 용도 |
|---|---|
| 01 | 차체 도장 |
| 02 | 장갑판 |
| 03 | 유리 |
| 04 | 타이어/고무 |
| 05 | 어두운 플라스틱/마운트 |
| 06 | 발광/마킹 텍스처 |

기준 문장:

```text
머티리얼 슬롯이 많아질수록 1인 개발 관리 부담이 커진다.
```

## 6. 기본 색상 팔레트

CarFight의 기본 색상은 저채도 중심으로 제한한다.

권장 기본색:

| 색상군 | 사용 위치 | 기준 |
|---|---|---|
| 어두운 회색 | 장갑, 마운트, 휠가드 | 가장 안전한 기본값 |
| 차가운 회색 | 차체, 보조 패널 | 산업적 느낌 |
| 탁한 청회색 | 차체 포인트 | 약한 근미래 느낌 |
| 탁한 녹색 | 장갑/기능성 차량 | 군용으로 과하게 가지 않게 제한 |
| 탁한 적갈색 | 녹/오염/보조 포인트 | 넓은 면 기본색으로는 주의 |
| 더러운 흰색 | 차체 변주 | 너무 깨끗한 쇼카 느낌 금지 |
| 저채도 노랑/주황 | 경고 마킹 | 작은 면적만 사용 |

피해야 할 기본색:

- 과한 네온 보라/분홍/파랑
- 고채도 레이싱 컬러 전체 도장
- 실제 브랜드를 떠올리게 하는 고유 색 조합
- 전체 차체를 덮는 발광 라인
- 군용 위장색 패턴 중심 디자인

---

## 7. 위치별 색상 기준

### 7.1 차체 도장

차체 도장은 차량의 가장 큰 색면이다.

권장 기준:

- 저채도 기본색을 사용한다.
- 차체 색은 장갑판과 약간 구분되어야 한다.
- 색상보다 큰 면 분할이 먼저 읽혀야 한다.
- 실제 브랜드나 특정 차량 모델 색 조합을 피한다.

피해야 할 것:

- 고광택 슈퍼카 도장
- 전체 네온 그라데이션
- 복잡한 레이싱 스트라이프
- 실제 브랜드 리버리 복제

---

### 7.2 장갑판

장갑판은 차체보다 기능적인 느낌이어야 한다.

권장 기준:

- 차체보다 조금 어둡거나 탁하게 한다.
- 무광 또는 반무광 느낌을 우선한다.
- 큰 판형 패널이 색면으로 읽혀야 한다.
- 작은 스크래치와 볼트는 텍스처/노멀로 처리한다.

피해야 할 것:

- 장갑판을 너무 화려한 포인트 컬러로 칠하기
- 장갑과 차체 색이 같아서 큰 판이 안 읽히게 만들기
- 군용 장갑차처럼 위장색 패턴을 중심으로 만들기

---

### 7.3 유리/강화유리

유리는 어둡고 단순해야 한다.

권장 기준:

- 어두운 청색/회색/검은색 계열을 사용한다.
- 반사나 내부 디테일을 과하게 그리지 않는다.
- R1에서 캐빈 위치가 읽히는 큰 색면으로 처리한다.
- 유리 파손선이나 작은 반사는 텍스처로 제한한다.

피해야 할 것:

- 내부 좌석/계기판을 자세히 보이게 만들기
- 유리를 여러 작은 조각으로 과하게 나누기
- 강한 네온 반사로 차급 실루엣을 흐리게 만들기

---

### 7.4 타이어/고무

타이어는 어둡고 단순한 고무 재질로 처리한다.

권장 기준:

- 어두운 회색/검정 계열을 사용한다.
- 큰 타이어 덩어리와 휠 위치가 R1에서 읽혀야 한다.
- 타이어 패턴은 큰 방향성만 남긴다.
- 작은 트레드 디테일은 텍스처/노멀로 처리한다.

피해야 할 것:

- 복잡한 타이어 패턴을 메쉬로 만들기
- 휠을 고채도 포인트 컬러로 과하게 강조하기
- 작은 로고나 브랜드 마킹 넣기

---

### 7.5 마운트/하드포인트

마운트와 하드포인트는 차량보다 먼저 보이면 안 된다.

권장 기준:

- 어두운 금속/플라스틱 계열을 사용한다.
- 차체와 장갑 사이에서 읽히는 정도의 명도 차이를 둔다.
- 작은 고정구는 텍스처/노멀로 처리한다.
- 발광은 센서나 상태등에만 작게 사용한다.

피해야 할 것:

- 루프 마운트를 고채도 색으로 강조하기
- 마운트 주변에 많은 발광 라인을 넣기
- 복잡한 금속 재질 변주를 많이 만들기

---

## 8. 발광 색상 기준

발광은 제한적으로만 사용한다.

권장 발광 요소:

- 센서 렌즈
- 작은 상태 표시등
- 냉각부의 약한 발광
- 배터리/전자장비 상태 패널
- 하드포인트 작동 표시등

권장 발광 색상:

| 색상 | 용도 | 기준 |
|---|---|---|
| 청록 | 센서/전자장비 | 가장 안전한 기본값 |
| 약한 파랑 | 냉각/상태등 | 작은 면적 |
| 주황 | 경고/열/위험 표시 | 소량 |
| 빨강 | 위험/피격/경고 | 매우 제한 |

금지 기준:

- 차체 전체 네온 라인
- 휠 전체 발광
- 과한 보라/분홍 네온
- 기능 설명이 없는 장식용 발광
- 발광이 차급 실루엣보다 먼저 읽히는 구성

---

## 9. 경고 마킹과 데칼 기준

경고 마킹은 기능적 정보처럼 보여야 한다.

권장 기준:

- 큰 장갑판 또는 차체 큰 면 위에 소량 배치한다.
- 번호, 방향 표시, 경고 삼각형, 정비용 라벨 정도로 제한한다.
- R1에서는 큰 색면 보조 요소, R0에서는 디테일로 보이게 한다.
- 실제 브랜드 로고나 상표를 쓰지 않는다.

피해야 할 것:

- 차량 전체를 덮는 그래픽 패턴
- 실제 레이싱 스폰서/브랜드 느낌
- 너무 작은 라벨을 많이 넣기
- 마킹이 차급이나 장갑판보다 먼저 읽히기

---

## 10. 오염/마모 표현 기준

오염과 마모는 분위기 강화용이다.

권장 기준:

- 텍스처 중심으로 처리한다.
- 하단부 먼지, 장갑판 가장자리 스크래치, 약한 페인트 벗겨짐 정도를 허용한다.
- R1에서 큰 명암 덩어리를 깨지 않는 선에서 사용한다.
- 파손 메쉬는 초기 기준에서 기본값으로 삼지 않는다.

피해야 할 것:

- 폐차처럼 보일 정도의 과한 손상
- 복잡한 파손 메쉬
- 작은 스크래치를 과하게 많이 넣기
- 오염 때문에 차체와 장갑의 구분이 사라지기

---

## 11. 차급별 색상 적용 기준

차급별 색상은 기능적 인상을 보조하는 정도로만 사용한다.

| 차급 | 권장 색상 인상 |
|---|---|
| Microcar | 작은 차체가 읽히는 밝은/중간 저채도 차체색 |
| City Car | 민간 차량 느낌이 남는 단순한 저채도 색 |
| Subcompact | 기본형 차체색 + 어두운 장갑판 |
| Compact | 가장 표준적인 회색/청회색 계열 |
| Sedan | 낮고 긴 형태가 읽히는 차분한 색 |
| Coupe | 고채도 스포츠카 색보다 낮은 명도 대비 |
| Wagon | 장비 차량 느낌의 탁한 회색/녹색 계열 |
| SUV | 튼튼한 인상의 어두운 차체 + 무광 장갑 |
| Van | 큰 면이 밋밋하지 않게 제한적 마킹 사용 |
| Pickup | 짐칸과 캐빈이 구분되는 큰 색면 |

공통 기준:

```text
차급 구분은 색상이 아니라 실루엣과 비례가 먼저 담당한다.
```

## 12. C1 재질/색상 원화 검수

AI 이미지나 수작업 원화를 검수할 때 아래 질문을 사용한다.

통과 질문:

- 차체, 장갑판, 유리, 휠이 큰 색면으로 구분되는가?
- 색상이 저채도 중심인가?
- 발광 요소가 작은 포인트로 제한되어 있는가?
- 머티리얼 슬롯을 5~6개 정도로 정리할 수 있어 보이는가?
- 작은 라벨, 스크래치, 볼트는 텍스처로 넘길 수 있는가?
- 실제 브랜드 색 조합이나 로고를 피하고 있는가?
- R1에서 작은 장식보다 큰 명암 덩어리가 먼저 읽히는가?

탈락 질문:

- 전체 차체가 네온 장식 중심인가?
- 고채도 레이싱/쇼카 느낌이 강한가?
- 실제 브랜드 리버리처럼 보이는가?
- 재질이 너무 많아 머티리얼 슬롯이 과하게 늘어날 것 같은가?
- 발광 요소가 차량 실루엣보다 먼저 읽히는가?
- 오염/마모 때문에 차체와 장갑 구분이 사라지는가?

## 13. AI 프롬프트 영향

AI 원화 생성 프롬프트에는 재질과 색상 제한 문구를 넣는다.

기본 형식:

```text
[Class Name],
[class silhouette phrase],
[class proportion phrase],
simplified near-future civilian combat car,
low saturation industrial colors,
matte armor panels,
painted civilian car body,
dark simple glass,
dark rubber tires,
small limited emissive sensor lights,
large readable color blocks,
low modeling complexity,
no real car brand,
no racing livery,
no excessive neon,
no full body glowing lines,
orthographic side/front/rear/top concept sheet,
plain background
```

권장 포함 문구:

```text
low saturation colors,
matte armor panels,
painted metal body,
dark glass,
dark rubber tires,
small warning decals,
limited emissive points,
large readable color blocks
```

권장 금지 문구:

```text
no excessive neon,
no cyberpunk glow overload,
no racing sponsor livery,
no real brand logo,
no complex material variation,
no full body decals,
no glossy supercar paint
```

## 17. Migration

### v0.1 적용 시 기존 작업 영향

- 앞으로 차량 원화는 저채도 큰 색면으로 차체, 장갑판, 유리, 휠을 구분하는지 검수한다.
- 기존에 생성된 차량 이미지가 있다면 다음 기준으로 재검토한다.
  - 차체/장갑/유리/휠이 R1에서 큰 색면으로 구분되는가?
  - 과도한 네온이나 고채도 쇼카 느낌이 강하지 않은가?
  - 실제 브랜드 로고, 색 조합, 레이싱 리버리처럼 보이지 않는가?
  - 머티리얼 슬롯을 5~6개 정도로 정리할 수 있는가?
  - 발광 요소가 작은 센서/상태등 포인트로 제한되어 있는가?
- 색상으로만 차급이나 장갑 구조를 설명하는 차량은 실루엣/비례/장갑 기준부터 다시 검토한다.
- 이후 `10_ConceptSheetFormat.md`는 이 문서의 재질군과 색상 기준을 바탕으로 콜아웃 표기 방식을 정한다.
