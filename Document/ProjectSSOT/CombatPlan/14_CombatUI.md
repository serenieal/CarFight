- 최근 갱신일: 2026-06-08

- 담당 범위: 전투 UI 정보 구조

---

## 1. 목적

이 문서는 CarFight의 전투 UI가 어떤 정보를 어떤 우선순위로 보여줘야 하는지 정의한다.

CarFight는 거리, 각도, 속도, 락온, 무기 각속도, 무기 열, 탄약, 배터리, 연료, 모듈 손상 등 정보량이 많은 전투 게임이다. 따라서 UI는 단순 장식이 아니라 플레이어가 왜 맞았고 왜 못 맞혔고 왜 졌는지 이해하게 만드는 핵심 시스템이다.

---

## 2. UI 핵심 원칙

```text
01. 전투 중 UI는 현재 판단에 필요한 정보만 우선 표시한다.
02. 세부 피팅 수치와 중량 변화는 피팅 화면에서 보여준다.
03. 플레이어 조준점과 무기 실제 조준점은 분리해서 보여준다.
04. 락온과 과열은 경고가 명확해야 한다.
05. 모듈 손상은 전투 결과를 이해할 수 있을 정도로 표시한다.
```

---

## 3. 조준 UI

| UI 요소 | 역할 |
|---|---|
| 플레이어 조준점 | 플레이어가 명령하는 조준 방향 |
| 무기 실제 조준점 | 무기가 실제 바라보는 방향 |
| 예측 조준점 | 탄속/목표 이동을 고려한 리드샷 보조 |
| 조준 가능 범위 | 짐벌/터렛/락온 유지 가능 각도 |
| 안정화 표시 | 무기가 따라왔는지, 정확히 쏠 수 있는지 표시 |

중요 원칙:

```text
내가 조준했는데 무기가 아직 못 따라왔다면 UI로 보여줘야 한다.
그렇지 않으면 플레이어는 판정이 불공정하다고 느낀다.
```

## 4. 대상 정보 UI

| 정보 | P0 여부 | 설명 |
|---|---:|---|
| 대상 거리 | 포함 | 무기 유효거리 판단 |
| 대상 속도 | 포함 | 추격/이탈 판단 |
| 락온 진행률 | 포함 | 미사일/센서 사용 판단 |
| 락온 안정도 | 포함 권장 | 흔들림/차단 상태 이해 |
| 장갑 방향 | P1 | 정면/측면/후면 판별 |
| 모듈 상태 | P1 | 바퀴/엔진/터렛 손상 표시 |
| 약점 정보 | P1 | 스캔 기반 정보 |

P0에서는 대상 거리, 속도, 락온 게이지, 락온 완료 표시만 먼저 구현한다.

---

## 5. 자원 UI

| 자원 | 표시 방식 | 설명 |
|---|---|---|
| 배터리 | 게이지 | 락온/센서/방어장비 사용 가능 여부 |
| 연료 | 게이지 또는 작전 지속 표시 | 부스트/이탈/추격 여유 |
| 탄약 | 무기별 잔탄 / 현재 탄종 | 탄종 전환과 지속 전투력 |
| 무기 열 | 무기별 열 게이지 | 과열 직전/과열 상태 |
| 중량 | 피팅 화면 중심 | 전투 중에는 직접 표시 최소화 |

전투 중에는 모든 숫자를 세밀하게 보여주기보다, 경고 중심으로 보여주는 것이 좋다.

---

## 6. 경고 UI

| 경고 | 조건 |
|---|---|
| 과열 경고 | 현재 무기가 과열 직전 |
| 무기 과열 | 해당 무기 사용 불가 |
| 락온당함 | 적이 나를 락온 중 |
| 미사일 접근 | 유도탄 접근 중 |
| 배터리 낮음 | 방어장비/락온 사용 제한 위험 |
| 탄약 부족 | 현재 무기/탄종 잔탄 부족 |
| 모듈 손상 | 바퀴/엔진/터렛 손상 발생 |
| 연료 낮음 | 장기 추격/이탈 제한 위험 |

---

## 7. 모듈 손상 UI

P0 모듈은 바퀴, 엔진, 터렛만 다룬다.

| 모듈 | 표시 내용 |
|---|---|
| 바퀴 | 선회/접지 저하 상태 |
| 엔진 | 가속/최고속도/부스트 제한 상태 |
| 터렛 | 각속도/안정화/사격 가능 상태 |

손상 단계는 `정상 / 손상 / 치명 손상 / 무력화`로 표현한다.

---

## 8. 피팅 UI

피팅 화면에서는 전투 중 UI보다 더 많은 정보를 보여준다.

| 항목 | 설명 |
|---|---|
| 총중량 | 현재 피팅 총중량 |
| 성능 변화 | 가속, 제동, 선회, 최고속도 변화 |
| 탄약 중량 | 탄종/탄수별 중량 |
| 장갑 방향 | 정면/측면/후면 보강 상태 |
| 배터리 용량 | 전자장비 운용 여유 |
| 연료량 | 작전 지속력과 중량 |
| 하드포인트 | 장착 위치와 사각 |
| 무기 그룹 | Primary/Secondary/Missile/Utility 구성 |

## 9. P0 UI 범위

```text
P0 Combat UI Scope

01. 플레이어 조준점
02. 무기 실제 조준점
03. 현재 무기 열 게이지
04. 현재 무기 잔탄 / 탄종
05. 배터리 게이지
06. 연료 게이지
07. 대상 거리
08. 락온 게이지
09. 락온당함 / 미사일 경고
10. 바퀴 / 엔진 / 터렛 손상 표시
11. 피팅 화면의 총중량과 주행 성능 변화 표시
```

---

## 10. 핵심 원칙

```text
01. UI는 플레이어가 패배 원인을 납득하게 해야 한다.
02. 조준점과 무기 실제 방향의 차이를 반드시 보여준다.
03. 락온과 과열은 경고가 늦으면 안 된다.
04. 피팅 화면에서는 중량의 대가를 명확히 보여준다.
05. 전투 중 UI는 판단 우선순위 중심으로 간결하게 유지한다.
```
