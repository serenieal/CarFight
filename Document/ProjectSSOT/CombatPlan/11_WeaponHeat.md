# 11. Weapon Heat

- 문서 버전: v0.1
- 작성일: 2026-06-08
- 최근 갱신일: 2026-06-08
- 문서 상태: Current
- 담당 범위: 무기별 과열 / 냉각 / 사격 리듬

---

## 1. 목적

이 문서는 CarFight의 `무기별 열` 시스템을 정의한다.

CarFight에서 열은 차량 전체 자원이 아니다. 뜨거워지는 것은 자동차가 아니라 계속 사격한 무기다. 따라서 과열은 차량 주행이나 모든 무기를 막는 전역 페널티가 아니라, 해당 무기 하나의 사격 리듬을 제한하는 장치로 다룬다.

---

## 2. 핵심 정의

> 무기별 열은 연사, 점사, 재장전, 냉각 타이밍을 만들기 위한 무기 단위 자원이다.

무기 열은 다음 역할을 가진다.

| 역할 | 설명 |
|---|---|
| 연사 제한 | 계속 누르고만 있으면 손해가 생긴다. |
| 점사 유도 | 무기별로 끊어 쏘는 리듬을 만든다. |
| 무기 개성 | 기관총, 오토캐논, 대구경포, 레일건의 감각을 분리한다. |
| 재정비 구간 | 엄폐, 이탈, 재접근의 이유를 만든다. |
| 냉각 장비 가치 | 피팅에서 냉각 장비 선택의 의미를 만든다. |

---

## 3. 열 상태 단계

| 상태 | 의미 | 전투 영향 |
|---|---|---|
| 정상 | 열이 낮은 상태 | 성능 저하 없음 |
| 가열 | 열이 쌓이는 상태 | 분산 증가 또는 안정화 저하 가능 |
| 과열 직전 | 위험 경고 상태 | UI 경고, 사격 지속 판단 필요 |
| 과열 | 해당 무기 사용 불가 | 일정 시간 해당 무기 사격 불가 |
| 냉각 | 열이 감소하는 상태 | 시간이 지나거나 냉각 장비로 회복 |

중요 원칙은 다음과 같다.

```text
과열되면 해당 무기만 잠시 사격 불가가 된다.
차량 전체 주행, 배터리, 연료, 다른 무기까지 동시에 막지 않는다.
```

---

## 4. 무기군별 열 방향

| 무기군 | 열 누적 | 냉각 | 설계 의도 |
|---|---:|---:|---|
| 기관총 | 낮음~중간 | 빠름 | 길게 긁을 수 있지만 무한 연사는 금지 |
| 오토캐논 | 중간 | 중간 | 점사와 연사 선택이 중요 |
| 대구경포 | 발당 높음 | 느림 | 강한 한 방 후 재정비 필요 |
| 산탄 무기 | 낮음~중간 | 중간 | 근접 폭딜 후 간격 필요 |
| 로켓 | 낮음 | 중간 | 열보다 탄약/재장전 중심 |
| 미사일 | 낮음 | 중간 | 열보다 락온/탄수/배터리 중심 |
| 레일건/코일건 | 매우 높음 | 느림 | 배터리와 열을 모두 쓰는 고위험 무기 |
| EMP/전자전 | 낮음~중간 | 중간 | 직접 열보다 배터리 부담 중심 |

---

## 5. 과열과 조준 안정화

열은 단순히 사격 가능/불가만 결정하지 않고, 일부 무기에서는 조준 안정성에도 영향을 줄 수 있다.

| 열 상태 | 조준 영향 예시 |
|---|---|
| 정상 | 기본 분산 |
| 가열 | 분산 소폭 증가 |
| 과열 직전 | 안정화 시간 증가, 탄 퍼짐 증가 |
| 과열 | 사격 불가 |

단, P0에서는 너무 복잡하게 가지 않는다. P0에서는 우선 `열 증가`, `자연 냉각`, `과열 시 해당 무기 사격 불가`만 검증한다.

---

## 6. 냉각 방식

| 냉각 방식 | 설명 | 도입 단계 |
|---|---|---|
| 자연 냉각 | 사격하지 않으면 자동으로 열 감소 | P0 |
| 엄폐 냉각 | 엄폐/이탈 중 사격을 멈추고 냉각 | P0 플레이 패턴 |
| 냉각 장비 | 일정 시간 냉각 속도 증가 | P1 |
| 냉각 피팅 | 냉각 성능을 높이는 장착 부품 | P1 |
| 손상 페널티 | 터렛 손상 시 냉각 또는 안정화 저하 | P1 |

---

## 7. 다른 자원과의 관계

| 자원 | 관계 |
|---|---|
| 탄약 | 쏠 때 탄약과 열이 동시에 관리된다. |
| 배터리 | 일반 물리 무기는 배터리를 쓰지 않는다. 단, 레일건/터렛 안정화/냉각 장비는 배터리와 연결 가능하다. |
| 연료 | 직접 연결하지 않는다. 연료는 주행/작전 자원이다. |
| 중량 | 냉각 장비와 대구경 무기는 중량을 증가시킨다. |
| 모듈 손상 | 터렛 손상 시 각속도, 안정화, 냉각 성능이 저하될 수 있다. |

## 8. P0 최소 구현

```text
P0 Weapon Heat Scope

01. 무기별 Heat 값
02. 사격 시 Heat 증가
03. 비사격 시 Heat 자연 감소
04. Heat가 한계치에 도달하면 해당 무기 과열
05. 과열 중 해당 무기 사격 불가
06. 일정 시간 또는 일정 Heat 이하로 내려가면 재사용 가능
07. UI에 현재 무기별 열 상태 표시
```

P0에서는 탄종별 열 보정, 냉각 장비, 손상에 따른 냉각 저하는 제외한다.

---

## 9. 핵심 원칙

```text
01. 열은 차량 자원이 아니라 무기 자원이다.
02. 과열은 해당 무기만 막아야 한다.
03. 강한 무기일수록 열과 냉각 부담이 커야 한다.
04. 빠른 무기는 오래 쏠 수 있지만 결정력은 낮아야 한다.
05. 과열은 플레이어에게 재정비, 엄폐, 무기 전환 판단을 요구해야 한다.
06. 냉각 장비는 P1 이후 피팅 선택지로 확장한다.
```
