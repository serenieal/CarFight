## 1. v1.1 목표

`CFServerLauncher` v1.1의 목표는 v1.0의 단일 서버 실행 설정 구조를 다중 실행 프로필 구조로 확장하는 것이다.

v1.1은 기능을 크게 늘리는 버전이 아니다. 핵심은 앞으로 서버 실행 옵션이 늘어나도 런처가 유연하게 확장될 수 있도록 설정 구조를 정리하는 것이다.

```text
v1.1 목표:
다중 실행 프로필과 설정 마이그레이션을 도입해서,
향후 서버 실행 옵션 확장에 견딜 수 있는 설정 구조로 개편한다.
```

## 2. v1.1 핵심 원칙

1. 저장용 설정과 실행용 설정을 분리한다.
2. `AppConfig`는 런처 전체 설정을 담당한다.
3. `ServerProfile`은 서버 실행 설정만 담당한다.
4. `ServerRunConfig`는 실제 서버 실행 1회에 사용할 값을 담당한다.
5. v1.0 설정 파일은 자동 마이그레이션한다.
6. Unreal 서버 C++ 코드와 런처 코드는 계속 분리한다.

## 6. v1.1 완료 정의

다음 조건을 만족하면 v1.1 완료로 본다.

```text
1. v1.0 설정 파일이 v1.1 프로필 구조로 자동 변환된다.
2. 최소 1개의 기본 프로필이 생성된다.
3. 프로필을 추가/선택/저장/삭제할 수 있다.
4. 마지막 선택 프로필이 앱 재실행 후 유지된다.
5. 선택한 프로필 값으로 서버 시작/종료/재시작이 가능하다.
6. ActiveLogFilePath와 기준 LogFilePath 분리가 유지된다.
7. v1.0에서 통과한 핵심 기능이 깨지지 않는다.
```
